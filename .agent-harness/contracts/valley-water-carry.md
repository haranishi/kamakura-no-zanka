# 庭の暮らしと自然表現の工程契約

目的は既存の水運びの結果を景色へ残し、水路復旧と点灯までの短い続きへ磨くこと。
変更範囲は仕様、実行ソース、少量の配布可能素材、検証と非公開Git運用。
元GLB・衝突・移動範囲・稲の共有描画を維持する。
戦闘、人物、室内、拡張マップ、バックエンド、公開デプロイは対象外。

正本は.kiro/specs/valley-water-carry/。v18-designとv18-tasksで追補する。
成功は要件7・8と既存要件の回帰、通常操作での全しごと、保存移行で照合する。
Node・配布・HTTP、実ブラウザ、画面3幅、固定画角、移動中の性能を確認する。
独立した体験評価とコードレビューを行い、実在する指摘を直す。
改善は最大3周。同一失敗2周は原因と残件を報告する。採点を製品全体の完成度と呼ばない。

依頼者の作り込み・ハーネス反復と、SDD・非公開Gitのcommit/push/PR/mergeの指示を継承する。
公開、秘密情報送信、課金、重要データ削除は許可に含めない。
