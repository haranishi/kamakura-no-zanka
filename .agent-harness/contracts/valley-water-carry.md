# 水運びと谷の風景の工程契約

目的は既存v16で一周する水運びと、奥行き・自然光・動きのある3D風景を実現すること。
変更範囲はこのプロジェクトの仕様、実行ソース、必要な検証、非公開Git運用。
戦闘、人物、拡張マップ、バックエンド、公開デプロイは対象外。

成功は`.kiro/specs/valley-water-carry/requirements.md`と引き継ぎの受入一覧に照合する。
Nodeテスト・配布検査・HTTP、実ブラウザ一周、保存復帰、入力、画面3幅を確認する。
実装と別の読取レビュー、体験評価と画面評価を行い、指摘を再現して採否を決める。
改善は最大3周。同一失敗2周は残件として報告する。

依頼者はSDD、非公開リポジトリ作成、commit・push・PR・mergeを明示的に許可した。
公開、秘密情報送信、課金、重要データ削除は許可に含めない。
