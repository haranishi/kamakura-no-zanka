# 既存の実行方式を継承する

ビルド不要のJavaScript ES Modulesと同梱Three.js 0.180.0を使う。
Node.js 18以上の標準機能で起動・単体検証・配信検査を行う。
`dist/` が編集対象であり、元のGLBと衝突データは保持する。

- 依存追加・フレームワーク移行は行わない。
- 状態と保存の検証はDOM・描画から分離する。
- WebGL2が必要。外部CDN、ログイン、バックエンドは使用しない。
- 品質設定、停止時描画抑制、稲インスタンシングを維持する。
- 進行と表示・音設定の保存キーを分ける。
- QA機能は`?qa=1`のみ。QA操作による成功と通常操作の成功を区別する。
