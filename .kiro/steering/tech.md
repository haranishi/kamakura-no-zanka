# 既存の実行方式を継承する

ビルド不要のJavaScript ES Modulesと同梱Three.js 0.180.0を使う。Node.js 18以上の標準機能で起動・単体検証・配信検査を行う。

- npm依存の追加・フレームワーク移行は行わない。同じ版のThree.js付属ファイル（SkeletonUtils等）の同梱は可。ライセンスを `licenses/` に残す。
- 縦切りの純粋ロジックは Three.js・DOM・Math.random・Date.now を使わず、Nodeで検査する。
- WebGL2が必要。外部CDN・ログイン・バックエンドは使用しない。品質設定（標準／軽量）と「動きを減らす」を維持する。
- 保存キーは庭と縦切りで分ける。QA機能は `?qa=1` のみ。QA操作による成功と通常操作の成功を区別する。
- 素材加工は Blender 5.2系のCLI（`--background`）。人物は Meshy → Blender で骨へ動作を焼いたGLBを使う。
- 外部素材はCC0か本人制作に限り、出所・作者・日付・ハッシュを記録する。外部の参照プロジェクト（閲覧と手元実行だけを許す規約）のコード・数値・素材は持ち込まない。
