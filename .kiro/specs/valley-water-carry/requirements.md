# Requirements: 隠れ谷で水を運ぶ

## Introduction
初めて遊ぶ人が、庭を歩き、桶を拾い、井戸で水をくみ、庭へ届けられる。
根拠は引き継ぎdocs/01〜05と、今回のグラフィック向上・非公開Git運用の依頼。

## Boundary Context
対象は既存の庭と道。戦闘、人物、室内、広いマップ、クラウド保存、Web公開は含めない。
風景の背景表現を追加しても、歩ける範囲と既存の障害物は維持する。

## Requirements

### Requirement 1: 目的を持って一周できる
**Objective:** 初回プレイヤーとして、暮らしを助ける短い行動を完了したい。

1.1 庭へ入ったとき、本作は最初の目的と操作方法を表示する。
1.2 対象の桶へ近づいて操作したとき、本作は空桶の所持へ一度だけ移行する。
1.3 空桶を持って井戸を操作したとき、本作は水入りの所持へ移行する。
1.4 水入りを指定の庭へ届けたとき、本作は所持を解除し、完了を伝える。
1.5 完了したとき、本作は散策の継続と再挑戦を可能にする。

### Requirement 2: 届く対象にだけ操作できる
**Objective:** プレイヤーとして、予告どおりに手が届くものを操作したい。

2.1 操作するとき、本作は身体からの水平距離・向き・遮蔽を再確認して一対象を選ぶ。
2.2 遠い・背後・遮られた対象や不正な順序を操作した場合、本作は進行を変えない。
2.3 長押しや連打をした場合、本作は一入力一遷移を守り、表示と保存を重複させない。
2.4 桶を拾う・満たす・届ける・復元するとき、本作は全39部品と水面を状態に同期する。

### Requirement 3: 中断後も続けられる
**Objective:** プレイヤーとして、安全に止めて、進行を失わずに再開したい。

3.1 メニュー・タイトル・読み込み・エラー中や画面離脱時、本作は移動・対話・音を停止する。
3.2 再開したとき、本作は押しっぱなし入力を解除し、現在の所持と目的を復元する。
3.3 進行が変わったとき、本作は表示設定と分けて進行を保存し、再読込から続けられる。
3.4 保存が壊れている・未知の版である場合、本作は安全な初期状態と復帰案内を示す。
3.5 保存できない場合、本作は理由を通知し、セッション内の遊びを継続できる。
3.6 出発点へ戻るとき、本作は進行を維持する。最初からやり直すときは確認を挟み設定を保持する。

### Requirement 4: 入力と音で迷わない
**Objective:** キーボードまたはタッチの利用者として、同じ遊びに到達したい。

4.1 遊んでいる間、本作は現在の目的・一枠の所持・必要な操作予告を読みやすく示す。
4.2 タッチ操作のとき、本作は移動・見回し・対話・メニューを同じゲーム処理へ接続する。
4.3 設定へ入力している間、本作はゲーム操作を発火させない。
4.4 HUDを隠したときも、本作は対話と再表示・メニューへの経路を維持する。
4.5 音を鳴らすとき、本作は明示的なユーザー操作後に開始し、ミュートを保存する。
4.6 390・768・1440px幅で表示するとき、本作は横はみ出しを起こさず、主要操作とフォーカスを見せる。

### Requirement 5: 谷の空気と生活感が伝わる
**Objective:** プレイヤーとして、自然光のある奥行き豊かな谷を歩きたい。

5.1 風景を表示するとき、本作は空から霧、距離のある山並み・木立を連続した色調で表現する。
5.2 標準品質で表示するとき、本作は斜光と影、動く水面、風に揺れる稲・草を表現する。
5.3 軽量品質や動きを抑える設定のとき、本作は装飾負荷・動きを抑え、遊びを維持する。
5.4 風景を拡張するとき、本作は元モデル、稲の共有描画、地形・衝突、庭への安全な連続経路を維持する。

### Requirement 6: 検証と非公開での引き渡し
**Objective:** 依頼者として、仕様・実装・確認結果を非公開で追跡したい。

6.1 変更を提出するとき、開発工程は既存検証と新しい重要規則・実ブラウザ操作の証拠を記録する。
6.2 GitHubへ反映するとき、開発工程は非公開リポジトリで小刻みにコミットし、PRを作成してマージする。
6.3 性能や互換性を報告するとき、開発工程は測定した環境と未確認の実機・ブラウザを区別する。
