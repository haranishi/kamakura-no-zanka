# Design: 押し戻しと、とどめ・弾きのスロー（8.4a・8.5a）

本人の評価「斬っても当たった感じが弱い」への手当てで、規則に触れる2つ（R18.12・2026-10-30に本人が「どちらも入れる」を選んだ）。
8.3a（`design-combat-trail.md`）の軌跡・踏み込み・火花の上に足す。時間割・ダメージ・構え・間合い・無敵・連続入力の数値は変えない。
要件は requirements-polish3.md の R18.4・R18.5・R18.12、上位の設計は design-combat-presentation.md、タスクは tasks-polish3.md の 8.4a・8.5a。数値は M4 Pro・Chrome・seed 1333 の実測。

## 論理と見た目の分け方

| 層 | 置き場所 | 変えるもの |
| --- | --- | --- |
| 論理（規則に触れる） | `knockback.js`（純粋）・`actors.js` の `updateKnock` | 当たった敵の論理の位置（当たり・AI・カメラが読む実座標） |
| 論理（規則に触れる） | `time-warp.js`（純粋）・`game.js` の `update` | ゲームの時間の進み（全員の動き・技の経過・タイマー） |
| 見た目だけ | `actors.js` の被弾の動作 | 敵の被弾の動作を1種へ（下の「ついでに直したこと」） |

結線は `battle.js` の `onStrike` だけ。主人公の刀の「当たり」で押し、主人公の「弾き」と「とどめの当たり」でスローを頼む。

## 押し戻し（8.4a）

- 量：0.2m。強い技（三段目・強斬り・反撃・とどめ）は0.25m。侍大将（重い鎧）は半分（0.1m・0.125m）。鎧でひるまない規則（R18.4）に合わせ、押されにくく見せる。
- 向き：攻め手の論理の位置から受け手への水平の向き。時間：ゲームの0.14秒で、始めが速い曲線（1−(1−u)²）。命中の停止の間はゲームの時間がほぼ止まるので、押すのは停止が明けてから。
- 対象：主人公の刀が当たった敵だけ（倒れた体も押す）。受け・弾き・闇討ち・矢・敵の刀は押さない。主人公も押されない（操作が乱れない）。
- めり込み：壁・水・段差・上りの急な斜面は、論理の移動と同じ `moveActor` の規則で止める。下りも、歩ける46度より急な所へは押さない（ふつうの歩きは56度まで降りられる）。
  ほかの人（主人公・敵・休んでいる敵・仲間・村人）へは中心0.72m（人どうしの押し分けと同じ値）より近づけず、押された人だけ止める。止められたら残りは捨てる。

## スロー（8.5a）

- きっかけ：主人公の弾きの成功と、とどめの当たりの瞬間。普通の当たり・受け・敵の技では出ない。
- 形：命中の停止（弾き0.09秒・とどめ0.10秒・0.05倍。揺れ0では前から半分）が明けてから、実時間0.25秒。始めの55%は0.3倍、残りで1倍へ滑らかに戻す。
  0.25秒の間にゲームは約0.11秒進む（約0.14秒の遅れ）。停止とスローは掛け算しない（停止の間はスローの残りを減らさない）。
- 「画面の揺れ・衝撃 0」「動きを減らす」でも、長さを変えない（揺れでも光でもない）。光・明滅・画面の色は足さない。音の速さは変えない。

## 捨てた案と理由

| 案 | 捨てた理由 |
| --- | --- |
| 当たった瞬間に0.2m移す | 1コマで跳んで見える。停止のあと、曲線で押す |
| 停止の間に押す | 止まった絵の中で敵だけが滑る。停止が明けてから押す |
| 停止とスローを掛け算する | 0.015倍で、止まったまま長く感じた。「ヒットストップと二重に掛けない」（本人の指定） |
| スローを揺れの設定で短くする | 揺れではない。本人の指定で「揺れ0・動きを減らす」でも有効 |
| すべての当たりにスロー | 本人の指定は、とどめと弾きだけ。普通の当たりは停止だけで、連打のリズムを保つ |
| 押された人が、ほかの人を押していく | 人の押し分けが壁際で重なり、ほかの人が壁へ入る。押された人だけ止める |
| 受け・矢でも押す | 受けは手応えの種類が違う（8.3a の火花と反動で分ける）。仲間の矢で押すと、敵が主人公から離れていく |
| 侍大将も0.2m | 重い鎧の侍大将が兵と同じに弾かれ、鎧でひるまない規則と食い違って見える |

## ついでに直したこと

- とどめの詰め：崩れた敵の前1.35mへ詰め終えたかを、ちょうどの値で比べていた。丸めで1.3500000000000003mになると、0mずつ詰め続けて、とどめが出なかった。1mmの幅で比べる。
- 被弾の動作（見た目だけ）：敵の被弾を Hit_Reaction_1 の1種にした。ほかの2種は、刀を持った腕が横へ80〜100度跳ね上がり、両腕を水平に広げた棒立ち（T字）に見えた。共用の乱数は前と同じ回数だけ引く。
- 押される間の動作（見た目だけ・第2周）：鎧でひるまない一・二発目は、論理は待機のままなので、構えた姿で0.2m滑って見えた（別役の採点）。待機中の兵と弓兵には、押される0.3秒だけ同じ被弾の動作を見せる。技・受けの最中は替えない（予兆を隠さない）。侍大将は上体のしなりだけ。
- とどめで倒れる動作（見た目だけ・第2周）：膝をついた相手が、刺されたあと背筋を伸ばして刀を立て直してから崩れ、とどめが効いていないように見えた。とどめで倒れたときだけ、倒れる動作の始めの立ち姿を飛ばす（dying_backwards は0.6秒から）。

## 契約（合否）と実測

| 項目 | 合格の条件 | 実測 |
| --- | --- | --- |
| 押す距離 | 兵 弱0.2m・強0.25m、侍大将 0.1m・0.125m（±0.01）、横ずれなし | 0.2・0.25・0.1・0.125m、横0 |
| 三連の間合い | 相手まで1.2・1.6・2.0・2.15m（端）で、3発とも当たる | 4距離すべて3発。三段目の時の距離は0.72・0.72・0.82・0.97m |
| 壁 | 背を壁に付けた相手が、当たりの箱へ入らない | 入り0m（動いた量0.7mm） |
| 崖 | 押す向きの、46度より急な下りの手前で止まる | 出られる0.146mに対し+0.008m（歩きなら0.488mまで降りる場所） |
| ほかの人 | 中心0.72m以上、ほかの人は動かない | 最小0.72m、押された量0.13m、ほかの人0m |
| スロー | 弾き・とどめで、停止のあとに15コマ（0.25秒）、最も遅い0.3倍、停止×スローなし。普通の当たりは0コマ | 弾き 停止6・スロー15、とどめ 停止7・スロー15、弱 停止5・スロー0 |
| 揺れ0・動きを減らす | スローの長さと押す距離は同じ | スロー15コマ（停止は3コマ）、押す0.2m |

純粋な部分の試験は7件（`tests/valley-impact.test.mjs`）、変異試験は19件すべて検出（`tools/verify-impact-mutations.mjs`）。実ゲームは `tools/scenarios/regress-impact.mjs`（記録は `reports/polish3/combat-impact/`）。

## 論理と難度への影響（R18.12の測り方）

- `regress-attack-timing.mjs` に `KZ_IMPACT`（off・knock・slow・on）を足した。off は変更前（feat/polish3-combat-trail）と全コマ一致（斥候320・侍大将520）。
- 斥候（弾き・とどめなし）：攻撃の開始コマ・技・相手の技・体力は変更前と同じ。位置だけ、押し戻しの分ずれる（相手最大0.47m・主人公0.23m）。
- 侍大将：押し戻しだけなら、開始コマ・技・体力は同じ（位置のずれ0.045m）。スローを入れると、38コマ目の弾きの後、ゲームの時間が約8コマ遅れ、
  決まったコマに置いた入力が別の場面に当たる。侍大将の技はゲームの時間では同じ間隔で、画面のコマでは9〜10コマ後ろへずれる。
- 難度（同じ操作の手で4回ずつ）：`reports/polish3/combat-impact/README.md` の表。

## 盲検採点と残った弱点

別役（Opus・画像だけ）の盲検採点の第2周で、三連・とどめの手応え・押し戻し・迫力は変更前3〜4点→変更後6点、弾きの間と迫力は5→6点。7点に届いた項目はない。
姿勢（腕が水平に広がる・頭上へ跳ね上がる）は2周とも4点で止めた。点と、弾かれた相手が下がらない・案内が2つ同時に出る件は `reports/polish3/combat-impact/README.md`。
