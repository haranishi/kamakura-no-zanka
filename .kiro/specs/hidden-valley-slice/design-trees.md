# Design: 木（R14.4・R14.5、タスク7.9）
木の形・色・距離表現の判断を残す。草と林床は [design-vegetation.md](design-vegetation.md)、要件は [requirements-polish.md](requirements-polish.md)。数値は2026-10-28の現行設定・試験と照合した。

## 見立て（2026-10-28、修正前の測定と固定画角）
- 木は1パス130〜144万三角形。最大は杉の中景（80〜220m、498三角形×約1,600本で64〜84万）、次いで近景の杉10〜38万、遠景の杉約29万。広葉と松は合わせて5%未満だった。
- 80m内の近景は100〜300本だけ。画面の出来には、中景・遠景の形と色の変化が大きく効く。この80mは旧LODで、現行の境界ではない。
- 広葉は暗く平らで幹の頭が切れ、杉の内側には黒い穴が見えた。遠景は一色の円錐が並び、全体の広葉1.63%では紅葉が固定画角にほぼ出なかった。
- 今回は近景の豪華さより、群れの色・丸い輪郭・黒い穴の解消を優先する。形と比率の合格だけで、見た目の改善とは判定しない。

## 判断と捨てた案
| 判断 | 理由 | 捨てた案と理由 |
|---|---|---|
| 樹種は `species` という派生の層にする | 既存の座標・当たり・配置の再現を守る | `kind` の追加：配置と当たりの前提が崩れる |
| 杉を広葉へ読み替える場所と色づきを、群れの場で決める | 谷底・川沿い・里の縁にまとまりを作り、深い山腹には杉を残す | 一本ごとの一様乱数：紙吹雪に見える |
| 遠景は葉を描かず、樹冠の塊と平均色で見せる | 色の斑を遠くまで残し、輪郭に予算を使う | 遠景にも葉カード：全体の三角形が増えすぎる。広葉の単一殻：輪郭が単調 |
| 広葉の樹冠は小さな葉の絵を繰り返す「葉の玉」、芯は幹側のメッシュ | 丸い光と陰を作り、抜けから見える芯に質感を貼らずに済む | 広葉カードの追加：平たい紙の束。円盤の葉の絵：コイン。不透明の予約領域：格子の四角 |
| 丸さは縦方向の帯も増やして作る | 横の辺数だけ増やしても側面の角は消えない | 殻の3帯：広葉の中遠景が六角形になる |
| 針のフリンジは緑で描く | 杉の暗い塊を保ちながら、枝先を抜く | 灰色のフリンジ：雪をかぶったように白くなる |
| 若木・灌木は独立した乱数系列で足し、当たりを付けない | 道と里の縁に低い帯を作り、到達格子と既存の当たりを守る | 当たり付き：通路を塞ぎ、到達検査が揺れる |
| 成木LODは3段。奥の段は境の手前 [a−2w, a] で入り、手前の段は [a, a+2w] で出る。境では両方が重み1 | どの距離でも一方は不透明で、背景が点で透けない | 相補ディザ（手前を n<w、奥を n≥1−w）：手前の隙間に奥の段が1画素の点で出て、杉の全面が点描になった。段ごとの即時切替：飛び出す。頂点モーフ：形が違いすぎる |
| 標準品質の溶かしは、MSAAのアルファ→カバレッジ（アルファテストの後に重みを掛ける）。軽量（MSAAなし）は1画素のディザ | 4サンプルの被覆で滑らかに混ざる | 標準でも `discard`：1画素の点が目立つ |
| 広葉は、描かれる本数が少ない近景・中景の三角形を厚くし、遠景（約1,300本）は絞る | 広葉は全体の約1割でも、遠景に集まる。遠景を368三角形にすると+30万で旧上限を超えた | 全段を均等に細分化：総量が旧の1パスを超える |
| 杉の形は5つ（既存3つ＋細長い・乱れた）で、個体の `tint` から決める。輪郭は位置から決める揺らぎをシェーダーで足す | 約8割を占める杉が、山腹で同じ円錐の複製に見えるのを減らす | 形を1種のまま拡縮だけ：評価で「同じ形の繰り返し」と指摘された |
| 質感は手続きだけにする | 外部画像を増やさず、質感の容量枠を林床へ残す | 樹皮・葉の写真：出所管理と容量が増える |
| 近景を軽くし、樹種の差と若木・灌木へ回す | 全体の描画予算を守る | 近景だけの増量：中遠景の単調さが残り、総量も増える |

決定（2026-10-27）：楓の彩度は低め。鮮やかな案は採らず、企画の「絵画的」と夕景の折り合いをプレイで確かめる。
風は草と向き・突風を共有し、樹冠のゆっくりした揺れと葉先の震えを重ねる。逆光の透けは距離で弱め、白い点にしない。後処理で近景の粗さを隠す案は採らない。

## 数値の目標と実測
- 距離は地面上で測る。標準の境界 a は48・150m、半幅 w は4m（軽量は32・100m・3m）。奥の段は [a−2w, a]、手前の段は [a, a+2w] で重みが動く。軽量の遠景は半数に間引く。
- 若木／灌木は18／13mで段を切り替え（溶かさない）、外縁45／32m（軽量30／22m）では根元へ縮んで消える。若木・灌木にL2は作らない。
- 到達格子の母数645本は不変。杉以外は旧24.96%→38.14%、広葉は13.18%→26.36%。要件下限25%／10%に対し、試験は30%／15%以上、4種以上、欅・楓それぞれ4%以上を守る。
- 全体15,830本の広葉は1.63%→9.61%。設計の狙いは6〜10%、試験の許容範囲は5〜12%。比率の母数に若木・灌木を混ぜない。
- 到達木の25m内最近傍で、同種率64.81%（固定seedで並べ替えた対照41.86%）、色段階差23.73（対照71.38、255段階）。色を共有する場は30mで、独立した個体差は小さく保つ。
- 若木709本・灌木2,134本。上限は1,200／4,000本。水・道・建物・畑・小道具・岩・幹・急斜面・頂を避け、若木は見通しも塞がない。
- 木は固定4地点とも旧の1パス未満、目標は1.30M以下。現行試験の実数は下表で、溶かしの重複と若木・灌木を含む。影など別パスを含むブラウザの全体値とは分ける。

## 再発させない落とし穴
1. 葉の絵に大きな不透明の円盤を描くと、樹冠がコインの貼り合わせに見える。小さな葉の和集合にする。
2. 殻の帯が3つだと、横の辺数に関わらず側面が六角形になる。広葉の中遠景は4帯以上にし、頂点の半径に低〜高周波のノイズを足して丸い球に戻さない。
3. 針の絵を灰色にすると、杉が雪をかぶったように白くなる。緑で描く。
4. 繰り返す絵に不透明の予約領域を置くと、格子状の四角が出る。芯は質感のない幹側のメッシュへ移す。
5. 継ぎ目をまたぐ葉は反対側にも描く。繰り返したときの隙間を単体の絵だけで判断しない。
6. 杉の芯の円錐は底を塞ぎ、色は針の平均に近づける。底が開く・色が黒に近いと、枝の隙間から大きな黒い面が見える。
7. 標本は地面の稲や岩の陰を避けた平らな場所で撮る。地面の混入を樹形の欠点と取り違えない。
8. 溶かしの相補ディザは、手前の段に隙間があると奥の段が1画素の点として出る。穴の出ない重ね方にし、標準品質はMSAAのカバレッジ、軽量だけディザにする。
9. 球殻のUVを円筒写像にすると、塊の頂部で葉の絵が放射状に伸びる。面ごとの箱投影にし、塊ごとに回転とずらしを掛ける。
10. 広葉は遠景に約1,300本いる。遠景の1本を増やす前に、距離帯ごとの描画本数を数えてから予算を配る。
11. 作業が途中で止まったとき、終了コードだけで失敗とみなさない。作業ツリーとテストで確かめる。

## 検証と現在地
- Node：既存配置・当たり不変、再現性、到達比率、群れと色段階、禁止域、形状・法線・予算、LODの重み（どの距離でも最大が1）を検査する。`tests/valley-tree-*.test.mjs` と `tools/measure-trees.mjs --species --json` が照合先。変異検査は `tools/verify-tree-{geometry,view,field,species}-mutations.mjs`。
- ブラウザ：固定13画角の前後、`capture-tree-specimens.mjs` の順光・逆光標本、`capture-tree-lod.mjs` の近づき撮影、性能と軽量、`regress-tree-quality-switch.mjs`（品質を4往復してもGPU資源が増えない）、`regress-tree-reduced-motion.mjs`（動きを減らす設定で木の揺れが通常の約1割）。
- 独立評価（別役Opusの盲検A/B・8場面・3周で上限）：新旧の総平均は 4.7対3.5 → 4.93対2.63 → 5.1対3.1。8場面すべてで新が上。7に届いた項目は立体感の2場面のみ。3周で止めた。
- 残る欠点（評価者の指摘）：中遠景の形（平均4.0）に、広葉の多面体・段の針葉樹の繰り返し（モミやトウヒの形で杉に見えない）・近景の杉の葉が板状。標準の溶かしの細かい網目。紅葉が橙一色の群れ。7.12の正式評価で再採点する。
- 人の目：紅葉と夕景の調和、遠景の斑が水玉に見えないか、LODのちらつき（動画）は未確認。本人の確認待ち。7.9のチェックは未完了のままにする。
