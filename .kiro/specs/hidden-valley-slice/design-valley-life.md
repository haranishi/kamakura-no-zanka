## 結論

谷の物語は、台詞を足すより**物の置き方で語らせる**のがいちばん効く。最初の一手は、垂直スライスの2か所（見晴らし岩・里の入口）に「兵が蔵の米を運び出し、兵自身も腹を空かせている」場面を作ることだ。その前に下ごしらえがある。いまの柵・薪・置き物・農家を「同じ形はまとめて1回で描く」作り（以下、まとめ描き）へ直す。狙いは描画の余白だ。いまの置き物だけで、1コマの描画の呼び出し（絵を描く命令の回数）を最大およそ400回使っている。上限は900回。まとめれば60回前後に減る見込みなので、物を足す余裕ができる。

物語の仕掛けは次の6つに絞った。

1. 本物の石段：オープニングの「燃える寺を石段の下から見上げる」場面と、谷の廃寺の石段を重ねる。いまの谷には石段の形が無く、足音だけが石になる。
2. 門の跡：廃寺の出口に門の礎石だけを残し、謎の核「門を離れた夜」を言葉を使わずに置く。
3. 灯：結末で廃寺の灯籠に火が入り、帰り道では石段の灯籠が灯る（滅びの火から、守る灯へ）。
4. 俵の列と空の鍋：新しい政権の米の取り立て（徴発）と、兵の飢えを絵で見せる。
5. 結果が見える：救ったあとに張り直される村境の縄、選んだ道で変わる荒れ方、結末で見える米の量。
6. 掛け合いの引き金：石段脇の地蔵と、待ち伏せの前に飛び立つ鳥。

本人への3つの質問（§5）と作業の順番（§4）は、冒頭の承認で決まった。残る未確認は §7 の5点で、S7-A の着手前に確かめる。

## 4. 順番と範囲：まず2か所で、3つの項目の7点を狙う

順番は S7-0（まとめ描きと状態の層）→ A（見晴らし岩・里の入口）→ 本人の確認 → B（里の中・弥十郎）→ C（廃寺・石段・帰り道）→ S8（体験の評価）とする。A で作る小物の型・まとめ描き・状態の層・配置の表を B と C で使い回し、仕組みは増やさずに配置と状態のつなぎだけを足す。

A の合格の線は次のとおり（案）。

- 撮る物：固定画角 08（見晴らし岩から里）・09（里の入口）・19（荷車と幟）に2枚を足す。1枚は入口の野営の寄り、もう1枚は見1の立ち位置から景継越しに見る里で、design-validation-polish3.md の E1 を兼ねる。加えて、見晴らし岩から里の入口まで歩く動画を1本。
- 7点を狙う項目：密度とばらつき（17.5）・二次運動（17.6）・形と3層（17.2。里の中景に限る）。
- 残りの5項目（色・絵肌・光と空気・人物・仕上げ）は、木（8.1a）と人物（8.6）の仕事になる。S7 は「前より下げない」を条件にする。木の第2周の盲検はどの項目も7点未満だったので、2か所の全8項目がそろって7点に届くかは 8.1 との合わせ技になる。
- 物語の読み取り（採点とは別の案）：別役に新旧を伏せた画像を見せ、「ここで何が起きているか」を1文ずつ書かせる。入口なら「兵が蔵の米を運び出している」「兵も腹を空かせている」「里の守りが破られた」のうち2つ、見晴らし岩なら「敵のいる場所」「三つの道の違い」の2つが出れば合格とする。
- 周回は最大3周で、1周に渡す画像は8組まで。同じ失敗が2周続いたら本人に返す。最後は本人が画面と実際のプレイで確かめる。

**仕様の依存を一部前倒しする（承認が要る）。** tasks-story.md では S7 は S4 と 8.7 のあとになっている。A だけを先に進める案だ。A は 8.1 の垂直スライスと同じ2か所なので、「方向の確認より前に全体へ広げない」という 8.1 の関門の内側に収まる。B と C は、依存どおり本人の方向の確認のあとに置く。

新しい小物の型は、Drive の v02 の小道具（橋・柵・薪）と同じ作り方にする。Blender の手順書きで形を組み、絵も手順で描くので、出所が自分の手元で閉じる。Meshy は1個が約1MBで三角形も多い（7千〜1万5千）ため、小物には向かない。配置は既存の試験（道を通して歩ける、敵が逃げ道へ出られる、救った人が戸口から持ち場へ歩ける、置き物が道に立たない、行き止まりが無い）をそのまま通す。膝より高い物（俵・桶・臼・甕・杭）にだけ当たりを付け、平たい物（筵・こぼれた米・道具）には付けない。戦いの場の真ん中には背の高い物を置かず、家の壁際と荷車の周りへ寄せる。S7-0 では模型を読み込む関数の戻り値を変えない。オープニングが同じ模型を使い回しているからだ。

## 7. やらないことと、未確認のこと

やらないことは、戦闘の規則（combat.js）の変更、新しい動作、外部の素材の持ち込み、谷の外（橋・関所・山砦）の作り込み、地形の高さの変更、台詞の本文を書くこと。地形の高さを変えると、当たりと配置の試験がすべてずれる。台詞は S5・S6 の持ち物なので、案を渡すだけにとどめる。

未確認なのは5点ある。全部入りのビルドの性能、木の第3周での見た目（今回見た画像は第1周のあと）、蔵の模型の戸口の向き、Safari・Firefox・実機での表示、小物と習わし（縄・地蔵・板碑・干し柿・曲物・箕・背負子・瓢箪）が1333年の信濃の山里に合うかどうか。最後の点は、S7-A の着手前に一覧で裏取りする（Codex が上限切れなら Opus に頼む）。
