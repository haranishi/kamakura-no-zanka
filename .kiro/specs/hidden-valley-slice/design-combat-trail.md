# Design: 刃の軌跡と、当たりを「刃が体を通るコマ」に合わせる（8.3a）

本人の評価（2026-10-30「戦闘シーンに迫力がない」）への手当て。第1周で振りの向きは読めるようになった。第2周で、停止と火花の来る時刻を「刃が胴の高さを通るコマ」（接触）へ合わせた。
第3周（2026-10-31）は、間合いの距離では刃がそもそも胴に届かない（0.24〜1.56m足りない）問題を、見た目だけの踏み込みで解いた。あわせて、火花を白い煙の玉から線状の筋へ替えた。
変えたのは表示だけで、`combat.js` の規則・入力・停止の長さ・時間の進み・論理の位置（実座標）・音はそのまま（R18.9）。論理は main と一致した（斥候320コマ・侍大将520コマ）。
要件は requirements-polish3.md の R18.2〜18.5・18.9、上位の設計は design-combat-presentation.md、タスクは tasks-polish3.md の 8.3a。数値は M4 Pro・Chrome・seed 1333 の実測。

## 接触時刻（第2周）：刃が胴の高さを通って、胴の点へ最も近づく時刻

刃の中ほど〜切先（刀の枠の y=0.52〜0.88m）が、間合いの距離に置いた点（地面から1.1m）へ最も近づく時刻。点に最も近い刃の点が1.1±0.35mのサンプルに限る（袈裟は頭上で正面を横切るので、絞らないと頭上を選ぶ）。実測は `measure-combat-trail.mjs` の contact。
`anim-data.js` の `MOVE_CONTACT`・`contactSegment` が、技の開始からの秒を動作の秒へ写す折れ線を作り、接触を判定の始めへ置く。動作は論理の技の経過で進める（`characters.js` の `followWarp`）。
三段目だけは第3周で接触を 0.609→0.645 へ遅らせた。0.609 では刃が頭の高さ（1.44m）で止まり「振りかぶったまま」に見えた。0.645 で肩の高さ（1.14〜1.25m）。速さは1.8倍以下、使用割合は0.527で前と同じ。

## 第3周の実測：刃は前に届かず、横へ流れていた

- 判定の始めの刃は、体から前へ0.3〜1.2mにしかない。しかも多くの技で横へ流れている。袈裟は止まるコマで左へ約60度、三段目は約50度、強斬りは約40度、反撃は右へ約50〜75度。前へ出すだけでは横を通る。
- 当たりと停止は「判定の始めを越えた最初のコマ」で起きる。60コマ/秒では判定の始めの最大1コマ後になり、そのあいだに刃が大きく動く。袈裟は1コマで刃が1.44m→1.1mへ下がり、さらに左へ流れる。
- 人物の胴は腰0.79m〜肩1.15m（胸の骨 Spine02 は0.87m）。接触の点（1.1m）は肩の線で、刃の1.44mは頭の高さだった。

## 採った方式（第3周）

- 見た目だけの踏み込み（`lunge.js`・`actors.js`）：論理の位置・向きは変えず、模型の根だけを、振りの間、相手へ出して回す。
  - 表 `CONTACT_POSE` に、技ごとの判定の始めと1コマ後の刃の姿勢（攻め手の局所）を置く（`measure-combat-trail.mjs` の pose・pose2）。
  - 止まるコマ（判定の始めを越える最初のコマ）を毎コマ見込み、その姿勢の刃の5点から1点を選ぶ。選ぶ基準は、高さが0.6〜1.65m、回す角が小さい、前進が小さい。
  - その点が相手の胴の軸の0.1m奥を通る量を出す。回す角は60度まで、前進は−0.3〜0.9m。受けている相手には、胴の0.45m手前（刀の所）で止める。
- 時間の配り方：予備の間に曲線（smoothstep）で寄せ、判定の始めでちょうど着く。途中で相手が動けば残りの差を詰め直す。判定の間はそのまま。判定の終わりから0.3秒（戻りの7割まで）で元へ戻る。技が中断されたら毎秒14の速さで戻る。
- めり込み：論理の間合い・弧の外の相手には踏み込まない（当たらない振りで胴へ入れない）。見た目の中心どうしは0.55m以上（相手もそばの人も）。
  - 壁・急な斜面は、技の始めに論理の移動と同じ規則で、前後へまっすぐ出られる長さを0.1m刻みで測り、その内に収める。根の高さは地面の傾きに沿わせる（±0.25m）。
  - 足音・カメラ・影の追従・当たりの判定は論理の位置のまま。共用の乱数は使わない。
- 火花（`spark-streaks.js`・`fx.js`・`clash.js` の `entryPoint`）：刃が胴まで届いたら、火花は刃が胴の表面へ入る点（手元からたどる）に置く。胴の中の点だと体に埋もれて見えなかった。
  - 粒を、速度の向きへ伸びる短い筋（明るい芯→橙の尾）にした。大きな柔らかい光（0.38〜0.75）は、小さく短い芯（0.14〜0.24）にした。
  - 筋は当たり1回で9〜14本、弾き22本。前の粒は10〜18個・22個。8割は刃の進む向きの円錐へ飛ぶ。メッシュは1つ（加算）で、筋がある間だけ描く。

## 捨てた案と理由

| 案 | 捨てた理由 |
| --- | --- |
| 前へ出すだけ（回さない） | 刃が横へ流れる技（袈裟・三段目・強斬り・反撃・侍大将）は、胴の横を通る |
| 横へずらして刃へ合わせる | 横滑りに見える。前進と回すことで、根のずれは相手への向きだけにした |
| 判定の始めの姿勢（1コマ後を見ない）で合わせる | 60コマ/秒の停止は最大1コマ後。袈裟の刃が0.3m下がり、10度左へ流れて外れた |
| 回す角の上限50度 | 袈裟は止まるコマで約60度左。50度では胴の縁（0.2m）を通るだけ |
| 前に出られる長さを1回の移動で測る | 壁へ斜めに向かうと、壁に沿って滑った分を出られる長さに数え、根が壁へ0.18m入った |
| 火花を刃と胴の最も近い点（胴の中）に置く | 体に埋もれて見えない（第2周の点は刃が届かないので表面にあった） |
| 数を引数・物の欄・戻り値で渡す | 呼ぶたびに数の箱が作られた（45〜186B/コマ）。1つの Float64Array で受け渡す |
| （第2周）高さを問わない接触・技を出す距離で測る・3区間を遅くする・照り返しだけ下げる・弾きに既存の受けの動作・加算の帯 | 頭上を選ぶ／技ごとに違う／振りが遅くなる／にじみが残る／刀が後ろを向く／白飛び |

## 契約（合否）

| 項目 | 合格の条件 | 実測（第3周） |
| --- | --- | --- |
| 刃が胴に入る | 停止のコマで、刃（中ほど〜切先）と胴の軸（Spine02±0.28m）の距離が0.22m以下（11技×相手まで1.2m・1.6m・間合いの端） | 33件すべて。最大0.195m（`regress-lunge-after3.json`） |
| 論理 | 同じ入力列で main と一致 | 斥候320コマ・侍大将520コマとも一致 |
| 前進・回す角 | 前進0.9m以下・見た目の中心どうし0.55m以上 | 前進最大0.9m・回す角最大60度・中心どうし最小0.553m |
| めり込み | 壁へ根が入らない／急な斜面の先へ出ない／そばの人へ0.55mより近づかない | 0m／0.24m手前で止まる／最小0.72m |
| 戻り | 技が終わって0.4秒で、根のずれ・向きのずれが0 | 0（33件） |
| 揺れ0・動きを減らす | 踏み込みは有効（揺れではない） | 前進0.82m |
| 火花 | 6割以上が刃の進む向き。芯の光1つと筋9〜14本 | 86〜100%。芯1・筋9〜14本。弾きは芯1＋筋22本 |
| 性能 | 描画呼出+2以内、三角形数千以内、毎コマの新規確保なし | +2（帯1・筋1）。筋は最大192三角形。0.56B/コマ（空の繰り返しと同じ） |

純粋な部分の試験は、踏み込み・筋・入る点で14件（新規確保の測りを含む）、帯・切り出し・幾何は前のまま。変異試験は新しく27件、前の49件とあわせてすべて検出。
実ブラウザの確かめは `regress-lunge.mjs`（踏み込み）と `regress-slash-trail.mjs`（帯・火花・弾き）。

## 未確認と次の候補

本人のプレイ、別役の盲検採点、Safari・Firefox・実機は未確認。回す角が大きい技（袈裟60度・反撃50度）は、体ごと回るので、見え方は本人の判断を待つ。上体だけをひねる案は試していない。
指示の3〜6（相手の反動とT字の棒立ち・帯の扇・弾きの動き・予兆の金色）は第3周では扱っていない。
踏み込みの結線（`actors.js`）の毎コマの確保は、ブラウザでは測っていない（純粋な部分だけ測った）。
