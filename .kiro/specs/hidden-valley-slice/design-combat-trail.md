# Design: 刃の軌跡と、当たりを「刃が体を通るコマ」に合わせる（8.3a）

本人の評価（2026-10-30「戦闘シーンに迫力がない」）への手当て。第1周で振りの向きは読めるようになったが、別役の採点（第2周の入力）では、帯が乳白の板・縦の柱に見え、停止と火花が「刃が届く前」に来ていた。
第2周は、当たりの基準を手首の速さの山から接触時刻へ替えた。帯・予兆・火花・ひるみ・弾きの見た目も作り直した。
結果、弓以外の11技すべてで接触が判定の始めから1ms以内に来る。変えたのは表示だけで、`combat.js` の規則・入力・停止の長さ・時間の進み・実座標（踏み込み・押し戻し）・音はそのまま（R18.9）。論理は main と一致した。
要件は requirements-polish3.md の R18.2〜18.5・18.9、上位の設計は design-combat-presentation.md、タスクは tasks-polish3.md の 8.3a。数値は M4 Pro・Chrome・seed 1333 の実測。

## 接触時刻：刃が胴の高さを通って、胴の点へ最も近づく時刻

接触時刻は、刃の中ほど〜切先（刀の枠の y=0.52〜0.88m）の線分が、相手の胴の点へ最も近づく時刻。相手は技の開始の位置から前へ間合い（`MOVES.reach`）の距離に置いた動かない点で、高さは地面から1.1m。とどめだけは、膝をついた相手の胸の骨（Spine02）を点にする。
ただし、線分の中で胴に最も近い点が胴の高さ±0.35mにあるサンプルに限る（無ければ高さを問わない）。袈裟（Katana_Kesa_Cut）は正面を頭の上（約2.0m）で横切ってから左の胴の高さへ降りる。高さで絞らないと、頭上のコマを「接触」と選んでしまう。
実測は `measure-combat-trail.mjs` の contact で行う。1/240秒刻みで進め、最も近いサンプルの前後3点の放物線で時刻を詰める。

## 実測：刃は胴に届かず、7技は当たりが判定より34〜100ms遅かった

- 第1周の時点で、接触と判定の始めの差は light1 +38・light2 +59・light3 +21・heavy +78・counter +34・finisher −7・soldier_slash +22・soldier_thrust +61・officer_a +23・officer_b +70・officer_c +100ms（`contact-before.json`）。
- 間合いの距離では、どの技も刃が胴の点に届かない。最短距離は0.24〜1.56m。振りは横へ大きく流れ、切先の前への届きは体から約0.8〜1.1mにとどまる。
- 動作は技を始めたコマに1コマ先へ進んでいた（60コマ/秒で17ms早い）。敵は個体差（0.94〜1.06倍）の分もずれる（斥候の袈裟で約±30msと見積もった。測ってはいない）。
- 帯は、外側半分が濃い幅広の帯で、停止のコマに残ると板に見えた。強斬りの縦の振りでは、戻りの間まで画面の上端から地面までの帯が残った。刃が自分の軸に沿って動くコマも濃く描いていた。
- 戻りの間の敵の刃の金色は、予兆ではなく、夕日の直射を映した鋼のにじみ（ブルーム）だった。照り返しの強さと粗さを下げても消えず、地の色を落とすと消えた。
- 一・二発目の無反応は、背骨のひるみが骨の局所の軸で回っていて、上体が相手の側へ曲がっていたため（頭が相手へ約0.1m寄る）。
- 火花は受けた人の胸の中心から放射状に出て、刃の無い側にも散った。弾きでは、主人公の受けの姿勢（Two_Handed_Parry）の刀が後ろを向き、刃同士が触れていなかった。

## 採った方式：動作の折れ線で接触を判定の始めへ置き、見た目を作り直す

- 接触を判定の始めへ（`anim-data.js` の `MOVE_CONTACT`・`contactSegment`・`moveSegment`）：技の開始からの秒を動作の秒へ写す折れ線を作る。
  - 予備から接触までを1つの速さで流せて、それが今の振りの速さ以上なら、from から手首の山の終わりまでをその速さで流す。上限1.8倍を超える技（light2・light3）だけ、動作の少し先から始める。
  - 間に合う技（突き・二段目・とどめ）は、振りの速さをそのままにして、予備だけをゆっくりにする。
  - 戻りは、使う長さを今より短くしない範囲で延ばす。
- 動作は論理の技の経過（`f.move.t`）で進める（`characters.js` の `followWarp`、`actors.js` が `warpClock` を渡す）。これで、技を始めたコマに動作が1コマ先へ出ることも、敵の個体差が当たりに掛かることもなくなった。
- 帯（`slash-trail.js`・`fx.js`）：切先の道に細く明るい芯を置き、内側へ素早く消す。新しい所ほど濃く、寿命は0.07〜0.11秒。
  - 出すのは接触の0.08秒前〜判定の終わりまで。戻りには足さず、閉じたら0.05秒で消す。
  - 幅は0.24m、長さは切先の道のりで0.8mまで（後ろ半分で薄れる）。濃さは刃に直交する速さで付け、軸に沿う動きは描かない。
  - 色は芯が白で尾が青白。三段目・強は尾に朱をさす。突きは、切先の前へ刃の軸の向きに短い光の線を出す（同じメッシュ）。
- 予兆と帯を分ける（`battle.js`）：予兆は金色で明滅し（0.34秒に約2.5回）、帯を出し始める所で止める。敵の刃は予兆の間だけ元の鋼にし、ほかは地の色を #9a9a9a へ落とす。
- 火花（`clash.js`・`fx.hit`）：相手の刃と、受けた人の胴の軸の最も近い所に置く。刃が胴から離れていれば、胴の表面の刃の側に置く。粒の8割は刃の進む向きの狭い円錐へ散らす。
- ひるみ（`characters.js` の `kick`）：世界の軸（上×押す向き）を親の向きで骨の局所へ直して回す。押す向きは、相手から自分への向きに刃の進む向きを35%混ぜる。強い技は1.25倍にする。
- 弾き（`sword-rig.js` の `clash`）：主人公の右手を伸ばし、刃を「相手の刃の上で右肩に最も近い点」へ通す。左手は柄頭へ添え、停止の間は保ち、0.2秒で元の動作へ戻す。火花は2本の刃の最も近い点に出す。

## 捨てた案と理由

| 案 | 捨てた理由 |
| --- | --- |
| 接触＝高さを問わない最も近い時刻 | 袈裟で頭上の横切りを選び、停止のコマの刃が頭の上のままになる |
| 接触を、敵の思考（enemy-ai.js）が技を出す距離（1.3〜2.3m）で測る | 指示どおり間合いの距離で測った。技を出す距離は技ごとに違い、間合いの距離では刃は胴に届かない |
| 振りの間だけ、人物の見た目の向きを回して刃を胴へ通す | 「再生区間と速さだけ」の範囲を超える。次の判断の候補として残す |
| 1つの速さのまま、使う区間を後ろへずらす | 予備の溜めが消え、戻りの端で使用割合が下がる |
| 3区間の技の振りを遅くして合わせる | 振りの速さそのものが落ちる |
| 敵の刃の照り返しの強さ・粗さだけを下げる | 夕日の直射の光沢が残り、にじみが消えなかった |
| 弾きに既存のクリップ（Katana_Parry・Two_Handed_Parry）を流す | 刀が頭上から後ろへ回り、前から来る刃に触れない |
| 加算合成の帯（第1周） | 白飛びと、予兆の金色が埋もれる危険がある |

## 契約（合否）

| 項目 | 合格の条件 | 実測 |
| --- | --- | --- |
| 接触 | 判定の始めとの差±30ms（弓以外の11技） | 0〜1ms（`contact-after2.json`） |
| 切り出し | 速さ1.8倍以下（とどめは今の2.0以下）、使用割合を下げない | 最大1.8、とどめ2.0のまま。light2 だけ0.491→0.485 |
| 論理 | 同じ入力列で main と一致 | 斥候320コマ・侍大将520コマとも一致 |
| 帯の寿命 | 0.11秒以下。判定の終わりで閉じ、0.05秒＋1コマで消える | 回帰で確認（戻りに足した数0） |
| 停止のコマ | 主人公の切先が地面から1.75m未満 | light1 1.14・light2 0.95・light3 1.44・heavy 0.87m |
| 火花・弾き | 火花の6割以上が刃の進む向き。弾きは刃同士の距離3cm以内 | 80〜90%。距離0.000004m |
| ひるみ | ひるまない一段目でも、相手の頭が主人公から離れる | 8.7cm 離れる（state は idle のまま） |
| 性能 | 描画呼出+2以内、三角形数千以内、毎コマの新規確保なし | +1。三角形は上限732（実測の最大56）。0.59B/コマ（空の繰り返しと同じ） |

純粋な部分の試験は、帯18件・切り出し9件・接触の幾何4件。変異試験は49件（すべて検出）。実ブラウザの毎コマの確かめは `regress-slash-trail.mjs`。
帯の見た目を2つ以上混ぜると、第1周の形でも68B/コマの数の箱が作られていた。色の配列の種類が混ざるためで、色を Float64Array にそろえて直し、試験も全部の見た目を混ぜる形にした。
