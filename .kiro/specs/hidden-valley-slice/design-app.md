# Design: 結線層（app）の判断と落とし穴

規則（combat / enemy-ai / companion-ai / quest / save / nav）は純粋ロジックで、`design-contracts.md` が正。ここは、その外側
（`actors.js` `battle.js` `game.js` `ai-world.js` `bow.js` `props.js` `water.js` `main.js` `qa.js`）で**判断が要った所と、踏んだ罠**だけを書く。

## 層の約束
- `actors.js`：主人公・敵・仲間・村人が、論理の状態（Fighter / Brain）を読んで動作と位置を決める。規則は持たない。
- `battle.js`：当たりの判定は `combat.strike` に任せ、結果を音・火花・揺れ・敵の反応・士気・任務へ配る。矢・予兆・掛け声もここ。
- `game.js`：任務（`quest.reduce`）の効果を世界へ配る。段階（beat）から世界を**作り直せる**（はじめから・つづき・やり直しが同じ道）。
- `ai-world.js`：AIへ渡す歩ける格子・経路・見通し・近接の札。`qa.js`：`?qa=1` のときだけ入る検査の口。

## 判断（なぜそうしたか）
- **強攻撃は F キー**。長押しは連続斬りの入力窓と衝突し、ポインターロック下のクリックの長押しがブラウザごとに不安定だった。
- **ヒットストップは時間全体を 0.05 倍に落とす**（0.07/0.10/0.09 秒）。個別に凍らせると、弾きの窓・敵の予兆の時計とずれる。
- **敵の経路は主体ごとにキャッシュ**（0.45秒・通過した折れ点を捨てる）。AIは毎フレーム `pathTo` を呼ぶので、そのままだとA*が毎コマ走る。
- **里の敵は最初から置き、段階 b3 で起こす**（`dormant`）。出現の瞬間が見えない。里に入る前に倒していた分は b4 で再送する（quest は b4 以外の死亡を無視する）。
- **弓は骨に付けず、構えの間だけ両手の位置から作る**（`bow.js`）。焼き込んだ Archery_Shot は矢筒から矢を取る動作が長く、手の速さの山が「放ち」と一致しない。
  使う秒を `anim-data.js` の `CLIP_SEGMENTS` に決め打ち（つがえ 2.0 / 放ち 4.0 / 下ろし 4.95）。テストが「放ちが当たりの時刻に着く」ことを守る。
- **腕の力抜き**（`characters.js relaxArms`）：Meshy由来の待ち・歩きは腕が体から30〜40°開く。下がった腕だけ、開きを9°へ実行時に詰める（構え・振りの腕には効かない）。
  元の焼き込みを直す案は、7体を焼き直す手間に対し効果が同じなので見送った。
- **弾きの後の反撃**（`counter`）：弾きに見返りが無いと、受けが「ただの防御」になる。弾いた側だけに0.9秒の窓。窓は反撃で消える。
- **結果と冒頭は演出カメラ**（`setCine`）：リグのカメラへ戻す滑らかな補間つき。見晴らしの会話・結果の焚き火・冒頭の目覚めで使う。
- **描画の解像度は自動で調整**（コマ時間の移動平均。戻す試しは失敗するたびに間隔を倍に）。`?w=`（固定撮影）と QA では動かさない。
- 草・稲・岩は**空間の区画ごとに InstancedMesh を分け**、視錐台と距離で区画ごと描かない（三角形が約半分）。

## 落とし穴（再発させない）
- Meshy のモデルは原点が中心に寄る。置く前に底面中心へ揃える（`props.js loadPropModels`）。揃えないと地面に埋まる。
- Three の `Box3` は `updateMatrixWorld` 後でないと古い。骨の世界座標を読む処理は先に行列を更新する。
- 会話を閉じる E が同じ瞬間に別の操作（闇討ち等）にならないよう、入力の受け取りを先に作ってから会話を進める（`game.update`）。
- 仲間AIの `intent.move` は**進む向き**（単位ベクトル）で、敵AIは**座標**。取り違えると仲間が動かない。
- 水面は深度で岸に隠れる前提（帯は川幅より広く取る）。橋は川を横切る向きに置き、両岸の高い方へ床を合わせる。
- 検査の `__valley.step` は**コマ送り**で、CSSの遷移（暗転）は実時間。暗転の見た目は実時間で待たないと撮れない。
- **道の継ぎ目に段を作らない**（`terrain-height.js`）。道の踏み面は端で自然な高さへ寄せ、重なる道は重みで混ぜる。端どうしで平均の取り方が違うと、廃寺の道と林道の継ぎ目に2.7mの崖ができ、キーで歩くと止まった。
  経路の試験（格子の探索）は崖を迂回して通るので気づけない。**操作と同じ移動の規則で道を歩く試験**（`valley-world.test.mjs`）が門番。道の上の置き物（干し台）も同じ試験で見つかる。
- ヘッドレスではポインターロックが無い。入力は `key/tap/click` で注入する（実機のマウス操作とは別に、本人の確認が要る）。

## 未解決・限界
- 人物GLBが約59MB（骨付きの頂点が重い）。量子化やメッシュ圧縮は未実施。
- 性能：M4 Pro・720pで約9ms／コマ。弱いGPUは解像度の自動調整に頼る。標準の地形シェーダーが最も重い。
- 音は合成のみ。再生の無事は確かめたが、音の良し悪しは耳で確かめていない。
- 素材（Meshy）の公開・商用条件は未確認。非公開リポジトリだけに置く。
