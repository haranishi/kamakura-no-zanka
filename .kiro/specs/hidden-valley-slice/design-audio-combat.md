# Design: 戦いの金属音（R15・R18.6・tasks-polish3 8.4）

2026-11-03、開発者がプレイして「ちゃんと戦ってる音を出してほしい。キーンとか、カーンとか」。決定は**合成を強める**（録音・外部素材は使わない。
録音は本人が試聴して不足と判断したときだけ検討）。戦闘の規則と時間は変えない。数値は試聴前のたたき台で、本人の耳で動かす。

## 狙いと種類

| 音 | 種類 | 鳴る時 | 作り |
|---|---|---|---|
| キーン | `parry` | 弾き | 刃（棒）の非整数倍の部分音5本、基音約1.75kHz。高い部分音ほど早く消える（基音は−60dBまで約1.7秒）。うなり2組 |
| カーン | `block` | 受け | 基音約820Hz・4本・短い（約0.5秒）。腕に来る低い衝撃（150→75Hz）を下に |
| カーン | `clash` | （今は鳴らさない） | 基音約1.08kHz。受けより明るく少し長い |
| ガン | `hit_armor`／`hit_armor_heavy` | 鎧の相手への命中（兵＝軽い・侍大将＝重い） | 板の振動の比（1・1.59・2.14・2.30…）6本＋高Qの帯域のノイズ（板の胴鳴り）＋肉の鈍い音。軽い鎧は高く短く、強い技は低く長く |
| カラン | `sword_drop` | 倒れた者の刀が地面に着いた瞬間 | 3回の打撃（先が当たる→約85ms後に跳ねる→約175ms後に転がる）、次第に弱く短く |
| ジッ | `spark` | 金属の音の中の層（単独でも鳴らせる） | 6.5〜10kHzの帯の45msのノイズ＋散る4粒 |

肉への命中（`hit`・`hit_heavy`）は金属を混ぜない。以前の `hit_heavy` に入っていた金属の部分音（620・1480Hz）は外した。
毎回の揺らぎ：基音±3%・部分音±0.6%・強さ±1.5dB・減衰±10%・変奏3通り（直前と同じ変奏は続けない＝`audio-rules.js` の `pickVariant`）。
乱数は種つき（`ValleyAudio.fxRng`）なので、書き出しと回帰は毎回同じ波形になる。

## 判断と、捨てた案

| 判断 | 理由 | 捨てた案 |
|---|---|---|
| 設計図（純粋・`combat-synth.js`）とノード化（`audio-valley.js` の `scheduleCombat(ctx,…)`）に分ける | 足音（`step-synth.js`＋`playStep`）と同じ形。設計図はNodeで、音はOfflineAudioContextで検査できる | `play()` の中に直接書く（検査できない） |
| 非整数倍の部分音＋部分音ごとの減衰＋うなり＋1〜6msのクリック＋揺らぎ | 「金属らしさ」の主因は、整数倍でない部分音と、高い音から先に消える減衰。数値の上では5種類の重心と余韻が分かれた（聴き分けは本人の試聴） | 合成の短い反響（帰還ループの後始末が要り、声の束の解放が複雑になる）。高Qの共鳴は鎧の胴鳴りだけに使う |
| 火花のジッは金属の声の中の層にする | 別の `play('spark')` にすると、受け・弾きのたびに声の束が1つ増える（同時数28の枠を食う） | 命中のたびに `spark` を別に鳴らす |
| 兵（軽い鎧）への命中も金属（ただし高く短い板）にする | 兵は最も多い相手。肉の音だけだと「戦っている音」が出ない | 侍大将だけを金属にする（兵の命中は今と同じに聞こえる） |
| 闇討ちは鎧でも肉の音 | 静かな技（発見の半径3m）。鎧の鳴りは合わない | 鎧なら常にガン |
| ノイズは文脈ごとに1つの種つき白色雑音（1秒）を位置をずらして読む | 発音のたびにバッファを作らない（以前の `noiseSource` は毎回作る） | 毎回作る |
| `clash` は鳴らす瞬間が無いので結線しない | 規則に「互いの刃が同時に当たる」結果が無い（結果は命中・受け・弾き・回避だけ）。新しい規則は作らない | 受けの一部を `clash` に振り分ける（区別の根拠が無い） |

## 落とし穴

- 測り方：書き出し・`regress-combat-sounds.mjs` は master を素通し（音量0.8）にして**圧縮器とリミッターを通さない**（合成の形を比べる）。
  実際の出口のピークは `regress-audio-levels.mjs`（実時間・リミッターの後）が守る。圧縮器は無音のあとの最初の音を小さく通す（`design-validation.md`）。
- 続きから始めると、最初から倒れている者の刀も落ちる。音まで鳴らすと読み込みの直後にカランが一斉に鳴るので、生きている姿を見た者だけ鳴らす（`actors.js` の `seenAlive`）。
- `regress-slash-trail.mjs` の「三段目は強い当たりの音」は、斥候が軽い鎧なので `hit_armor_heavy` も受け入れるように直した（強い音を求める意味は同じ）。
- 声の束は余韻の終わり＋100msまで数える（弾きは約2秒、以前は一律1.8秒）。
