# Design: 動きと間で見せる斬り合い（R18）

抜刀・納刀と攻撃のつながりを先に設計し、粒子やカメラで補う順にする。設計のみで実装は未着手。前値は research-polish3.md、合否は design-validation-polish3.md。

## 見立て：接触の前後がつながっていない

確かめたことは、刀の表示切替と動作が独立、近接動作の使用割合28〜56%、被弾と死のクリップが乱数選択、とどめの受け側が未対応、軌跡が未使用という点。
これにより「抜いて構える→踏み込んで斬る→相手が受ける→残心」の因果が読めず、短い火花だけが結果を説明していると考える。倍率の高低だけを原因と決めず、ラボと実プレイで確かめる。

## 判断と捨てた案

| 判断 | 理由 | 捨てた案・保留 |
|---|---|---|
| 戦闘規則を先に固定し、動作の接触を合わせる | 手応えの改善と難度の変更を混ぜない | 演出のため全技を遅くする案は本人確認まで保留 |
| 鞘口を基準に刃を連続して受け渡す | 出現・浮遊の原因に直接対処する | 表示切替だけ／光で切替を隠す案は採らない |
| 予備・振り・残心と接地を技ごとに確認する | 使用割合が大きくても不要な待ち姿勢なら改善しない | 全動作を同じ倍率で流す案は採らない |
| 接触の種類から体・火花・音を選ぶ | 受けと斬りと弾きを読み分けられる | 全打撃を同じ大閃光にする案は採らない |
| とどめを双方の動作として検討する | 当たる場所と倒れる原因を対応させる | 通常の死を乱数で重ねる案は採らない |

## 抜刀・納刀の方式候補（18.1・18.9）

| 候補 | 採否と理由 |
|---|---|
| 既存動作を測り、手・鞘口・刃の接触を通じて受け渡す | 第一候補。鞘口から出る長さと握りを連続して合わせ、音を抜け・収まりに同期する |
| 手の骨と腰の骨のあいだで、動作の1コマを決めて付け替える | 条件つき候補。世界位置と向きが前後で連続し、刃が鞘口を通る過程も見える場合だけ。付け替え単独では不足 |
| Blenderで手・鞘・刃の相対運動を再編集する | 既存動作が届かない場合の候補。骨や衣服の干渉と再配布条件を確認して比較する |

平時の準備と戦闘後の納刀で見せ場を検証する。攻撃・受け入力に強制の待ちを足す案は採らず、危険時の中断・再抜刀・被弾・回避・会話・休止・再開の姿勢を設計する。
既存の初撃予備内で成立しなければ、平時に抜く見せ場と緊急の短い遷移を比較する。時間割の変更が必要ならR18.9へ理由と影響を追記し、本人の確認まで保留する。

## 攻撃動作の調達と編集の比較（18.2）

| 候補 | 採否・費用の見方・出所の条件 |
|---|---|
| 既存動作の区間と速さを見直す | 最初に比較する。追加容量は小さいが手首の山だけで接触を決めず、姿勢・足・刀を測る。既存の出所と編集条件を確認する |
| Blenderで既存動作を再編集する | 次候補。予備と残心を保持した短い動作へ整え、当たりと接地を合わせる。編集工数と再焼き込み容量を測り、改変・公開条件を確認する |
| 本人制作の新規動作 | 不足技に限定する候補。工数は未見積もり。生成支援を使う場合も入力と出力の出所を記録する |
| 外部動作の購入・採用 | 保留。価格・骨の写し替え・OSS同梱と改変後の再配布条件を1件ずつ確認し、本人の採用判断を得る。今回は取得しない |

三連の終わりと次段の構えを対で見て、足の固定と前進量を照合する。見た目だけの補正で当たりと体の距離が乖離しないようにする。前進量の変更もR18.9で扱う。
刃の軌跡は切先と根元の履歴を結ぶ板ポリゴンのリボンを第一候補とし、短い加算合成と通常の半透明を比較する。加算で白飛び・敵の予兆消失が出るなら採らない。軌跡は表示だけで、当たり判定には使わない。

## 受け・反応・倒れ・とどめの規則（18.3・18.4・18.6・18.7）

- 受けは刃の接点から押し返され、弾きは入射と逸れる向きへ反動と火花を出す。避けは重心移動と着地で区別し、既存の無敵時間を維持する。
- 被弾は相対方向→高さ→武器と技→鎧の反応可否の順に候補を絞る。同条件内の変種だけを選び、対応動作がない場合は既知の反応へ戻して不足を記録する。見せ方の高さから新しい部位ダメージを作らない。
- 倒れは重心の崩れ・膝や手・胴の接地を連ね、刀は握りが解けた時点から落ちる。定時0.3秒の切離しを完成基準にせず、段差・壁・地面との干渉を検証する。
- とどめは両者の開始位置・向き・接触時刻を共有する組を候補とする。接近は通行と間合いを守り、壁抜け・瞬間移動を認めない。不成立時は通常の技表示へ戻す。非致死のとどめは受け側の復帰を用意し、結果確定を映像都合で遅らせない。
- 音は7.7と共同で刃・鞘・金属・木・布や鎧の接触を設計する。束上限と発見半径を保ち、出力遅延込みで本人が聴く。敵の構え直しと足運びを強調し、同時攻撃2人までの群れで交代と待機を見せる。

## カメラと間、武器の形（18.5・18.8）

短い停止→接触の読み→戻りの順を比較し、通常・強・弾きを区別する。寄り・視野・軽いスローは候補で、予兆と周囲の敵、入力受付を優先する。連打時の重なり、ロック切替、壁際、揺れ0を動画で検証する。
現行のヒットストップは論理と動作の時間も縮める。持続・倍率や追加スローの変更は演出だけと扱わず、R18.9の確認対象とする。主人公の被弾で画面の縁が90ms赤くなる既存の演出は残し、画面全体の色調変化は必要性未確定で保留する。
武器は刀身の面と反射、鞘口、柄巻き、鍔、下げ緒を同じ夕景で比較する。先に形と材質で読みを確保し、常時発光する刃や大きな軌跡で棒を隠す案は採らない。

## 段階ごとの実ブラウザ検証と予算

実装を依頼された後の順序は、見て分かる効果が大きい順に **抜刀・納刀→攻撃の動作の整合→当たり・倒れ・とどめ→カメラと間→武器の造形**。各段を実ブラウザのコマ割りで確かめ、実プレイ動画と本人の確認を次段の条件にする。
標準p95≤20ms・軽量≤33.3ms、呼出≤900・三角形≤500万、実読み込み≤90MiBは未測定の設計目標。前値の呼出757や約77MiBとの差を全部使える追加枠としない。R14/R15の予約枠を保ち、全体で再測定する。

## やらないことと未確認

血の表現（R11.2の設定との関係は本人の確認まで保留）、規則変更を伴う無断調整、全員の動作・モデルの全面再生成、外部作品のコード・数値・素材の転用は行わない。規則変更は本人の確認まで保留する。
動作ごとの改変・再配布条件、鞘口と手の一致、足滑り、組の成立範囲、追加方式の容量と性能、実機の音と操作は未確認。候補の採否は測定と本人のプレイで確定する。
