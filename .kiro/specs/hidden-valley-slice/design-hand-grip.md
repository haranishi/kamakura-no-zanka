# Design: 刀を握る手（タスク8.6a・R17.7・R18.8）の実測と採用方式

本人の評価（2026-10-30・プレイ後）「手の持ち方が変。剣の」への対応（Issue #10）。2周目は、別役の採点で指摘された破綻（黒い板・針・袖の黒い穴・兵の半透け）と、握りの不足（抜刀の右手・両手持ちの下の手・兵の人差し指・侍大将の拳）を直した。数値は設計目標。

## 実測：何が握りを難しくしているか

| 項目 | 実測 |
|---|---|
| 骨 | 3体とも24本で、指の骨は無い。手は体と同じ1つのメッシュの一部 |
| 柄の軸 | 刀は動作の右手の骨に付き、柄の軸は**右手首の関節の中心を通る**。握る溝は柄の軸から約12cm。手そのものを12cm動かすしかない |
| 指の形 | 主人公・兵は、指が付け根の近くまで分かれている。**侍大将は、指先の近くまでつながったミトン形**（法線と線画で確認） |
| 左手 | 動作の左手首は、構えで柄の軸から3〜4cm、袈裟・横薙ぎ・唐竹で2〜26cm、歩きで24cm、両手受けで28cm以上。逆袈裟・横薙ぎ・止めでは、動作の左手そのものが鍔を通り抜けるコマが31〜54ある |
| 肌の照り | 兵の手の粗さは0.42（主人公0.79）。材質は不透明（`transparent`・`alphaTest`・両面・巻きの向きを確認）。半透けに見えたのは照りと、両手の重なり |
| 2周目の「黒い板・針・膜」 | 寄り裏のカメラが、柄へ寄せて動いた袖から6〜9cmにあり、近い面（10cm）で袖が切れていた。近い面を1cmにすると消える。ゲームのカメラは2m以上離れ、近い面15cm |
| 袈裟の黒い破片 | 柄へ寄せた右の袖の裾（黒い縁）が、離れたままの左の指の前へ出ていた |
| u0.8 の袖の黒い四角 | 鍔の縁が前腕の袖を突き抜けていた（刀を隠すと消える。影ではない） |
| 袖口の中の黒 | 主人公の袖口の内側の絵が sRGB 5,5,5（前腕に付く面だけ。髪の黒は頭） |

## 判断と捨てた案

| 判断 | 理由 | 捨てた案 |
|---|---|---|
| **見える腕を写し（上腕・前腕・手）にし、写しだけを二関節IKで柄へ寄せる**。刀は動作の手の骨に付いたまま | 動作の骨を動かさないので、刀・抜刀の層（8.2）・論理は変わらない | 動作の骨を動かし刀の付け方を毎コマ補正（8.2の測定の意味が変わる）、刀を手のひらへ動かす（軌跡が変わる） |
| 指は**4本それぞれ3関節の鎖**。関節の高さは4本で共有。合わせは「板（4本同じ角）→指ごとの差」の2段で、隣の指との差は0.22radまで | 板では侍大将が7〜13mm離れた。指ごとに独立に合わせると、境で混ぜた皮が柄の内側へ落ち、侍大将で5〜12mm入った。指ごとの先の高さに比例した関節は、板の合わせが4.5mm→12mmへ悪化 | 指ごとに独立の合わせ、指ごとの関節の高さ |
| 合わせの式に「いちばん離れた節」を25倍で足す | 和だけでは1つの節が7mm離れたまま残った（6・12・25倍で比べた） | 和だけ |
| 親指は狭い格子で探し、どれもめり込むときだけ広い格子 | 初めから広い格子だと、兵の右手で付け根を大きく反らした姿勢が選ばれ、甲の上に親指の先がとげのように立った | 広い格子だけ |
| 右手の位置は、握った手の親指の側の広がりが鍔の面から4mm離れる所（主人公・兵・侍大将とも約5.6cm） | 兵の人差し指が鍔に掛かった | 型ごとの固定値 |
| **両手持ち**：動作の左手首が柄の軸から12cm以内なら左手で柄頭の側を握り、22cmで離す。重みは臨界減衰の2次で追う | 袈裟の黒い破片が消え、動作の左手が鍔を通り抜けるコマが106→11（2コマに1回の測定）に減った。1次の追従は離し始めの1コマが最も速く、左手首が隣の3.6倍回った | 左手を常に握らせる（歩きで左手が24cm引かれる）、1次の追従 |
| 抜刀の右手は、構えの握りから−1.0rad回した握り（親指が上・四指が下）。刃を振る前半は−1.5radまで回し、u=1で0へ戻す | 構えの握りのままだと真上から手の甲だけが見えた。親指の先が真上に来る回り（約±π）は下から支える握りになり、抜く間に手が柄を1周した。−1.0のまま振ると u0.7〜0.88 で袖が鍔を横切った | 親指の先の向きで回りを決める |
| 鞘の溝の向きは +c に固定（左手の親指が鯉口の側） | 握り始めのコマで ±c を選ぶと、納刀の始め（内積ほぼ0）に逆を選び、のちに反対向きになって1コマで2.8rad回った。+c なら全場面で内積−0.74〜1 | 毎コマ選ぶ・握り始めに選ぶ |
| 肘の向きは、動作の腕の曲がる向きへ肘から25cm出した点。手首のねじれの半分を前腕へ移す | 見える肘を使うと、納刀の始めに肘が1コマで23cm裏返り、袖が48mm伸びた。手首だけでねじると抜刀の振りで手首の皮が45mm伸びた | いまの見える肘、手首だけでねじる |
| 指・親指が主の頂点（手の重み半分以上・その6割以上が指）は前腕の小さな重みを外す | 侍大将の親指の付け根が前腕の5%に引かれ、柄へ2.4mm入った | — |
| 材質に2つの補正：前腕に付くほぼ黒の絵を袖の紺の暗い布色に、肌色の画素の粗さを0.8以上に | 袖口の中が黒い穴に見えた。兵の手が照りで半透けに見えた。髪などは変えない | 全員の黒を持ち上げる（主人公の髪も変わる） |
| 撮影の近い面は2cm、寄り裏は柄からカメラへの5本の線が前後とも人物に遮られない向きを選ぶ | 2周目の黒い板・針・膜は撮影の近い面のせいだった | 元の向きのまま |

侍大将の「指が分かれた拳」は、型の指が先の近くまでつながっているため、曲げの差では作れない。指ごとの差を交互に0.12〜0.4rad足すと、指先がとげのように割れた（撮影で確認）。分けるには型の作り直しが要る（範囲外）。

## 契約

- 写しは毎コマ、動作の骨から写し直してから動かす。動作の骨・刀・鞘・論理（`combat.js`）・入力・音には触れない。
- 重みの付け替えと握りの合わせは、型の形（全員で共有）に1回だけ（読み込みの間）。骨は人物ごとに作る（24＋左右17本）。影響は4つまで・合計255。
- 握る重み：右手は刀が手にある間1（落とす・降参で0.08秒かけて離す）、抜刀・納刀の間は u から。左手は、抜刀・納刀の間は鞘（抜刀の層の左手の重み）、抜き切って持つ間は両手持ち（鞘の重みの分だけ弱める）。
- 握っていない指は軽く曲げる（小指ほど深い。小指1.3倍〜人差し指0.85倍）。
- 対象は主人公・兵・侍大将。村人・弥十郎の型は変えない。柄の位置と向き（`GRIP.tachiDrawn`）は変えない。

## 構成

純粋層（Node）：`hand-grip.js`（手の形の測定・重みの分け方・指の姿勢・握りの合わせ・広がり・配列を作らない二関節IK・届く回り）。結線：`hand-rig.js`（型の準備・材質の補正・写しの骨・毎コマの適用）。`characters.js` の `update()` は、抜刀の層の `apply()` のあとに `hands.apply()`。

|---|---|---|

## 未確認・既知

- 侍大将の拳のミトン形と、甲の白い線（籠手の縁の絵。前後とも同じ）は型の側の問題。
- 抜刀・納刀で刃を振る u0.75〜0.89 の数コマ、右の袖が鍔を横切る（ラボの止め絵では−1.5radで消えるが、ゲームの構えへの移り目では残る）。
- 本人のプレイ・別役の採点（8.6a-3）、Safari・Firefox・実機、静かな環境での型の準備時間は未確認。
