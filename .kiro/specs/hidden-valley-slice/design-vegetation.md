# Design: 草と木（R14）

現行の植生（`vegetation.js`・`scatter.js`）は、形も葉の絵も手続きで作る。ここには、足りない所の見立てと、直し方の判断だけを書く。
数値は設計目標で、tasks.md の7.0で実測してから見直す。

## 足りない所の見立て（コードと測定で確かめた。原因は仮説。固定画角の比較で確かめる）

1. **草が少なく低い。** 候補の格子は0.55mごとで、斑の規則で間引くため、主要3地点の10m以内で1㎡あたり3.6〜5枚。高さ0.13〜0.30mは形の生成値（配置倍率0.8〜1.35）。標準は28〜46mで縮小して消える。足もとに地面の色が見える。
2. **遠景込みは杉87%・広葉1.6%。** 到達格子の645本では杉以外24.96%・広葉13.18%（research.md）。比率だけでは見た目の不足を判定できない。下草は1種。
3. **木が「葉のカードの束」。** canvasで描いた枝先を板に貼る作りで、近づくと樹冠が平らに見える。幹の枝と根張りが弱い。
4. **林床が一様。** 既存の落ち葉層（terrain-height.js・terrain.js）では不足する。立体的な落葉・針葉・岩や岸の苔を足し、道の縁の踏み分けを見せたい。

## 判断と、捨てた案

| 判断 | 理由 | 捨てた案 |
|---|---|---|
| 草は三段：近くは葉を一枚ずつ、中は株のカード、遠くは地面の質感に細部を焼く | 近くの密度だけ上げれば足り、遠くは安く済む | 全域に静的に高密度（100枚/㎡×約6万㎡＝600万枚。配列と生成時間が持たない） |
| 近景はカメラ周りの区画（近景1m角・中景2m角）だけ、区画の番号から決定的に作り、InstancedMesh を使い回す | 同じ番号は同じ絵になり、固定画角の前後比較が崩れない | 毎フレームGPUで全生成（WebGL2には compute が無い） |
| 区画の生成は、読み込み時に一度作る草の濃さ・高さの格子（1m）を読む。分割生成・行列更新・転送を部分予算内で進める | 数十msという遅延は未測定の見積もり。旧案の8m角は100枚/㎡なら6,400枚なので、一区画でも時間の上限にはならない | 区画に入った瞬間に全部作る |
| 木は樹冠を葉のカードの塊（ドーム）に束ね、頂点に内側ほど暗い「露出」を持たせる | 手本の講評でも、カードの散らしは「平たい紙の束」だった。塊にすると立体に見える | カードを増やすだけ（三角形が増え、平らさは残る） |
| 質感にCC0の写真（Poly Haven・ambientCG）を使ってよい。形は手続きのまま | 樹皮と葉の写真感が出る。出所を台帳に残せばライセンスは単純 | 外部の木モデルをそのまま置く（1本数MBで予算が持たない。他作品の見た目に寄る） |
| 樹種・色づき・空き地・大木は、低い周波数の場で決める | 近くの木が同じ色づきを共有し、群れと空き地ができる（一様乱数は紙吹雪に見える） | 樹種を一本ずつ乱数で振る |
| 後処理（被写界深度など）でごまかさない | 近景の粗さは変わらず、コマ時間だけ増える | — |

SpeedTree など有料のミドルウェアはWebで使えず、依存も増えるので対象外。

## 構成

- **草の葉（近景）**：3〜4節の細いリボン（幅1.5〜3cm、先ほど細く）。根もとの暗さ・先の明るさ・一枚ごとの色と曲がり。真横を向く葉は幅を広げ、画面で線に消えないようにする。
- **株のカード（中景）**：葉10〜20枚分を絵にした交差カード（`alphaToCoverage`）。距離で葉を間引きつつ幅を太くして、被覆を保つ。切り替えは葉ごとのハッシュで溶かし合わせる。
- **下草の種**：短い草・丈の高い株・ススキ（逆光の穂が効く）・シダと笹・花（畦の彼岸花など）。種・丈・空き地は低周波の場（value noise）で決める。
- **木**：杉の三段は残して枝ぶりを足す。広葉を2種足す（楓＝紅、欅＝黄）。若木と灌木を足し、道と里の縁に低い帯を置く。幹は曲線の管＋根張り＋樹皮。LODは3段（葉カードの塊→簡略の塊→一つの塊）を溶かし合わせる。
- **色づき**：広葉の紅葉と黄葉は場の値で段階づけ、近くで同じ段階を共有する。杉の塊は暗くしすぎず、黒い穴にしない（`design-app.md` の罠）。
- **風**：樹冠全体のゆっくりした揺れ＋外側の細かい震え。突風は、時間と位置の低周波ノイズで帯にして草地を渡らせる。向きの共有契約は design-contracts.md「風」。導きの風より先に固定する。
- **逆光の透け**：太陽と視線の内積で、葉と草の縁を明るくする（材質は Lambert のまま、シェーダーを一部差し替える）。
- **林床と道の縁**：落ち葉・針葉の敷きを木の下で濃く、道の縁に踏み分けと草の縁、岩と川岸に苔。地形の質感に重ねる（`terrain.js`）。
- **軽量品質**：密度を0.4倍、距離を0.6倍。

## 約束

- 乱数の系列は新しく足す（既存の `world.seed + seed*307` の系列は変えない）。既存の木・岩・稲の配置は、テストで同じであることを守る。
- 既存配置は `scatter.js`、草の場・区画生成は `grass-field.js` に置き、Three.js・DOM・乱数・時計に触れない。`vegetation.js`（view）は形と材質だけ。
- 見た目の調整値は `config.js` に集め、`?lk=` で試せる。

## 予算（設計目標）

| 項目 | 目標 |
|---|---|
| 近景の草 | 8m以内で100枚/㎡＝π×8²×100≒20,106枚。1枚6三角形なら約12万（円外区画は別計上） |
| 中景の草 | 8〜25mで20枚/㎡相当＝π×(25²−8²)×20≒35,249枚相当を株カードで（未測定） |
| コマ時間 | design-validation.md のp95と区画部分予算を満たす |
| 追加の質感 | 2MiB以内。録音などと合わせた総量は design-validation.md |

## 検証

- Node・ブラウザ・人の合否は design-validation.md「植生」。母数を固定し、比率・まとまり・形を合わせて判定する。密度の式・場の係数を壊す変異で落ちること。
- ブラウザ：固定画角13（既存10＋新3）の前後、コマ時間と描画呼び出し・三角形を2回測る、独立評価（最大3周）。
- 講評の読み方：不満を「足りない・平ら・同じ」に仕分け、足りなければ足し、平らなら接地の暗がりや凹凸を、同じなら形の種類と個体差を増やす。

## 7.8 配置の純粋層（Node検証。描画は未接続）

- `createGrassField(world, terrain, {box, padding})`：既定は旧草の箱＋8m、1mセル256×266。
  `placeable/density/height/species` はUint8、`heights` は角の257×267点のFloat32。
- `sampleGrass(field,x,z)`：配置可否と種は所属セル、濃さと丈の倍率はセル中心の双一次補間。
  濃さはUint8の0〜255を0〜2倍、丈は0.8〜1.35倍に戻す。範囲外は配置不可。
- `nearTile(field,tx,tz,{quality})`：1m角。葉は `count,x,y,z,h,w,lean,yaw,hue,species`。
  浮動小数はFloat32、種はUint8。SHORT/TALL/FERNの葉と、別の `clumps` を返す。
  `clumps` は `count,x,y,z,h,yaw,hue,kind`。ススキ・花のセルにもSHORTの下草を残す。
- `midTile` は同じ引数で2m角、`count,x,y,z,s,yaw,hue,species` の株カードを返す。
  両APIの整数 `size` オプションは再分割検証用。セル単位の乱数は再分割しても変わらない。
- `tilesAround(field,x,z,{quality})` は矩形と円/環の交差で区画を選び、最短距離順に返す。
  近景8m、中景25m、重なりは近景半径の0.8倍から。標準は密度/距離1、軽量は0.4/0.6。
- `grassBudget(quality)` はカメラの区画内位置を16×16で調べ、円を誤差分広げて上界を求める。
  全区画が最大濃度でも標準は近景30,125葉・180,750三角形、中景4,288カード・17,152三角形。
  軽量は近景4,850葉・29,100三角形、中景832カード・3,328三角形。専用株の描画予算は次工程。
- 密度100葉/㎡、中景20葉相当/㎡を切り上げる（1カード14葉相当、現状2カード/セル）。
  濃さは最低1倍＋森で減る大小の斑、上限1.24倍（Uint8量子化後は最大1.2471倍）。
  丈は種×場×個体差の後0.15〜0.6mに制限。葉幅1.5〜3cm、倒れは種ごと0.06〜0.40。
- ススキはその生息セルで0.25株/㎡、花は0.8株/㎡。種の場と個体の系列は既存配置と分ける。
- 理由：角の高さを一度保存すれば区画生成時の重い地形問い合わせがなくなり、区画境界も一致する。
  空き地は植物を出さない場所なので密度の母数から除く。密度不足を空き地で水増しして判定しない。
- 禁止域との境界セルを半対角分広げて除外する。岩は小岩を含む模型の外接円で避ける。
  傾斜は中心と角の勾配で保守的に判定する。既存の配置・地形・当たりは変更しない。
- Node単独測定：配置可40,787㎡、空き地4,532/45,319㎡（10.0002%）、濃さ平均1.0802倍。
  種の割合は短草57.83%・高草19.02%・ススキ6.49%・シダ14.05%・花2.60%。
  隣接同種率93.51%、固定seedの並べ替え39.79%。6地点の密度と200乱択区画の除外を検査。
- 角補間の誤差：54,016葉で平均0.098cm・最大9.236cm（平均2cm・最大10cmの目標内）。
- 生成時間（Node v24、最終検査）：場1,180msで600msの目標未達。近景122葉のp95 0.030ms、
  中景8カードのp95 0.0025ms（各100回暖機＋500回測定）。CPUのみで転送/描画を含まない。
- `node --test tests/valley-grass-field.test.mjs` で再測定。ブラウザ・GPU・LOD・風・見た目は未確認。
- 最終検査：全288件・配布検査・差分検査に合格。変異19種を全検出し、全復元後も合格。
  `smoke` はローカルポートの権限制限で実行不能。文書lintは依存不足のため手動点検。
