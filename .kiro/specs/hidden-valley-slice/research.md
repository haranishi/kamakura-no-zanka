# Research: 調べたことと、採らなかった道

## 引き継いだ事実（2026-10-27時点）

- v18は一人称の庭のしごと。Three.js 0.180.0同梱・ビルドなし・Node 18+。人物・戦闘・三人称・広い地図は無い（README明記）。
- Driveの `残火の鎌倉/` に、企画書 v0.1・隠れ谷の企画図（約1.2km四方）・三人称の企画画・鳥瞰画・人物と生活の参考画像9枚・
  Blender製の実3D素材（農家・廃寺・橋・杉・岩・小道具・水路・農具）がある。いずれも本人制作で非公開。
- 作者の別作品（非公開）に、Meshy 24本骨へ約90本の動作を写し替えて焼くBlender道具と、
  SSD上の動作キャッシュ181ファイルがある。湊は別作品（1589年）。人物・場面は持ち込まず、道具と動作だけを使う。

## Meshy の実測（2026-10-27）

- 残高1,219→下限500。使えるのは約719。三面図（nano-banana-pro）9cr、multi-image-to-3d 30cr、image-to-3d 30cr（ultra 35cr）、骨入れ5cr。実測が見積と一致した。
- 三面図の出力順は 側面・背面・正面（または 背面・正面・側面）で一定でない。3D化へ渡す前に目視して、正面を先頭に並べ直す。
- multi-image と single-image のどちらも参考画像に忠実な形になった。主人公と弓手は常に背中を見せるため、三面図で背面を確定した。
- 動作は既存の90本で足りる。クレジットは人物の追加・小物・作り直しに回せる。

## 判断（要約は design.md）

- 三人称アクション。企画書の約束（士気で崩れる・予兆・同時攻撃2人まで）を設計の骨にする。
- 見た目は「絵画的なスタイライズド3D」の指定を、企画の三人称画に近い写実寄りの夕景で解釈する（本人の依頼文「グラフィック性の高い」と、
  既存Drive素材の質に合わせる）。**この解釈は本人の確認待ち**。違う場合は大気と質感の設定だけで寄せ直せる設計にする。

## 採らなかった道

| 案 | 採らない理由 |
|---|---|
| 外部の参照プロジェクトのコード・数値・素材 | 閲覧と手元実行だけを許す規約。手法（周回・固定画角・規則優先）だけ借りる |
| 別作品（非公開）の人物・場面・コードの持ち込み | 構成も違う（TypeScript/Vite）。道具（Blender）と動作データだけ使う |
| Unity/UEへ移す | 企画書の第一候補がWeb（Three.js）。既存の庭と同じ配布方式を保つ |
| Meshyで地形・建物・樹木 | 物は作れるが地形・植生は不向き。建物は既存の本人制作を使う |
| 全員に動作を購入 | 骨が同じ24本で、動作は写し替えで流用できる |

## 未確認（作業中に埋める）

Safari・実機スマートフォンの動作／Meshy生成物の公開時の扱い（有料プラン・非公開で作成。公開前に利用条件を再確認）／
Drive素材の軽量化後の見た目の劣化／WebP質感のSafari対応／足の滑りの実測値。
