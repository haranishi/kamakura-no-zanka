# Design: オープニングの実装（S3・S4）— 実測・採用した方式・捨てた案・契約

design-opening.md（R22・R23）を実装に落とすときに決めたことを残す。数値は特記のない限り、M4 Pro・Chrome（ヘッドレス）・1280×720・DPR1・標準品質の実測。

## 1. 実装の前に測ったこと

- 谷を目覚めの画角で描くと、描画呼出434・三角形315万。遊びに入った直後は707〜710・393万で、1コマ約14.3ms（readPixelsでGPUの完了を待つ測り方）。
- 別の THREE.Scene に寺・農家・主人公の複製を置いた試しは、呼出43・三角形11万・定常1.4ms。ただし最初の1コマに543msかかった（材質の組み立てと画像の送り込み）。
- installFog は霧の断片を差し替えており、霧の色は `fogColor` を使わず、谷の空気遠近の色（青灰と暖色）で決まる。谷が使う霧は FogExp2 だけ。

## 2. 採用した方式

- **進行は純粋層**（`opening.js`）。`stepOpening(state, { dt, skip, reduced })` が新しい状態・見え方・出来事を返し、入力の状態は書き換えない。出来事は skip・cut・seen・wake・getup・done の順に出る。時計と乱数を使わない。
- **データ**（`opening-data.js`）：語り6画面（id・文・史実／創作）、通常版と短い版の区間と語りの時刻、目覚めと飛ばしの時間、暗転と溶け合いの長さ、題名と注記、字と帯の色。文は design-opening.md の案から変えていない。
- **舞台は別シーン**（`opening-stage.js`）。カメラも舞台専用。`game.render` は舞台があれば舞台だけを描き、谷は描かない。場面A〜Dは互いに離れた組に置き、見せるのは1組だけ。光源は鍵の光と炎の光の2つで、場面が替わるたびに置き直す。環境光は空の色から作った反射の絵を使う。
- **温め**：最初の暗転の4コマで、場面B・C・D・Aを1コマずつ描く。材質の組み立てを暗転の下で済ませ、場面の切り替えで止まらないようにする。
- **場面の溶け合い**：`post.js` に「前の1枚を残す」仕組みを足した。仕上げを8bitの絵へ描いてから画面へ写し、場面が替わった瞬間（cut）に直前の1枚を残して、1.0秒かけて薄くする。残した1枚は、画面の大きさが変わっても捨てずに引き伸ばして重ね、溶け終わったら返す。絵を持つのはオープニングの間だけ。
- **霧**：線形の霧（THREE.Fog）は舞台だけが使う。線形のときは `fogColor` の一色にし、谷の霧の帯もかけない。FogExp2（谷）の式は変えていない。
- **語りの枠** `#narration`：HUDの外に置く。重なり順は z-index 28 で、#fade（30）の下。上下に不透明の帯（#05080a）を置き、語りは下の帯の中に出す。字幕の設定（subsOn）は見ない。暗転は枠の中の幕で、不透明度を毎コマJSで書くので、「動きを減らす」でCSSの遷移が止まっても効く。
- **見たかの記録**：`save.js` の別キー `kamakura-valley-meta`（`{schema, version:1, openingSeen}`）。目覚めの区間に入った時点で書く。最後まで見た場合も、飛ばした場合も同じ。無い・壊れた・知らない版・読めない記録は初回として扱う。書けないときは例外を出さずに続ける。
- **目覚め**：既存の `startIntro` の中身を `startWake` へ移し、wake の出来事で呼ぶ。2.7秒で立ち上がり、5.2秒で終わり、入って0.6秒後から飛ばせる。この3つの値はデータへ移したが、動作そのものは変えていない。
- **休止**：Esc（ポインターの解放）・P・画面の切り替えで、オープニング中も休止する。休止画面の「区切りへ戻る」は、オープニング中は隠す（まだ区切りが無い）。

## 3. 捨てた案と理由

- 谷から離れた座標に舞台を置く案：地形・遠景の山・影・大気と衝突する（design-opening.md §5）。
- 場面の切り替えを暗転だけにする案：「動きを減らす」ではクロスフェードと決まっている。場面ごとに暗くすると、9.5秒の場面が細切れに見える。
- 2つの場面を毎コマ描いて混ぜる案：切り替えの1秒だけ描画が倍になる。止めた1枚を重ねれば足りる。
- 2Dキャンバスへ写して重ねる案：preserveDrawingBuffer が無いと、描いた直後にしか写せない。
- 短い版の目覚めを4秒に縮める案（design-opening.md §3）：既存の目覚めの時間割を変えたくない。短い版は約15.7秒になる。
- 語りを既存の字幕（#subtitle）に出す案：HUDの子なのでイントロ中は隠れ、字幕OFFでも消える。
- 見たかを進行の保存に入れる案：「はじめから」の最初の保存で上書きされる。
- 場面の上に半透明の帯を敷いて語りを置く案：比が場面の明るさで変わる。白の上でも4.5:1を保つには帯を約9割の不透明にする必要があり、それなら不透明の帯（映画の上下の黒帯）の方が絵として素直。

## 4. 契約（壊してはいけないこと）

- 通常版は52.2秒（45〜75秒）、短い版は15.7秒（14〜16秒）。各文は40字以内。開始から0.6秒は飛ばせない。飛ばすと0.6秒で暗転し、目覚めへ移る。飛ばしたあとの暗転は、飛ばした瞬間の濃さから単調に濃くなり、予定の暗転より明るくならない。
- 「続きから」「やり直し」では出さない。2回目以降の「はじめから」と、結果からの「もう一度」は短い版。QAの `?intro=0` は今までどおり飛ばす。
- 舞台は、複製したモデルの形と材質（谷と共有）を解放しない。自分で作った形・材質・画像・光の影の絵・反射の絵だけを解放する。
- 解放したあとの谷は、同じ固定カメラで、描画呼出・三角形がオープニング無しと同じ。形と画像の数は増えない（3回上映しても増えない）。
- 字と帯の比：生成り 16.6:1、朱 8.2:1（三段目で #e36b48 から #f08a66 へ。注記・飛ばしの案内も4.5:1以上）。炎の明るさの揺らぎは1.1Hz以下の正弦だけで作り、1秒に3回以下。

- 純粋層：`tests/valley-opening.test.mjs`（18件）。変異試験は `node tools/verify-opening-mutations.mjs`（32件）。
- 実ブラウザ：`tools/scenarios/regress-opening.mjs --intro 1 --strict` で、区間の時刻、語り、飛ばし（E・Space・クリック）、短い版、休止、動きを減らす、続きから、旧保存、やり直し、再上映、記録が書けない場合、解放後の描画を確かめる。

## 6. 二段目：場面の中身（A・B は作り込み、C・D は軽く）

- **純粋層** `opening-scenes.js`：場面の置き場（モデルの複製・炎の源・粒子の源・旗・基壇）、カメラの道筋、炎の板の並び、火の粉と煙の出し方、空の地平の色、朱の面積と明滅の測り方。乱数の代わりに「場面・源・何個目」で決まる系列（`cellRand`）を使い、刻みの細かさに依らず同じ粒が同じ順に出る。
- **見た目** `opening-fire.js`：炎の舌と光のにじみ（加算の板。場面ごとに1つのインスタンス描画）、空（墨の上空・生成りの地平・煙の雲・炎の方角のにじみ）、地面と石の手続きの質感。画像は使わない。`opening-stage.js` は組み立てと毎コマの更新だけ。
- **A 燃える通り**：通りの両側に家10棟（農家4・納屋6）。燃えるのは2棟だけ（左奥の農家が主、右奥の農家は屋根の奥半分）。奥は納屋で閉じ、霧で溶かす。倒れた幟（無地の麻。竿は倒れた荷車に掛かり、布は垂れて地面へ広がる）、倒れた柵・薪・藁。カメラは高さ1.15〜1.22mで約4m前進。
- **B 燃える寺**：寺（1.45倍）を高さ2.1mの石の基壇に置き、9段の石段と袖壁、両脇に石灯籠。炎は棟の後ろ・前の屋根・隅・扉口。炎の光源は寺の中（扉の奥）に置き、外壁は暗いまま石段・軒裏・灯籠を照らす。石段の下（12.5m手前・高さ1.0m）から見上げる固定（画角50°）。
- **C 橋を渡る影**（軽く）：橋（長さ2.4倍・高さと幅はほぼ等倍。欄干を人の腰の高さに保つ）を川に架け、母子・老人・武士の4人が左から右へ渡る。人物は谷の人物の複製に、自分で作った暗い単色の材質（逆光の側だけの縁の光。向きに関係ない発光の縁は採らない）。対岸の家3棟の向こうに火と煙。横から固定し、わずかにパン。
- **D 山道の見返り**（軽く）：景継（主人公の複製・腰に太刀）の後ろ姿。道の縁から先は斜面で落ち、26m下の谷底の2か所に火と煙。空の地平に赤い帯（霧には混ぜない＝谷底は赤くしない）。肩越しに寄り、場面の終わりの2.6秒前に左へ向き直って歩き出す。カメラは右肩の後ろなので顔は向かない（試験で、どの瞬間も125°より後ろ向きを確かめる）。岩と地蔵で縁の直線を切る。人物の時刻は、opening.js の見え方に足した区間の長さ（segmentLength）で決める（「動きを減らす」ではカメラの k が止まるため）。
- **共通**：光源は2つ（空の明かりの鍵＝生成り・影あり、炎＝朱の点光源・揺らぎは flicker）。霧の色は、空が地平に描く色（`horizonColor`）に合わせる（地面の果てが空に溶け、継ぎ目が出ない）。煙は暗い柱（線形0.006）と、炎に照らされた低い煙（橙茶）の2種。火の粉・煙・幟は場面の風の向きへそろって流れる。
- **目覚めの止まり**：オープニングの始まり（暗転の下）で、谷の材質を後処理と同じ描き先・階調なしで `compileAsync` し、目覚めの画角から小さな絵へ1回だけ谷を描く（影の深さの材質と、映る絵の送り込み）。

### 実測（二段目）

- 朱の面積（帯を除く絵。320×180に縮めて数える。色相345〜45°・彩度0.45以上・明るさ0.25以上）：A 15.3%・18.7%、B 14.6%・14.5%。一段目の仮の舞台は3割超。
- 朱の面積（C・D）：C 5.6%・5.7%、D 18.8%・19.3%。明滅：A〜Dとも2秒間の平均の相対輝度で0回/秒（変化の閾値はその間の最大の10%）。
- 描画：A 呼出154・三角形48万、B 62・13万、C 63・36万、D 42・9万。1コマの p95：A 5.5〜7.4ms、B 4.7〜5.5ms、C 3.0ms、D 3.4ms（`measure-opening-perf.mjs`。測った回で揺れる）。
- 目覚めの最初の1コマ：288ms → 23ms（飛ばした経路）・35〜47ms（通しの経路）。代わりに始まりの1コマが536ms（C・Dの人物5人を足したあとは625ms。舞台の組み立てと谷の先組み立て。2秒の暗転の下で、語りの前）。
- 上映を3回繰り返した前後で、形296・画像175のまま。最初の上映の前後は、測る流れによって増えも減りもする（共有のモデルの形と絵が初めて送られる）ので比べない。

### 捨てた案（二段目）

- 炎の舌を等間隔に並べる：櫛のように見えた。線の上でも間隔を1.5倍ずらし、大きさを2倍まで散らした。
- 光のにじみを大きく強くする：朱の面積の主因（赤い円）になった。小さく弱くし、空の明かりは朱でなく生成り（彩度0.45未満）にした。
- 寺の外壁を正面から炎の光で照らす：壁一面が朱になる。光源を扉の奥へ移した。
- 煙の色を見た目の値で書く：線形0.07は sRGB で約29%の灰になり、夜空より明るい塊に見えた。
- 幟を地面に平らに寝かせる：高さ1.15mから13m先では1/11に潰れて読めない。
- 目覚めの先組み立てを `compileAsync` だけで行う：288→108msまでしか減らない（影の深さの材質が残る）。谷の全部の絵を `initTexture` で送る案は、映らない人物の絵まで送り、上映を繰り返すと画像の数が増えた。小さな絵へ描く向きを谷のカメラのままにする案は、カメラの位置で送る形が変わり、形の数が増えた。

### 残り（二段目の時点）

- C の水面と D の谷底は三段目で作り直した（§7）。人物の手（指の骨が無い）は 8.6a の範囲で、ここでは触れていない。

## 7. 三段目：2周目の講評（全体4/10）を受けた作り直し（見た目だけ）

語りの文・進行（opening.js）・仕組みは変えていない。新しい素材は使わず、谷のモデルの複製と手続きだけで作る（大道具は `opening-set.js`）。

- **C 人影**：白い粒の原因は、カメラへ向かない補間法線で縁の明かりが最大になったこと。艶のない黒（映り込み0）にし、縁はカメラを向く面の、光の側だけにした（`rimShade` と同じ式）。人数は4人から8人へ。荷（天秤棒・背負った包み・抱いた子）は胸の骨に付ける。橋の手前の岸では地面に立たせる（`figureAt`。一段目までは0.63m浮いていた）。
- **C 川面**：場面の光源を受けない手続きの水（`WaterSurface`）。波の法線で砕けた炎の照り返しと、弱い空の照り返しだけを描く。光る板は、標準の材質が鍵の光を一面に照り返したものだった。火は対岸の家2棟の屋根に付けた。
- **D 町**：眼下に手続きの家620棟（1呼出）と灯230点。燃えるのは一区画（家の約5%）と小さな火2つ。霧の層2枚と山並み（頂点の色で濃淡）。カメラを高く引き、縁を足もとへ寄せて見下ろす。岩は形と大きさを変えて肩から離し、道・小石・草むらを足した。町の方角の低い鍵の光で輪郭を照らす。
- **炎**：短い舌を多めに高さを散らし、根元の高さもずらす。`sink` で根元を屋根に埋め、`top` で先を上の帯に届かせない。根元の消え方は雑音でずらす。焼ける屋根の材質の複製には熾火の斑（ゆっくり動き、明滅しない）を足し、寺は瓦の筋も足した（`decorate`）。
- **煙**：smoke を持つ炎の足もとから出す（`particleSources`）。出たばかりは朱茶で、昇るほど暗くなる（`fx.js` に寿命の終わりの色を足した。谷の粒子の色は変わらない）。D の柱は抵抗を0.12から0.02へ下げた（0.12では25mで止まり、玉に見えた）。
- **B・A**：B は少し引き、基壇の前に瓦の付いた塀、左右に杉の木立（26本・1呼出）を置いた。石段と袖壁に切石の目地、灯籠に石の斑。A は地面の凹凸を細かく弱くし（大きな凹凸は水面に見えた）、灰の斑と瓦礫を足した。幟は竿ごと伏せて自発光を外し（赤いしみの元）、宙に浮いた藁束を外した。通りの奥と裏に家並みのインスタンス17棟。
- **共通**：空と霧は淡い生成りの煙明かり。飛ばしの案内は入力があったときだけ出し、2.5秒で消える（`game.js`）。

### 実測（三段目）と捨てた案

- 描画：A 呼出156・三角形93万、B 66・14万、C 106・111万、D 48・10万。p95：A 6.9ms、B 5.1ms、C 8.3ms、D 4.6ms。始まりの1コマ705ms（暗転の下）、目覚めの最初の1コマ28ms。
- 朱の面積：A 14.7%・18.6%、B 15.8%・16.2%、C 9.9%・10.0%、D 6.0%・5.7%。明滅は A〜D とも0回/秒。上映3回の前後で形296・画像175のまま。試験は場面の純粋層15件、変異は43件。
- 捨てた案：遠い町を谷のモデルのインスタンスで作る（1棟1.4万三角形で、600棟は予算を超える）。山並みに線形の霧をかける（霧の色に溶け、砂丘に見えた）。人影を向きに関係ない発光の輪郭で囲む（design-graphics.md で採らないと決めた）。
