# Design: 絵画的で高品質な谷の画づくり（R17）

色・形・光・絵肌・人物を一つの場面で先にそろえ、本人の方向確認から全体へ広げる。設計のみ。特定作品の再現や、全面的な素材交換を目指さない。
根拠は research-polish3.md・design-trees.md、合否は design-validation-polish3.md。

## 見立て：要素の増量だけでは一枚の絵にならない

確かめたこととして、夕景の逆光・高さ霧・空の反射・補助光、草木の風、階調と色調の後処理はすでにある。材質補正も人物・建物・地形にあるので「光も色調整もない」とは扱わない。
親の画像所見では顔・手が寄りで粗く、人物と手続きの背景で絵肌・接地・輪郭がそろわない。木の独立評価は5.1/10、目標7未達。固定13画角のうち木の採点記録は8場面で、全13枚の合格は未確認。
残る指摘は中遠景の形が平均4.0、広葉の多面体、段が反復して杉に見えない針葉樹、近景の板状の葉、溶かしの細かい網目、橙一色の紅葉（design-trees.md）。
見立てとして、形の塊と色の主従、物ごとの模様の粒度、人物への視線の集め方が弱い。霧や後処理を増やすだけではこれらを直せない。

## 画づくりの柱：現状・目標・候補の採否

| 柱 | 現状 | 目標 | 手段の候補・採否・理由 |
|---|---|---|---|
| 色の設計（17.1） | 夕景の暖色と冷たい影はあるが、場面別の台本はない | 時間帯と感情に対応した主色・影色・差し色・彩度の主従 | 色の台本を採用。まず夕景の往路と帰還を比較し、差し色は視線を導く箇所へ限定する |
| 形と3層（17.2） | 山・森は分かれるが中遠景の反復と多面体が残る | 遠景の大きな塊、中景の樹冠と家、近景の人と刃を明暗で読む | 輪郭と大小の配置を優先。カード・面の増量だけは反復を残すため採らない |
| 絵肌（17.3） | 手続きの草木・地形と本人制作の建物、AI生成人物が混在 | 地面・樹冠・布・金属・肌が同じ絵筆に見える | 筆致の方向と尺度を共通化。手続き生成を先に比較し、本人の手描き風テクスチャは補完候補にする |
| 光と空気（17.4） | 逆光・高さ霧・影はあるが人物の切離しと接地が弱い | 形を失わず、空気遠近と重さを示す | 控えめなリムライトと局所の環境光遮蔽を候補にする。輪郭線は必要箇所だけ比較し、全面の太線は保留 |
| 密度とばらつき（17.5） | 草木の群れはあるが段形と橙の反復が残る | 群れ・空き・大小に理由があり、反復を意識しない | 中遠景の樹冠輪郭と群れ内の色幅を優先。均一乱数と全域の密度増加は採らない |
| 二次運動（17.6） | 草木・水・粒子は動くが布と髪の連動が弱い | 共通の風に体の動きと遅れが重なる | 布端・髪束の小さなばねを条件つき候補にする。全身の布物理は性能と干渉管理のため採らない |
| 人物（17.7） | Meshy人物の手と顔、髪と装備の寄りに粗さがある | 表情に頼らず顔・握り・髪の束と装備を読む | 材質と局所の形の修正を先に比較。Meshy再生成は費用・骨・動作・容量の再検証が必要なため保留 |
| 仕上げ（17.8） | ブルーム・階調・色調・ビネット・粒状感はある | 暗部と肌の階調を保ち、筆致と光の意図を支える | 既存色調を基準にLUTを条件つき比較。近景の粗さを隠すぼかし・被写界深度は採らない |

## 垂直スライスで方向を確認する

1. 8.0で前値と同一条件を固定する。試す場面の例は見晴らし岩から谷を見る画角と、里の入口の戦闘画角。夕景の広域と人物・刃の両方を対象にする。
2. その場面内で色の台本→形の塊→光と接地→絵肌→人物の寄りを一組として比較する。1要素だけの豪華さを全体の完成と扱わない。
3. 後処理あり・なし、色なし、寄り、通常移動の前後を示す。本人が方向を確認してから、林道・廃寺・川岸・帰還場面へ広げる。確認前の全域変更は保留する。
4. 全体展開後も前の画角を残し、戦闘の予兆・刀・足もとが暗部や霧で失われないことをR18と共に検証する。

## 候補の評価と捨てた案

| 候補 | 採否と理由・落とし穴 |
|---|---|
| 色の台本＋LUT | 台本は採用、LUTは比較候補。色の方針を先に決め、肌と刃の白飛び・暗部の潰れがなければ検討する。昼夜の動的切替は追加しない |
| 筆致の手続き生成／手描き風テクスチャ | 同じ場面で比較する候補。前者は容量を抑えられるが模様の反復、後者は容量と出所管理が課題。画面全体のノイズを筆致の代わりにしない |
| リムライト／輪郭 | 前者を優先候補、後者は人物と刃の読みが足りないときだけ。向きに関係ない発光縁や全景の太線は光の整合を損なうため採らない |
| 環境光の遮蔽の焼き込み | 静的な接合・布の重なり・根もとの候補。照明を二重に暗くしない。動く足の接地は焼き込みだけでは済まない。全面SSAOは従来の不採用を継承する |
| 光の筋／霧の体積 | 既存の高さ霧を先に整理する。局所の光の筋は条件つき比較、全画面の高コストな体積描画は保留。林内と逆光で面の板が露出しないか検証する |
| 布・髪のばね | 限定した束と端部だけを候補にする。風の共有、休止復帰、動きを減らす設定、体や鞘との干渉を確認し、全身物理は採らない |
| 人物材質修正／Meshyでの作り直し | 材質を先に検討。再生成費用はresearch.mdに過去実測があるが現在の見積もりではない。現残高・クレジット下限500・再試行・骨入れ・動作再検証の費用を本人と確認するまで発注しない |
| 後処理で絵を統一する | 階調と色調など意図した絵作りに限る候補。解除しても形・手・接地・刀が読めることを条件にし、粗さを見えなくする目的の処理は採らない |

## 性能・容量と検証

標準p95≤20ms・軽量≤33.3ms、呼出≤900・三角形≤500万、実読み込み≤90MiBは**未測定の設計目標**として継承する。前値は標準移動15.4ms（既存記録15.5）・戦闘14.5ms、呼出757・約77MiB。
効果ごとに有無の差を測り、後処理・影・透明描画・ばね・動作と質感を同時に載せた総量で判定する。差分を単純加算して合格とはしない。R14/R15の質感2・録音3・その他0.5MiBの枠を侵食しない。
測定はM4 Pro・Chrome・1280×720・DPR1、既存8試行の契約を継承する。Safari・Firefox・実機は未確認。軽量でも主色・輪郭・接地を残し、単に霧と暗さを増やして省略しない。
固定画角と移動動画を別役が新旧を伏せて採点し、最大3周。本人が画面と実プレイで確認する。具体的な一覧・尺度は design-validation-polish3.md。

## やらないことと未確認

他作品に似せること、外部の素材の持ち込み、他作品のコード・シェーダー・数値の転用、依存・CDN・通信追加、全面再生成は行わない。外部の手本からは手法・進め方だけを借りる。
筆致の好み、時間帯ごとの色の具体値、輪郭の有無、局所AOと光の筋の効果、人物修正の範囲と費用、新方式の性能・容量は未確認。本人の方向確認と測定から候補を絞る。
