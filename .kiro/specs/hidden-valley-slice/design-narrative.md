# Design: 物語の骨格・過去の謎・掛け合い・選択・敵の事情（S1）

requirements-story.md の R19〜R21・R24 を、作れる形に落とす。本人の決定（2026-10-30）：謎の核は「門を離れた夜」で助けた相手は名のない子ども、追手は新しい政権の徴発隊、範囲は今の約20分を磨き切る、語りは古い絵巻の語り口。
話者は story-data.js の名前（榊三郎景継・穂太・久作・つばき・梓弥十郎）。本文では略して書く。台詞は一画面40字以内。数値は未測定の設計目標。2026-10-30にCodexが書き直し前の草案をコードと突き合わせ、誤り5件・抜け10件を直した。

## 1. 柱と主題

- 柱は「火→灯」。オープニングは滅びの火、結末は谷の焚き火。題名の回収文は、結末の語り「燃え残った火は、谷で、人の灯になった。」（19.1）。
- 主題は、負い目を抱えた者が、人の暮らしを守ることで生きる理由を得ること（docs/10_STORY_AND_DESIGN_JA.md の葛藤に沿う）。
- 台詞で説明しない。景継は多くを語らず、袖印・視線・間（無言1.5秒）で見せる。

## 3. 過去の謎「門を離れた夜」（R20）

**真相**：鎌倉の最後の夜、景継は裏門を任されていた。門の近くで泣いている子を見つけ、持ち場を離れて山へ逃がした。戻ったとき、門は破られていた。名も知らない子。守る相手を選んだことが、負い目になった。
意味：弥十郎の「先に逃げた」と鏡になる。景継の「悔いるなら、生きて償え」は、自分にも向いた言葉になる。穂太を見る目が、少し変わる。

| 断片 | 場所・形 | 内容（案） |
|---|---|---|
| F1 | 廃寺の庭・物（E） | 焼け焦げた袖印。景継「……あの門を。」 |
| F2 | 見晴らし岩・景色（E「遠くを見る」） | 景継「あの夜、持ち場にいなかった。それだけは、確かだ。」 |
| F3 | 里・久作（village_cleared の2行目） | 「逃げてきた武士は、あんたで三人目だ。皆、同じ顔をする。」 |
| F4 | 倉の裏・弥十郎（archer_joins） | 弥十郎の「先に逃げた」の後に、景継「……私もだ。」を足す |
| F5 | 帰り道・弥十郎（ambush_cleared の末尾） | 「……あの夜、門に貴殿の姿がなかった。」景継は答えない（間1.5秒） |

F1・F2は、会話の枠（`startDialogue`）で出す。字幕の設定に依らず出る。F3〜F5は、既存の会話に足す。

**結末（b7）**：拾った断片の数（0〜2／3〜4／5）で、台詞が深くなる。真相の3行は、断片が0でも必ず出る（20.3）。
- 共通：景継「あの夜、門を離れたのは、泣いている子がいたからだ。」弥十郎「……その子は。」景継「山へ逃がした。名も知らぬ。」
- 3〜4個：弥十郎「ならば、離れてよい理由だ。」景継「……そう言うのは、お前だけだ。」
- 5個：景継が袖印を焚き火にくべる。「もう、いい。」穂太を見る間（1.5秒）。**袖印を燃やす演出は案（本人の確認前）**。
- 続きへの引き（19.3）：弥十郎「橋の向こうに、追手の本隊がいるはずだ。」景継「……明日、考える。」

**保存**：拾った断片の id の配列を、quest の状態（`flags`）に持たせる。`snapshot`・`export`・`restore` と、保存の `sanitize` の許可リストへ足す（追加の項目は現行 `sanitize` で落ちる。save.js・quest.js）。旧い保存は、項目が無ければ空の配列。版番号は上げず、任意の項目として読む。やり直しでは、区切りの保存に戻るので、あとから拾った断片は拾い直せる（二重に数えない）。

## 4. 掛け合い（R21.1）

目標は約24本。主人公ひとりの間（b0〜b5）は独り言と里の人の言葉、弥十郎が加わる b6 からが掛け合い。
- 出し方：条件（場所・出来事・同行者・信頼・選んだ道）を持つ data。字幕の枠は一つで、新しい字幕が前を即座に上書きする。そこで優先を決める：掛け声＞掛け合い＞ヒント。戦闘中・会話中・ヒント表示中・掛け声の表示中は、掛け合いを出さない。同じ台詞は一度だけ、前から8秒空ける。字幕の設定がOFFなら出さない（断片は別の枠で出るので影響しない）。
- 例（案）：b0 景継「……生きている。まだ。」／b2 景継「穂太の言った兵は、この先か。」／b6 弥十郎「この脚では足手まといだ。置いていってもいい。」景継「置いていくなら、拾いに来た意味がない。」
- b6 の里の信頼（高≥58・中≥48・低）で言い換え：高「里の者は、我らを見送ってくれたな。」／中「まだ、様子を見ているようだ。」／低「武士は要らぬ、か。」景継「それでも、守る。」
- 遺物（E）の案内は、とどめ・闇討ち・縛めを解く、より後。気づいた敵が近くにいるときは出さない。

## 5. 選択と結果（R21.2）

選択は既存（正面／脇道。見晴らし岩）。代償は、既存の台詞「戦が長引けば、倉が荒らされる」「時はかかるが、見つかりにくい」で、選ぶ前に伝わっている。足すのは、結果が後に現れる3か所。条件は quest.js の既存の値を使う：`approach`（front／flank）、食糧（≥50・≥35・それ未満）、信頼（≥58・≥48）。
1. 里の戦いのあとの久作の第一声：正面で食糧35以上「あんたの戦で、畑が踏まれた。……それでも、倉は残った。」／正面で食糧35未満「畑も倉も、ひどく荒れたな。……皆、生きてはいる。」／脇道で食糧50以上「いつの間に片づけたのか。足音も聞こえなんだ。」／脇道で食糧50未満（既存の `flankLoud` と同じ条件）「静かに、とはいかなんだか。倉が荒れた。」
2. 里の荒れ（柵の倒れ・煙・散った荷）を、`approach` と食糧で出し分ける（見た目だけ）。
3. 焚き火の輪との距離が、信頼で変わる：高は輪の内側、中は外縁、低は少し離れて立つ。久作とつばきは話者なので、低でも画面に残す。

## 6. 敵の事情（R21.3）

素性は決定：新しい政権の徴発隊。旧幕府方の残党を追い、兵糧を集める命令を受けている。兵も飢えている。史実の人名は出さない。
**必ず見える手がかり**（出来事で出す。ランダムに頼らない）：
- C3 侍大将が最初に気づいたとき、字幕で「新しき世の命だ。蔵を空けよ。恨むなら、恨め。」（敵の一言。掛け声ではない）。
- 結果の会話（result）に一行：弥十郎「あの兵たちも、腹を空かせていた。」
**任意・ランダム**：
- C1 物見の落とし物（兵糧の書き付け）。Eで拾う。景継「兵糧の書き付け。腹を空かせた兵か。」
- C2 里の兵の掛け声「米を出せ。腹が減った。」。投降時の掛け声に「すまぬ……帰る所がない。」。掛け声は14字以内（`tests/valley-world.test.mjs:209`）。`barks` はランダム・距離制限・共通の待ち時間があるので、手がかりの保証には使わない。
言葉：画面に出す語は、公的資料で裏取りした範囲にそろえる（出典は design-opening.md §8）。「斥候」は画面に出さず「物見」。「割り符」は為替の意味もあるので「書き付け」。一般の兵に「足軽」は使わず「兵」。「侍大将」「兵糧」は使える。戦闘の規則は変えない。

## 7. データの形と検査（R21.4・R24）

`story-data.js` に足す：`banter`（id・when・lines・once）、`fragments`（id・場所・形・内容・順）、`relics`（id・位置・案内文・断片id）、`clues`（id・種類・条件・文）。遺物の「調べる」は `updatePrompt()` と `worldInteract()`（game.js）に足す。
検査（純粋層）：id の重複、どこからも呼ばれない台詞、40字超（掛け声は14字超）、未知の話者、条件が一度も満たされない台詞、断片idの欠け、旧保存が読めること、やり直しで断片が二重にならないこと。体験評価（R24.1）は tasks-story.md の S8。会話の長さ（R24.2）は、1回あたり約5行まで（行送りが既存の「飛ばす」操作）。
