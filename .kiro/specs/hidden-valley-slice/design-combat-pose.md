# Design: 被弾・弾かれ・倒れの姿勢と、弾いた瞬間の案内（8.3b）

8.4a・8.5a の別役の盲検採点で、姿勢（K5）は2周とも4点で止まった（`reports/polish3/combat-impact/README.md`）。そこで挙がった弱点のうち、見た目だけで直せるものを扱う。
戦闘の規則・入力・停止とスローの長さ・論理の位置・共用の乱数・音は変えない（R18.9）。数値は M4 Pro・Chrome・seed 1333 の実測。
要件は requirements-polish3.md の R18.3・R18.4・R18.9、上位の設計は design-combat-presentation.md、タスクは tasks-polish3.md の 8.3b。

## 腕の開きの上限（`arm-spread.js`・`characters.js` の `spreadArms`）

開き＝腕全体（肩→手首）と、胴の下向き（首→腰）のなす角。0度は体の横に下がった腕、90度は水平、180度は頭の上。
`tools/scenarios/measure-arm-spread.mjs` で、斥候の模型に動作を当てて毎コマ測った（変更前）。

| 動作 | 使う所 | 開きの最大（左／右） | 60度を越えたコマ |
| --- | --- | ---: | ---: |
| dying_backwards（die） | 倒れ・とどめ | 108／107度 | 226（150コマ×2本のうち） |
| dying（die2） | 倒れ・とどめ | 93／111度（始めの1〜3コマだけ） | 5 |
| Hit_Reaction_1（hit2） | 被弾（三段目・強い技）、鎧でひるまない一・二発目の見た目 | 108／110度（始めの0.1秒） | 67（40コマ×2本） |
| Hit_Reaction_to_Waist | 弾かれた敵 | 104／113度 | 85（50コマ×2本） |

dying_backwards は、倒れ始めてから地面に寝るまで、左腕を水平より上へ広げたままにする。別役の言う「両腕を真横へ水平に広げたまま倒れる」はこれ。
「三段目のあと両腕が頭の上へ跳ね上がる」は、被弾の動作の終わりではなく始めの0.1秒の形だった（命中の停止が、その形を4〜5コマ止めて見せる）。

- 方式：動作の骨を当てたあと、開きが上限を越えた腕だけ、腕と胴の下向きを含む面の中で上腕の骨を胴の側へ回す。横へ広げた腕は体の横へ、前へ上げた腕は前の下へ下りる。
  胴の向きを基準にするので、倒れて寝た体でも、地面に沿って腕が体へ寄る。
- 効き：上限をかけたコマで1、外したら毎秒18の指数で0へ戻す（反応が終わって腕が1コマで跳ばない）。かけるときも追う案は、命中の停止の間ゲームの時間がほぼ止まるので効きが上がらず、
  腕が跳ね上がる始めのコマをそのまま見せた（三段目のコマ64で効き0.45）。
- 上限：倒れた人（主人公・敵とも）は40度。55度では、真横のカメラで腕が前へ突き出たままに見えた。被弾（論理の hit と、見た目の被弾の0.3秒）は50度、弾かれ（recoil）は55度。
  被弾を70度にした周では、上限は効いていた（コマ64で左18度・右7度寄せた）が、肩の骨が首の近くにあるので手首が顔の高さに残った。
- 順序：`relaxArms` のあと、抜刀の層・握りの層（8.6a）の前。握りの層は見える腕の写しを動かすので、寄せた腕の上で握る。
- 副作用（本人の確認待ち）：鎧でひるまない一・二発目は、構えたまま当たった停止の最初のコマで、構えの腕が約35度下がり刀が下を向く。弾かれた敵も同じく、打ち合ったコマで刀が下がる。
  停止の閃きと同じコマで起きるので「構えが崩れた」と読めるが、刀の位置が1コマで変わる。
- 直せなかった物：弾かれの終わり（D のコマ58）に刀が頭の上へ上がる形は、腕の開きではなく手首のひねりなので、この層では変わらない。
- 実測（層あり）：記録は `reports/polish3/combat-pose/arm-spread.json`。数値は同じ README。

## 捨てた案と理由

| 案 | 捨てた理由 |
| --- | --- |
| 開きを模型の前後・左右の軸で測る（`relaxArms` と同じ） | 倒れる間は胴が後ろへ傾くので、模型の軸では「上げた腕」と「寝た体の横の腕」を分けられない。胴の向きを基準にした |
| 上腕（肩→肘）で測る | 肘が肩の高さでも、前腕が立って手が頭の上へ出る形を見逃す（被弾の動作で上腕79度・腕全体110度） |
| 倒れの動作を die2（腕が下がる）だけにする | 共用の乱数で選ぶ2種の割合が変わり、乱数を引く回数か、選ばれる動作を変えることになる。見た目の層で直す |
| 骨の角度を表で直に置き換える | 動作ごと・コマごとの表が要り、倒れの途中の揺れが消える。上限を越えた分だけを寄せる |
