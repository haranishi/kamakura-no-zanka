## コードで確かめたこと：抜刀・納刀と反応

| 対象 | 確かめた流れ・数値 | 設計に残す問題 |
|---|---|---|
| 抜刀 | anim-data.jsにdraw＝Katana_Draw_v2（2.9667秒）。actors.jsからdrawの動作再生なし。攻撃開始→攻撃動作→draw音→drawn=true→手の刃を表示・腰の柄を非表示 | 鞘口を通る過程がない。受けの開始（待ち4秒）と闇討ちにも同じ表示切替があり、この2つではdraw音が鳴らない（鳴るのは攻撃の開始だけ） |
| 納刀 | sheathe＝Katana_Sheathe（2.9667秒）も表のみ。攻撃の開始から4.5秒（終わりから数えると弱1で約4.0秒、強で約3.4秒）の待ち、戦闘中は残りを2.5秒以上に保つ。戦闘外・待ち0・idle・非防御で刃を隠し、腰の柄とsheathe音を出す | 戦闘中2.5秒で納刀する意味ではない。動作と刀の移動が結ばれていない |
| 武器 | weapons.jsは刃を断面5点の輪、鞘を曲がる管、柄・鍔・鎺を円柱中心で構成 | 形の存在と戦闘画角での読みやすさは別 |

| 死 | die＝dying_backwards 2.2333秒／die2＝Fall_Dead_from_Abdominal_Injury 3.5秒を乱数選択。主人公1.1倍、敵1.25倍 | 切り方との対応がない。敵は死の開始から0.3秒（ゲーム時間）後に刀を落とす（着地完了の0.3秒後ではない） |

## コードとNodeで確かめたこと：技の使用区間

combat.jsの時間割、anim-data.jsの対応と区間、dist/assets/characters/clips.jsonの69動作を照合した。秒と倍率は小数2桁、割合は整数へ丸めた。
「技秒」は予備＋当たり＋戻り。「区間」は元動作の秒、「割合」は区間長÷元動作長で、姿勢の良さを表す値ではない。

| light2 | Katana_Gyakukesa_Cut | 1.97 | 0.53 | 0.00–0.97 | 1.78 | 49% |

敵は個体ごとに全動作を0.94〜1.06倍で再生するので、敵の実効の倍速は表の±6%になる（soldier_thrustは約0.56〜0.64倍）。
ally_shotもarcher_shotと同じ区間・時間・速さ。表示側はMOVE_CLIPSが正で、combat.jsのclip名と異なる兵・大将の技もある。
近接の使用割合は28〜56%。通常の速さの制限は1.1〜2.2倍だが、先頭不足時は0.6倍まで下がるため「全技が早回し」ではない。弓は放ちを直接指定する別経路で2.22倍になる。
弱1は0.17＋0.10＋0.26＝0.53秒。手首の速さの山を当たりへ合わせて切るため、溜めと残心が失われるというのが見立て。手首の山は刀の接触そのものを測った値ではない。

再現はルートで次の1手順を実行する（表の丸め前の値も得られる）。

```sh
node --input-type=module <<'JS'
import fs from 'node:fs';
import { MOVES } from './dist/valley/combat.js';
import { MOVE_CLIPS, CLIP_SEGMENTS, segmentFor } from './dist/valley/anim-data.js';
const { clips } = JSON.parse(fs.readFileSync('dist/assets/characters/clips.json'));
for (const [id, { clip }] of Object.entries(MOVE_CLIPS)) {
  const m = MOVES[id], meta = clips[clip], s = segmentFor(meta, m, CLIP_SEGMENTS[clip]);
  console.log(id, clip, meta.seconds, m.windup+m.active+m.recover, s.from, s.to, s.speed, (s.to-s.from)/meta.seconds*100);
}
JS
```

## コードで確かめたこと：当たりと間

| 対象・根拠 | 現行値・有無 |
|---|---|
| fx.jsの火花と光 | 通常10・強18・受け12粒＋0.09秒の光、弾き22粒＋0.11秒の光。土煙あり、血なし |
| 刃の軌跡 | trails配列の初期化だけで追加・描画なし |
| battle.js・camera-rig.js | 当たりのkick要求0.25〜0.7、punchFov要求0.8〜3.2°。kickは設定と累積制限を経る無単位量で、移動距離ではない |
| config.js・game.js | ヒットストップ：通常0.07・強0.10・弾き0.09秒、時間の進み5%。受け0.056秒、揺れ設定0なら持続半分 |
| 演出の区別 | 命中連動の寄り・追加の軽いスロー・画面全体の色調変化なし。主人公の被弾では画面の縁が90ms赤くなる（battle.js→hud.hurt）。既存の短い5%進行とロック構図はある |
