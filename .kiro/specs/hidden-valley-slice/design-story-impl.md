# 実装の記録：物語の本体（S5・S6）

design-narrative.md §3〜§7 を実装した記録。2026-10-31〜11-01、枝 `feat/story-body`。設計書そのものは変えていない。
決めたこと・捨てた案・実測だけを書く（コードで分かることは書かない）。

## 1. 採った方式と理由

- **台詞はすべて story-data.js（data層）**。行に `when`（場面・場所・出来事・道・信頼・食糧・断片の数）、`pause`（無言の間）、`look`（見つめる相手）、`fragment`／`clue`（その行が出す断片・手がかり）、`narration`（語り）を持たせた。掛け合いも会話の行も、同じ条件の読み方（banter.js の `matches`）で選ぶ。
- **断片は「会話が出た時点」で拾ったことにする**（quest.js）。会話は一度キューに入ると、やり直し（状態ごと区切りへ戻る）以外では必ず表示されるので、表示の瞬間に数えるのと同じ。こうすると、断片の記録が Node だけで試験できる。捨てた案：HUD が行を出すたびに知らせて数える（ブラウザがないと試験できない）。
- **保存**：`flags.fragments`（物語の順の並び）と `flags.seen`（里で見つかったか）。どちらも版は1のまま、無ければ空・見つかっていないとして読む。壊れた値は、ほかの項目と同じく保存ごと退ける。`seen` は任務の状態では `flags` の外に置いたまま（既存の規則と試験に合わせた）。
- **結末は三つの会話**（result → ending_truth → ending_coda）。1回あたり約5行（R24.2）に収め、間で画角を切り替える。真相の3行は断片0でも出る。断片3以上で弥十郎とのやり取り2行、5で「もう、いい。」と袖印をくべる演出（炎が1.8秒高く上がる。音なし）と穂太を見る1.5秒。
- **字幕の優先（掛け声＞掛け合い＞ヒント）の解釈**：戦闘・会話・掛け声や侍大将の一言の表示中・字幕OFF・演出カメラ・暗転のときは、掛け合いを出さず、始まっていた掛け合いも切る（戦闘か会話が始まったら字幕も消す）。案内（ヒント）の表示中は新しい掛け合いを始めないが、始まった掛け合いは最後まで出す。急がない「G で導きの風」の案内は、掛け合いが出番を待つあいだ譲る。場面の変わり目の操作案内（屈む・弥十郎への指示）は遅らせない（操作を先に知らせる）。
- **侍大将の一言（C3）**は、里の戦いで侍大将が初めて戦いの状態に入ったコマで出す。「気づいた」出来事は使わない（正面から入ると、敵は出来事なしで戦いの状態になる）。字幕なので、字幕OFFでは出ない。
- **掛け声（C2）**：「米を出せ。腹が減った。」は、まだ気づいていない里の兵が荒らしながら上げる声にした（近づくと出る。14秒おき3回まで。乱数は使わない）。気づいた瞬間の声に混ぜる案は捨てた（斬りかかる相手に米を求める形になる）。投降に「すまぬ……帰る所がない。」を足した。
- **袖印は焚き火の石の縁**に置いた。庭は背の高い薄（実測：密度約1.1、高さ約1.1m）に覆われ、目覚めた場所の地面に置いた布は撮影で見えなかった。火のまわりだけ草がない。見つけた火に、5つ拾った結末でくべる対になる。
- **見つめる間**は、体ごと相手へ向け（毎秒4ラジアンまで）、画角を寄せるだけ。首の骨は動かさない（動作が書き直さない骨に後から手を入れると残る。メモリの罠の記録）。子が2m以上離れていれば肩越し、すぐ隣なら焚き火と反対の側から二人を横に撮る（肩越しは主人公の背で子が隠れた）。
- **焚き火の輪**：信頼が高い（58以上）と里の人3人が内側（0.78倍）に座り、中は外縁（1.0倍）に立ち、低い（48未満）と1.8倍離れて立つ。久作とつばきは話者なので動かさない。穂太は主人公の右隣に立つ（座らせると、見つめる間の画で子の顔が会話の枠に隠れた）。
- **結末の画角**：真相は火の北から二人を（火の北東2.6mの大きな茂みを外す）。結びは低く火越しに主人公を撮り、炎を会話の枠より上に置く（くべた袖印の炎と最後の語りが、火の上に重なる）。
- **里の荒れ（§5.2。見た目だけ）**：帰り道（b5〜b6）に、蓄えが50未満なら荷車のあたりから細い煙、35未満なら太い煙。柵の倒れ・散った荷は作っていない。

- **第2周の評価（盲検・Opus）で直したこと**：結果の久作の一言を信頼で3通りに（歓迎が結果画面の信頼と食い違った）。脇道は「見つかったか」で言い分ける（静かでも時がかかれば蓄えは50を割る。実測：5人が荒らすと毎秒0.2）。結果文にも「見つからずに時がかかった」場合の行（flankSlow）を足した。F2 を「あの夜、門を背に、山へ走った。」に（逃げたように読め、結末の「山へ逃がした」で意味が返る）。C1 を「取り立てが、多すぎる」に。結びの「ここが、帰る場所になる。」を「……飯にしよう。」に（主題は語りに任せる）。道中は「重荷→道→信頼」、待ち伏せのあと「詫び→穂太」の順にし、弓の一言は削った。目覚めの一言だけは操作の案内と並んで出す（overHint）。結末の間は体力・構え・目的を隠し、会話が始まると案内を下げる。袖印は手から火へ落ちる絵を足した。
- **評価の指摘で、直さず残したもの**：結末の段の境目（設計は3以上。評価は「F3〜F5 は必ず拾うので4以上に」）。侍大将の一言の字（「命」「蔵」。依頼の文のまま）。既存の台詞の読み（「待て、降る」「西の口」と目的の「南の林道」）、弥十郎の傷（腕と脚。既存の台詞と足を引く歩き方のまま）。

## 2. 実測

- 掛け合い23本（言い換えの組5つ）。会話11（新しいのは ending_truth・ending_coda・relic_sode・relic_far_look・clue_scout_note）。条件つきの行13、無言の間3。一画面40字・掛け声14字を全行で守る（検査が見る）。
- 単体試験：全576件合格（物語は16件。うち1件は、検査がわざと壊したデータの17種の誤りをすべて報告することを確かめる）。変異試験 `node tools/verify-story-mutations.mjs`：25件すべて検出。
- 検査：`tools/lib/story-check.mjs` を `tools/check-valley.mjs` から呼ぶ（id の重複・40字（掛け声14字）・未知の話者・条件の書き間違い・一度も満たされない条件・久作の第一声が各場合に一つ・断片idの欠け・呼ばれない会話・画面に出さない語）。
- 実ブラウザ `tools/scenarios/regress-story.mjs --strict`：合格。戦闘の論理 `regress-attack-timing`：変更前と320コマ一致。既存の回帰（つづきから・里を守った瞬間の会話・やり直しの漏れ・矢で倒れる）：合格。
- 保存の互換：断片の項目がない旧い保存は空として読め、つづきからの結末は真相3行だけになる（試験と実ブラウザで確認）。

## 4. 既知の限界・残り

- 新しい遊びでは F3〜F5 は必ず通る会話に入るので、断片の数は3〜5になる。0〜2 は、この変更より前の保存からつづけたときだけ。0〜2 だけの台詞はないので、使われない台詞は生まれない。
- 掛け合いの「一度だけ」と読んだ書き付けは保存しない。つづきからでは、いまの場面の掛け合いがもう一度出ることがある。
- 里の荒れは煙だけ（柵の倒れ・散った荷は未実装）。
- 調べると、主人公は対象へ瞬時に向き直る（画角の寄りに隠れる）。
- `hud.startDialogue` に第4引数（行ごとの知らせ）を足し、`game.js` の会話の開始・終了・`updatePrompt`・`worldInteract` を変えた。kz-opening と同じ関数に触れるので、統合時に突き合わせる。
- 袖印をくべる演出は設計で「案」のまま（本人の確認前）。
