# 要件：節目の演出（シネマティック）

2026-11-03の依頼・独立レビュー・本人の決定を反映した追補案。シネマティックは、カメラ・人物・字幕で節目を見せる短い演出。
今回は文書の修正だけ。以下の数値は受け入れ目標で、実装・実測・合格の記録ではない。

## 前提と決定

- 「残火の鎌倉」は1333年の信濃の架空の谷が舞台。現行は第一章の約20分、全体構想は5章。R18〜R24を継承する。
- 決定：最新の高グラフィックで動きの細かい演出を目標とし、アニメ4種類すべて、節目だけ5〜10秒・飛ばせる形、断片5個で袖印を燃やす結末を採用する。
- 決定U1：約20分の帰還を今回の区切りとし、「第一章完結」は表示しない。橋・山砦の制作時に正式な章末へ作り直す。
- 決定U2：大将前編は初めて戦闘に入ったときに流す。闇討ちで決着したときは流さない。
- 決定U3：台本・絵コンテは既存の文を組み直し、最小限で早く作る。あとから修正できる形にする。
- 決定U4：性能端末は今のMac（M4 Pro）とChrome。電源接続・1280×720・画素比1など既存条件を継承する。
- 決定U5：大将前編は、攻撃・被弾・回避の途中を避け、落ち着いた瞬間まで最大3秒待つ。過ぎたら出さず、待機中に闇討ち・決着となれば取り消して後から上映しない。
- 決定U6：動く絵の紙芝居は、大将後編（里を取り戻した後）の枠内に1例置く。
- 決定U7：章末の既存7行は、一部を手送り（押して進める）会話へ移し、自動で流れる部分を10秒以内にする。
- 決定U8：演出直後の手送り会話は別枠で数える。自動部分だけ10秒以内とし、手送りは自分のペースで読めて、いつでも飛ばせる（時間の上限は付けない）。
- #32はmainにマージ済みで章頭を担う。通常52.2秒・短縮15.7秒はR24.2の10秒原則の例外（長さはR22で定義）。冒頭は重ねて作らない。
- EARS（条件・出来事・応答をそろえる要件の書式）で記す。以下の主体はゲームとし、検証・制作の主体だけ別に示す。

## R25 節目と対象

25.1 常に、ゲームは演出の表に章番号と開始・終わりの区別を持つ。後続章の空の場面は作らない。
25.2 第一章を新しく始めるとき、ゲームはmainの#32の冒頭を1回だけ出し、別の章頭演出を足さない。
25.3 約20分の帰還で結末に達したとき、ゲームは「滅びの火から守る灯へ」を結ぶ今回の区切りを出し、「第一章完結」とは表示しない。
25.4 対象の出来事が成立したとき、ゲームは侍大将の前・後、弥十郎の救出、待ち伏せ撃退後の4区間を出す。前編は決定U2・U5に従う。
25.5 通常移動・通常攻撃・対象外の戦闘の間、ゲームは追加演出で操作を止めず、combat.jsの戦闘規則・難度・当たりを変えない。

## R26 長さと飛ばし方

26.1 新しい演出を自動再生するとき、ゲームは休止を除く準備開始から復帰完了までを5〜10秒に収める。暗転・画角移行も含め、例外は#32だけとする。
26.2 開始から0.6秒以降、ゲームはE・Space・左クリックで飛ばせる案内を出す。通常は新しい押下で受け付ける。
26.3 戦闘中に自動開始した演出では、ゲームは開始後に飛ばし3操作をすべて離したあと、新たに0.6秒長押しした操作だけを飛ばしとする。開始前からの押し続け・攻撃連打では飛ばさない。
26.4 飛ばしが成立したとき、ゲームは次の描画で反応し、0.6秒以内に操作・後続会話・結果の所定の復帰先へ戻す。入力は消費し、次の攻撃・回避・調べる・行送りへ渡さない。
26.5 操作へ戻さず演出を続けるとき、ゲームは自動部分の合計を10秒以内にする。直後の手送り会話は別枠とし、停止時間を計測して残す（決定U8。上限は付けず、いつでも飛ばせる）。

## R27 結末と4種類のアニメーション

27.1 断片F1〜F5を全部集めた結末では、ゲームは袖印が手から火へ移る因果と、その後に景継が穂太を見る動きを同じ章末の枠内で見せる。
27.2 断片が5個未満なら、ゲームは燃焼を出さず、0〜2個でも既存の真相3行、3〜4個では受け止める会話を伝える。取得条件・個数は変えない。
27.3 新しい遊びで必ず通る節目では、ゲームは紙芝居・短い3D・人物の身振り・景色の動きを各1例以上使う。任意の断片取得に依存させず、停止回数も増やさない。紙芝居は大将後編の枠内に置く（決定U6）。

## R28 音・文字・動きを減らす設定

28.1 音量0・通常字幕OFFでも、ゲームは理解に必須の文と次の目的を表示する。必須文は1画面40字以内、文字と背景の明暗比は4.5対1以上にする。
28.2 OSの「動きを減らす」（prefers-reduced-motion）が有効な間、ゲームはカメラ移動・絵の移動・飾りの揺れを止め、代表姿勢と字幕で同じ内容を伝える。検証担当はブラウザの模擬設定でも切り替える。
28.3 「画面の揺れ・衝撃」が0の間、ゲームは追加の揺れや瞬間的な画角変化を出さず、出来事と字幕を保つ。
28.4 常に、ゲームは明滅を1秒3回以下とし、R18.11・R23.3の血と残酷表現の制限を守る。

## R29 進行・保存・再上映

29.1 演出が操作を止める間、ゲームは戦闘の時間・敵味方の判断・矢・接触の押し出し・米の減少・任務タイマーを止める。演出用人物とカメラだけを別の時計で動かし、休止・画面非表示ではその時計も止める。
29.2 完走・飛ばしで復帰するとき、ゲームは停止中の戦闘状態を保ち、同じ任務・断片・仲間・資源・敵の結果へ戻す。既存の加入・回復・保存・終了は各1回だけ処理する。
29.3 章末を完走または明示的に飛ばして終了したとき、ゲームは進行とは別キーへ章末の完了を記録する。版1の任意項目として扱い、古い保存を壊さない。中断・表示失敗だけでは完了にしない。
29.4 「続きから」のとき、ゲームは冒頭と通過済みの節目を出さない。ただしcp_result（帰還の保存）で章末が未完了なら章末を出し直し、完了済みなら出さず結果へ進む。旧保存の完了記録欠落は未完了とする。
29.5 区切りへやり直すとき、ゲームは再生と予約を破棄し、任務を区切りへ戻す。再び成立する節目は新しい試行で1回出し、冒頭は出さない。
29.6 結果の「もう一度」または「はじめから」のとき、ゲームは章末の完了記録を含む今回の上映記録を初期化する。冒頭の記録openingSeenは保持し、#32は既存どおり短縮版にする。
29.7 演出や記録の読み書きに問題があるなら、ゲームは専用表示を片づけ、成立済みの任務を保って復帰する。保存不能は知らせ、未成立の勝利・救出を映像だけで成立させない。

## R30 高品質を判断する物差し

30.1 別役が新旧を伏せて採点するとき、各演出は下表の該当する各項目で10点中7点以上を得る。写らない項目だけを対象外と記録し、未確認は合格にしない。

| 項目 | 見る点 |
|---|---|
| カメラの動き | 主役が読め、入りと戻りが滑らかで、壁や草で隠れない |
| 光と空気 | 火・煙・霧・影が同じ場に見え、白飛び・黒つぶれで主役が消えない |
| 人物の演技 | 視線・身振りが気持ちを伝え、接地・接触・姿勢のつながりが自然 |
| 動きの細かさ | 布・髪・炎・粒の二次運動（主動作に伴う細かな動き）、間とリズムが自然 |
| 色 | 朱・墨・生成りの方針に沿い、炎・人物・字幕を見分けられる |
| 仕上げ | ちらつき・貫通・足滑り・残る字幕がなく、遊びとの接続が自然 |

30.2 採点するとき、評価担当はdesign-validation-polish3.mdの尺度（5＝現状、7＝商業の大作の最低線、9＝本人が水準到達と認める）を使う。同じ自作場面・時刻・乱数の種・品質の全尺と固定画像、匿名の比較順・点・欠点を残す。9は本人確認を要する。
30.3 全体を受け入れるとき、評価担当はR24の体験10項目・16点以上・0点と未確認なしを確かめ、本人の通し遊びを残す。進行不能・保存損失は点数によらず不合格。改善は最大3周、同じ失敗2周で残件を返す。

## R31 描画・性能・公開前の検査

31.1 演出と復帰を描く間、ゲームは影・後処理を含む画面全体で呼出900回・三角形500万以内を守る。p95（95%のコマが収まる時間）は標準20ms以内・軽量33.3ms以内、実読込は90MiB以内にする。
31.2 性能を判定するとき、検証担当は決定U4の条件で各演出を標準4回・軽量4回の計8試行、演出用の暖機（測定前の予備再生）なしで準備開始から復帰まで測る。各試行の準備・本編・復帰のp95、最初のコマ、最大値を残し、各上限を満たす。
31.3 準備済みの同じ演出を3回繰り返したとき、ゲームは終了後の専用の形・画像の数を増やさず、共有資源を壊さず、谷の描画負荷を同条件の基準へ戻す。
31.4 公開候補を検査するとき、検証担当は公開前でも本番と同じ配布物・経路・設定で流せる公開ゲート（公開条件で合否を決める検査）を使う。失敗・未確認は公開可としない。

## R32 公開OSSと後続章の境界

32.1 常に、制作担当はコードMIT・新しい絵と物語CC BY 4.0を守り、生成方法と出所を記録する。外部素材・依存・フォント・外部通信の追加は0件とし、既存部品と手続き生成（計算で作る方法）を使う。
32.2 常に、制作担当は手本から方法だけを学び、コード・シェーダー（描画の計算）・数値・生成データ・素材を持ち込まない。他作品の構図・衣装・台詞・固有演出を写さず、追加する公開面に実在の商標・人物名を出さない。
32.3 後続章を作るとき、制作担当は章の筋・要件・設計を先に確定してから内容を作る。今回は章番号を持つ共通の枠までとし、橋・山砦の制作は含めない。
