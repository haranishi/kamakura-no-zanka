# Requirements: 隠れ谷の縦切り（第一章の一部）

## Introduction
プレイヤーは榊三郎景継として廃寺を出て、林道を偵察し、水穂の里を追手から救い、負傷した弓手と廃寺へ帰る。
10〜20分で完走できる三人称アクションの縦切り。根拠は企画書 v0.1 §9「最初の試作」と、2026-10-27の
「実際のマップ・人物を高い品質で、戦闘とアニメーションを加え、ハーネスで改善を続ける」依頼。
物語と設計思想は docs/10_STORY_AND_DESIGN_JA.md。
2026-10-27のプレイ後の評価（草木・音・道しるべ）は requirements-polish.md（R14〜R16）。1.2・3.1・12.1は、その範囲で上書きされる。第2弾の13.2の測定条件は design-validation.md を正とする。

## Boundary Context
- 対象: 新しい入口 `/valley/`。既存の庭のしごと（`/`）は回帰検証のため残す
- 含む: 地形・風景・建物・人物・戦闘・敵と仲間の判断・任務と分岐・保存・音・UI
- 含まない: 橋の関所・山砦・仲間5人・広域行軍・騎乗・天候変化・モバイル/タッチ・マルチプレイ・公開デプロイ
- 数値の目標は未測定の設計目標。実測した環境と未確認の環境を必ず分けて書く

## Requirements

### Requirement 1: 説明なしで目的が分かる
1.1 開始したとき、本作は廃寺の縁側から谷を見せ、最初の目的を一文で示す。
1.2 目的の場所が遠いとき、本作は方角と距離を示し、任意で隠せる（道なりの案内はR16）。
1.3 初回の廃寺から村の見晴らしまでに、移動・視点・調べる・屈む・戦う各操作を一度ずつ使う場面を置く。

### Requirement 2: 一つながりの谷を歩ける
2.1 本作は廃寺・林道・見晴らし岩・水穂の里・棚田・清瀬川の岸を、読み込み画面なしでつながった地形として歩ける。
2.2 本作は遠景に橋と関所、対岸の山砦、稜線を置き、将来の広がりを見せる（入れない場所は理由が分かる）。
2.3 歩ける範囲の端・水・急斜面・建物・木・岩に触れたとき、本作は貫通せず沿って滑らせる。
2.4 カメラが木・壁・斜面に隠れるとき、本作はカメラを手前へ寄せ、主人公を見失わせない。

### Requirement 3: 絵が企画の夕景に近い
3.1 標準品質で、本作は斜光と影、山霧、空気遠近、風に揺れる草木、流れる水、焚き火と煙を表示する（草木の水準はR14）。
3.2 本作は空・霧・環境光・水面の色を同じ大気の設定から取り、地平線に継ぎ目を出さない。
3.3 本作は固定画角（8構図以上）を同じ乱数と時刻で撮り直せる。改善の前後を同条件で比べられる。
3.4 軽量品質と「動きを減らす」設定で、本作は装飾と動きを抑えても遊べる。

### Requirement 4: 人物が実在の3Dモデルで、複製に見えない
4.1 本作は主人公・弓手・敵3種（雑兵・弓兵・侍大将）・村人3種（男・女・子）を、骨入りの3Dモデルで表示する。
4.2 同じ型の人物を複数置くとき、本作は服の色・小物・体格・動作の位相をずらし、同時に同じ動きをさせない。
4.3 生成素材は出所・生成条件・日付・利用条件を台帳に残し、他作品の人物・衣装・ロゴに似せない。

### Requirement 5: 動きが連続して見える
5.1 本作は歩き・走り・停止・方向転換・構え・攻撃・受け・回避・被弾・倒れる・起き上がる・生活動作を、遷移を挟んで再生する。
5.2 本作は刀・弓・矢・鞘を人物の手と体へ付け、動作中に手から外れない。
5.3 本作は足の滑りを測り、移動速度と動作の速さを合わせる（基準値は design-characters.md）。

### Requirement 6: 戦闘に手応えと読み合いがある
6.1 プレイヤーが攻撃したとき、本作は太刀の三連撃（弱）と溜め斬り（強）を出し、連打で崩れない入力窓を持つ。
6.2 本作は体力と構えを分け、構えが尽きた者を崩れ（スタン）にする。崩れた敵にだけ「とどめ」を出せる。
6.3 敵の攻撃の前に、本作は予兆（動作・光・音）を出し、受け・弾き・回避で応じられる。弾きは受けの直前だけ成立する。
6.4 回避の無敵は短く、連続で使うと構えが減る。画面を埋める必殺技・長時間の無敵は持たない。
6.5 命中したとき、本作は短い停止・揺れ・火花・音・敵の反応で重さを出す。強さは設定で下げられる。

### Requirement 7: 敵が状況を見て動く
7.1 敵は巡回・警戒・確認・戦闘・離脱の状態を持ち、発見は距離・視線・遮蔽・音で決まる。
7.2 敵が見つけたとき、警戒は近くの味方（12m以内）にだけ伝わり、谷全体の敵が集まらない。
7.3 近接戦で同時に攻める敵は2人まで。他は間合いを取って回り込む。
7.4 味方の損害・将の離脱・孤立で士気が下がると、敵は撤退または武器を捨てて投降する。敵将一人で全員が消えない。
7.5 弓兵は距離を保ち、射線が通るときだけ予兆つきで射る。近づかれると位置を変える。

### Requirement 8: 弓手が仲間として機能する
8.1 弓手の加入前後で、本作は同行・援護射撃・撤退の指示ができる範囲を変える。
8.2 仲間は主人公の前や狭い道を塞がず、経路に失敗しても目の前へ瞬間移動しない。
8.3 仲間の体力が尽きたとき、本作は死亡でなく「倒れて回復を待つ」状態にし、敵が近いと起きない。

### Requirement 9: 選択が結果を変える
9.1 村へ入る前に、本作は「正面」と「迂回」のおおまかな代償を示す。
9.2 正面は速いが食糧の損害が出やすく、迂回は時間と見つかる危険と引き換えに食糧と村の信頼を守る。
9.3 どの選択でも、本作は弓手の救出と帰還に到達でき、進行不能にならない。
9.4 本作は帰還後の結果表示で、救えた人・食糧・士気・村の信頼を、選択に結び付けて伝える。

### Requirement 10: 失敗しても短く再挑戦できる
10.1 主人公が倒れたとき、本作は直前の区切りから、長い会話を飛ばして再開できる。
10.2 本作は版番号つきで進行を保存し、不正・未知の版・保存不可のときは安全に開始へ戻して理由を示す。
10.3 保存と読込で、任務・仲間・資源・敵の配置と生死が重複・復活しない。

### Requirement 11: 操作と設定
11.1 本作はキーボードとマウスで完結し、キー割り当て（移動・視点・攻撃・受け・回避・調べる・屈む・指示）を表示する。
11.2 本作は感度・視点反転・揺れの強さ・血や衝撃の表現・字幕・音量を変更でき、保存する。
11.3 画面外へ移った・押しっぱなしの・UI入力中の操作は、本作がゲームへ伝えない。

### Requirement 12: 音で状況が分かる
12.1 本作は風・川・足音（地面別）・刃・被弾・受け・弓・太鼓の合図を合成音で鳴らす。外部の音声素材は、R15の第2段階（15.9）まで使わない。
12.2 重要な情報は音だけに頼らず、字幕と視覚表示を付ける。ミュートを保存する。

### Requirement 13: 検証と引き渡し
13.1 開発工程は純粋な規則（戦闘・判断・任務・保存・地形）をNodeで自動検査し、実ブラウザで通しを確認する。
13.2 開発工程は性能を固定条件（解像度・品質・経路・時間）で測り、測っていない端末を報告から外す。
13.3 開発工程は独立した評価役による画面採点と体験採点を最大3周回し、改善の前後を同じ画角で残す。
13.4 開発工程は、小さなcommitとPRで反映する。リポジトリは2026-10-27に公開した（コードMIT・素材と物語CC BY 4.0）。デプロイは本人の依頼があるときだけ行う。
