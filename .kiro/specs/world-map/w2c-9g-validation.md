# W2c-9g：家の質感を追加、実機での画質・性能確認は残る

依頼書の確定設計を引き継ぎ、家の材質だけを実装した。形・配置・当たり・LODは合成／私有データのA/B試験で一致した。ブラウザは依頼の担当外で、描画の受け入れは親の実機確認後とする。

## 採った方式と理由

- UV・頂点色を持たない私有GLBにも適用するため、位置・法線の三面投影を使う。名前による役割判定を避け、基準高さ以下の石、上向き斜面の茅、残りの壁を分けた。
- 板・土壁・茅・石の模様をRGBAの各チャンネルへまとめた。標準も軽量も1枚で共有し、基準色・粗さ・金属感・照明・霧を引き継ぐ。
- 種固定の生成を行単位に分割し、ブラウザへ制御を返す。模様の平均は0.5付近に補正し、2尺度（片方を回転）と個体別のずらしで反復を抑える。
- 世界位置のハッシュで明度±8%、色相±3°、板／土壁約65／35を決める。茅の束・軒と棟・古色・北側の苔、壁の木目・ひび・染み、基壇と泥汚れを乗せる。柱の抽出と瓦／板屋根の選別は省略し、茅葺きに統一した。
- 80〜250mで全効果を基準色へ収束させる。微分で小さな法線の乱れを加える。軽量は1尺度・汚れと苔なし・振幅0.7、段階2は法線の乱れなし、段階3は振幅0。切替はuniformのみ。
- `htex=0` は新規材質・テクスチャを作らず従来の材質を使う。非表示の家の除外箱を作る経路でもテクスチャを作らない。

## Nodeで確かめたこと

- 純粋な式：役割の境界、決定性・個体差・範囲、壁比率、距離減衰の端と単調性。
- データ：同じ種のバイト一致、異なる種の差、4チャンネルの平均、上下左右の連続、ミップ込み容量。
- 同梱Three：既存hook・霧チャンクとの共存、PBR設定維持、近／中景の材質共有、段階の往復でuniform以外を再生成しないこと。
- 合成／私有GLB：A/Bで全行列・頂点・法線・インスタンス数・当たり箱・LODが一致。私有の全使用型に屋根／壁／基壇を割り当てた（名前別の集計は保存しない）。
- 正常／途中失敗の資源解放、二重dispose、破棄後updateで資源が復活しないこと。私有の未使用元材質も各1回破棄した。

## 数値（容量はRGBA8の計算値、材質数はNode実測）

- 開始時smoke：`listen EPERM`（127.0.0.1への待受が禁止）で失敗。
- 専用試験：私有データあり8/8成功。未設定時は私有用2件を理由付きでskip。
- 最終 `npm test`：1055 pass / 15 skip / 0 fail。`KZ_WORLD_DIR` 指定：1070 pass / 0 skip / 0 fail。
- 並行作業中に川の試験で `ERR_INVALID_URL: ./kamakura-fx.js` が一度出た。担当外は直さず1分以上待ち、再実行で解消した。
- 最終 `npm run check`：私有データなし／ありとも成功。最終 `npm run smoke`：開始時と同じ `listen EPERM` で失敗。
- 家の既存＋追加試験：私有データなし14 pass / 3 skip、私有データあり17/17成功。
- 文書lintは環境に `sudachipy` がなく実行できず、クイック工程の手動チェックで代替した（依存は追加しない）。

## 親が実機で確かめる手順

1. 同じ画面サイズ・時刻・品質で、`/valley/?world=kamakura` の出発点の町、`/valley/?world=kamakura&pos=-1057.2,-1801.4&yaw=180`（海辺）、`/valley/?world=kamakura&pos=-534.0,-99.6&yaw=0`を開く。
2. 各URLへ `&htex=0` を付けて固定画角の前後を撮る。茅の筋が斜面を下ること、板と土壁の差、基壇の石、泥はね、軒下と棟、近づいたときの質感を比べる。
3. 同じ家から80〜250mへ離れ、模様が滑らかに薄れ、ちらつき・モアレ・LOD交換時の不連続がないかを見る。
4. `&time=evening`、`&q=light`、`&autoscale=0&adaptstep=2`／`3`も比較する。段階3は基準色、軽量は苔・汚れが消えること。
5. M4 ProとCPU6倍・390×844でA/Bの1コマ時間を比較する。目標は追加0.5ms以内／スマホp50追加3ms以内。再入場のGPUメモリ、谷と庭も確認する。

## 未確認と次の一手

GPUのシェーダーコンパイル、実際の色・凹凸・模様の方向、固定画角の前後撮影、実機性能、長時間GPUメモリは未確認。Node試験では既知の材質不具合は検出していない。まず親が海辺のA/Bを同じ画角で撮り、描画と追加時間を確かめる。

## 9g2：役割の色と大きな斑を遠くまで残す

親の実機評価を受け、全効果を80〜250mで消す方式を変更した。K7の色を22%残し、茅・古い茅・灰茶の板・漆喰・寒色の石を78%混ぜる。家ごとの明度は±10%。役割の色と1〜4mの斑（上限±20%）には距離減衰を掛けず、300mでも残す。細部は0.65から1.15倍へ、擬似凹凸は0.06から0.11へ強めた。細部には従来の80〜250mに加えて画素幅の減衰を掛ける。軒は暗く、棟は明るくした。

施設も同じ生成器を使う。材質名で瓦・柱・板・石を判定し、不明は漆喰、上向き面は瓦とする。元の高さを頂点属性へ保存し、地形へ変形した塀でも地表高を壁の高さと混同しない。形・当たり・配置・描画数は変えない。`ftex=0`は施設の追加材質とアトラスを作らない。施設のURLは既存のブラウザlocationから受け取り、試験では任意引数searchを渡す。worldの配線は変更していない。

### 9g2の数値と試験

- 合成の基準色3通り・古さ21段階・明度0.9で、4役割の最小CIE76 ΔEは8.078。これは基準色の式の検証で、照明・霧・画面上の差の保証ではない。
- 合成20,000点の斑は-19.985〜+19.987%。細部振幅は40mで1、100mで0.9617、250mで0。役割色・大きな斑は距離で絞らない。
- アトラスは家／施設各1枚の512×512 RGBA。各ミップ込み1,398,100 bytes、両方で2,796,200 bytes。標準6 fetch、軽量3 fetchを維持。段階2は凹凸なし、段階3は追加効果なし。役割と斑は追加fetchなし。
- 合成施設のA/Bで頂点・法線・添字・行列・当たり・メッシュ数が一致。品質を往復してもuniformだけが変わり、取得した資源は各1回破棄した。既存の途中失敗試験も通る。
- 私有施設にもA/Bの頂点・法線・行列・当たり・メッシュ数の比較を追加。私有家の既存A/B・全型の役割判定を引き継ぐ。

### 9g2の親の実機確認

1. `/valley/?world=kamakura&pos=-1057.2,-1801.4&yaw=180`と出発点`/valley/?world=kamakura`で、同じ画角の`&htex=0`との前後を撮る。40mおよび30〜100mで茅と板壁の色・斑が読めるかを見る。
2. `/valley/?world=kamakura&pos=-200.7,-192.9&yaw=300`で`&ftex=0`と比較し、塀の漆喰・染み・泥、屋根の瓦を確認する。材質名が不明な柱は漆喰になるため、判定の妥当性も見る。
3. 各画角で`&time=evening`、`&q=light`、`&autoscale=0&adaptstep=2`／`3`を比べる。段階3は元の色、段階2は凹凸なし。80〜250mで細部だけが薄れ、モアレが出ないかを見る。
4. 同じ端末・画角でA/Bの時間を測る。今回の目標は追加+0.3ms以内、CPU6倍・390×844のp50は+3ms以内。谷と庭、再入場のGPUメモリも確認する。

ブラウザは依頼の担当外。GPUコンパイル・見た目・固定画角撮影・GPUメモリ・+0.3msの達成は未確認。施設は部品の意味が分かる名前を持たないため、面方向による瓦判定には柱の上端も含まれ得る。次は親が海辺と塀のA/Bを撮影する。

9g2最終結果：`npm test`は1074 pass / 18 skip / 0 fail。`KZ_WORLD_DIR`指定は1092 pass / 0 skip / 0 fail。`npm run check`は私有データなし／ありとも成功。`npm run smoke`は開始・終了とも待受禁止の`listen EPERM`で失敗。専用試験は18 pass / 3 skip。文書lintは`sudachipy`不足で失敗し、クイック工程の手動チェックで代替した。コミット・pushはしていない。

## 9g3：町家の板壁・茅と施設の塗装を修正（GPU確認待ち）

- 依頼書9g3の色・寸法・役割を引き継いだ。町家は板85%／黄土の土壁15%。sRGB目標を線形化し、K7の色を35%混ぜる。板・土・石の古色、明度±12%・色相±3°を家の位置から決める。
- 彩度の高い部品と黒漆は元色へ暗くなる風化だけを乗せる。不明な施設部品も元色を保持。材質名とメッシュ名で役割を判定し、既知の壁は生成り、柱梁は暗い木、屋根は炭色の瓦にする。
- 短周期の正弦波アトラスを8mの不規則な模様へ交換。板は幅18〜30cm・目地1.5cm・不揃いの縦継ぎ、茅は約37.5cmの段、石は不規則なVoronoi目地。大きくゆっくり座標を歪め、板と茅への回転模様の混合をやめた。
- 軒の縁を茅と同色にし、泥・雨筋・軒下・軒先を暗くする。北面に苔、棟に明るさを残す。未塗装の出力は線形0.45を上限とした。高彩度・黒漆・不明部品は色保持を優先する。
- 細部は画素幅と40〜120mの距離で消す。役割色と±20%の大きな斑は300mでも残す。軽量・段階2/3・htex/ftex=0は従来の切替を維持。world-kamakura.jsの配線変更なし。
