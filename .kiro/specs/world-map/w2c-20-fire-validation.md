# 火と煙の層：検証記録

火と煙の層を実装した。夕暮れの町は、火事に見える。

実 Chrome（設計した鎌倉・夕暮れ）で、北西の山の上（町から約 300m）と、町の上の低い空から見た。屋根の炎、火元を包む橙の光、地面と隣の家への赤い照り返し、火の粉が出る。山の上からは、橙の塊が 5 つ読める。コンソールのエラーは 0。

直す所は 2 つある。煙の柱が細く薄く、同じ形が等間隔に並ぶので、雨の筋のように見える。火の粉が、屋根の上で一列に並ぶ所がある。どちらも、次の直しで扱う。

合成世界の最大構成は 696 枚・1,392 三角形・描画 4 回に収まる。

## 引き継いだ要件と設計判断

- WW17.6とF1〜F4が対象。地形、場面の生成、時刻の追加は変更しない。
- 町から200〜450m離れた退路でも火事が読めることを目的とする。歩く視点と同じ配置を使う。
- 4種類の一括描画にまとめた。点光源は近くを歩くときだけ1個とし、遠景の火元ごとには増やさない。
- 地面の照り返しは高さを9点で測る粗い面。急な斜面の浮きや埋まりは実画面で確認が必要。
- にじみは指定された半径の1.2〜1.8倍を守る。画素数による拡大は、この範囲を超えるため採らなかった。
  30画素の達成は画角と画面の大きさにもよる。半径の小さい火元は、見渡す画で目標を満たさない可能性がある。
- 色は既存の炎・すすと、その場の霧の色から作った。新しい画像・模型・依存は追加していない。
- 煙の板は品質を落としても上下が重なる。上端は高さから連続的に消し、四角い外縁には雑音を使う。

## 実Chromeで確かめる手順

1. 設計した世界の控えを複製し、`meta.json`だけに`"fires":[{"x":0,"y":-100,"radius_m":18,"strength":0.8}]`を足す（ゲームの東・北）。
2. その複製を`KZ_WORLD_DIR`に指定して`npm start`。`/valley/index.html?world=kamakura&time=evening&fly=1&cam=-200,100,65,135,12,50&debug=1`を開く。
3. 退路から200〜450m先を見る。町の複数箇所が橙の塊として読めるか、黒い煙が空を背に柱として読めるかを撮る。
   火元を3〜4個に増やし、場面を統合後は`cam=overlook`でも撮る。`cam`の数は東・北・高さ・方位・俯角・画角。
4. `&firedebug=1`：炎は赤、にじみは黄、地面の光は桃、煙は紫、火の粉は水色。配置と欠落を見る。
5. コンソールで`__kzFire()`。数・三角形・描画回数・最近の火元の距離と方位・作業量を見る。
6. `&fire=0`と同じ画角で比較する。歩いて近づき、80m以内で最寄りの家が照らされること、屋根の根元の直線が出ないことを見る。
7. `&time=noon`で光だけが弱まり炎と煙が残ることを確認する。`&time=dusk`でも確認する。
8. `&q=light`、`&adaptstep=3&autoscale=0`で品質段階3、停止・再開・退出でも確認する。コンソールのGLエラーと解放漏れを見る。

## 見た目を詰める定数（`kamakura-fire.js`冒頭の`FIRE`）

| 名前 | 現在の値 | 上げると |
|---|---|---|
| `flameLow / flameMid / flameCore` | 線形RGB `[.55,.06,.01] / [1,.3,.04] / [1,.62,.26]` | その色の成分が強くなる |
| `flameMinM / flameMaxM / flameScaleMin / flameScaleMax` | `4 / 9m / .8 / 1.6` | 炎が高くなる |
| `flameWidth / roofEmbed / flameWind` | `.65 / .3 / .22` | 幅／屋根への埋まり／風の傾きが増す |
| `flickerHz / flickerAmount` | `.9Hz / .06` | 揺らぎが速く／強くなる。1.2Hz以下を守る |
| `glowColor / glowGain` | `[1,.4,.13] / .65` | にじみの色成分／明るさが増す |
| `glowRadiusMin / glowRadiusMax / houseGlowRadius` | `1.2 / 1.8 / 1.15` | 火元／家のにじみが広がる |
| `poolGain / poolMinM / poolMaxM / poolLiftM` | `.48 / 20 / 35 / .12m` | 地面の光が明るく／広く／高くなる |
| `pointGain / pointRangeM / pointNearM / pointHeightM` | `18 / 65 / 80 / 4m` | 家を照らす強さ／範囲／作動距離／光源の高さが増す |
| `smokeDark / smokeSkyMix / smokeLitMix / smokeDensity` | `#141210 / .32 / .42 / .58` | 色成分／空の色／根元の橙／濃さが増す |
| `smokeMinM / smokeMaxM / smokeBaseM / smokeSpread / smokeWind` | `90 / 160 / 2.4m / .16 / .28` | 高さ／根元の幅／上の広がり／風下への流れが増す |
| `smokeFadeStart / smokeNoiseScale / smokeRise / smokeEdge` | `.62 / 2.7 / .06 / .38` | 上端の消え始めが遅く／模様が細かく／上昇が速く／縁が欠ける |
