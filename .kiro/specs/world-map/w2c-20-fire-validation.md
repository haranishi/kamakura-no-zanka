# 炎の色と輪郭を保ち、棟の並びに房とすき間を作った

屋根の炎だけを配置し直した。合成7,680条件で、間隔の変動係数は最低0.481、高さ比は最低2.018。
1軒分の幅×高さの和は、前版の0.981〜0.987倍。断片シェーダー2本は、変更前の文字列と完全一致する。
実際の Chrome（序幕・夕暮れ）で、町の上の低い空と、見渡しからの望遠を、直す前とあとで撮り比べた。等間隔に並んだ同じ高さの舌が、高い舌を中心にした房に変わり、火が山の形に見える。色・にじみ・地面の照りは、前と同じ。コンソールのエラーは 0。

## 要求と判断

| 要求 | 結果 |
|---|---|
| 不規則な間隔・房 | 実装。棟の等間隔位置から±45%以内で動かし、2〜3本を寄せる。屋根3本の予算では2本の房と孤立した1本 |
| 実幅の0.5〜0.9倍／1.4〜2.4倍の絶対間隔 | 厳密保証は見送り。屋根内の配置幅で正規化する。狭い屋根に既存の幅と本数を収めるため。試験も正規化間隔と実座標の変動係数を区別 |
| 高さ0.45〜1.55倍・房の山 | 実装。家の基準高さに対する倍率。3本の中央を高く、端を低くし、最高の房は1軒に1つ |
| 幅0.75〜1.35倍・前後±25%・交差の回転 | 実装。幅は前版の各舌に対する倍率。根元の中心は屋根内に置き、屋根勾配へ埋める |
| 傾き0.6〜1.5倍・揺れの速度と位相 | 実装。屋根の舌だけを個別化。頂点側の式とCPUを照合 |
| 本数・板数・描画・品質段階 | 維持。標準／軽量と段階0〜3を検査。板数上限900・描画4回 |
| 色・明るさ・輪郭・ほかの火の要素 | 維持。断片シェーダーは同一。開口部・地面だけの炎・煙・火の粉・燠・にじみ・地面の照りは従来のまま |
| 実Chromeでの見た目 | 見送り。ブラウザを動かさない作業条件による。過去の結果を下に残す |

高さが低い舌へ4mの下限を掛ける従来の検査は、房の高低差を消してしまうため、家の基準高さ×倍率へ変更した。
根元も棟の高さ固定から、前後にずれた屋根斜面の高さへ変更し、埋まり量まで検査する。
追加の合成条件では面積が下限をわずかに割ったため、高さだけで補正しきれない分を許容幅の範囲内で補う。
火の面積は開口部の舌も含む。交差枚数は変わらないため、枚数を掛けた面積の比も同じ。

## これまでに実 Chrome で確認した結果

実 Chrome（序幕・夕暮れ）で、山の上からの見渡しと拡大、町の上の低い空から見た。炎は、屋根の棟に沿って並び、屋根の上に燠が光る。煙の根元は、火の色に照らされる。コンソールのエラーは 0。
前回の実Chromeでは黒い煙・橙のにじみ・屋根の照りは良好だった。一方、炎は板に見え、煙の大小と根元の橙が不足していた。
山の上から見ると、煙の柱が細い縄のように見えたので、いったん根元の太さを 5.2 → 7.6m に上げた。ところが、太くすると、同じ濃さの黒い縄が 3 本並んで見えた。原因は太さでなく、上まで濃さが変わらないことだった。そこで、根元を 5.2m に戻し、柱の 34% の高さから薄まり始めるようにした（前は 55%）。濃さは 0.9 → 0.78、空の色をまぜる割合は 0.14 → 0.3、上での広がりは 3.4 → 3.9 倍。見渡しでは、柱が上へ行くほど淡く広がって見える。GPU 時間と実 FPS は未測定。

## 実Chromeで確かめる手順

1. 序幕（`--scene escape`）の設計データを`KZ_WORLD_DIR`として`npm start`で配信し、`/valley/index.html?world=kamakura&time=dusk&fly=1&cam=overlook&debug=1`を開く。
2. 同じ画角と時刻で前版・変更後を撮る。20〜450mから、棒の列が房とすき間へ変わり、家並みの中で燃えて見えるか確認。
3. 低い空と歩く高さでも家を一周する。白い膜・盾状の根元・過度な重なり・屋根から離れた根元がないかを見る。
4. `&firedebug=1`は炎=赤、燠=橙、開口部=緑、にじみ=黄、地面=桃、煙=紫、火の粉=水色。`__kzFire()`で数・距離・方位・作業量を見る。
5. `&q=light`、`&adaptstep=3&autoscale=0`、停止・再開・退出、`&time=evening`、`&fire=0`を確認。コンソールエラー0も確認する。

## 未確認・制約と次の最小作業

間隔の倍率は配置幅で正規化しており、舌の実幅に対する絶対距離の保証はない。根元は中心位置を検査しており、交差板の全幅や風下の先端が屋根外へ出ない保証もない。
屋根が2本だけの品質では間隔が1つなので変動係数は定義できない。3本以上で検査する。前後のずれで見かけの重なりが増える可能性も残る。
屋根・開口部の近似と、地形や選んでいない家の影を照り返しへ反映しない制約は従来どおり。
舌は、まだ細い。家並みの中で燃える不定形の塊には、届いていない。太くして根元をつなぐ案は、白っぽい半透明の板に見えたので、採らなかった。
