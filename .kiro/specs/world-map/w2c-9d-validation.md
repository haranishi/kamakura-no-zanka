# W2c-9d：川の接地反応・魚・砂ぼこり

川に入って歩くと波紋としぶきが出る実装を追加した。魚の群れ、浅い岸の透過、乾いた地面の走行時の砂ぼこりも追加した。Node検証を担当し、画質・実機性能の受け入れは親へ引き継ぐ。commit・pushは行っていない。
## 採った設計と理由

- 確定済みの9d依頼書と共通前提を仕様として継承した。谷・庭・保存・共通の主人公コードは変更しない。
- 接地処理を包み、元の足音を先に1回呼ぶ。音側のattach後にdust APIを設置するため、音の代役による上書きを避ける。接地通知には足の世界座標がない。主人公の位置と向き、左右の足から横12cmの発生位置を作る。
- 川を最大12mの区間と32mの検索格子に分け、固定長の魚・粒子・波紋を使う。川全体の毎コマ走査を避け、索引作成は元の128区間ごとに描画フレームへ譲る。
- 魚の位置は世界座標のハッシュと経過時間で決める。散開は近接3mと約1秒の復帰、車線は半幅の±35%以内。幅1.2m未満・浅い底・陸・海を準備時に除く。
- 水面は川底までの中心水深を頂点属性に持ち、岸への横位置と合わせて透明度を変える。距離と岸端の既存フェードを保持する。
- 描画は波紋・粒子・魚の各1回。半透明板は通常合成・depthWriteなし・forceSinglePass。魚は不透明、影なし、水面より前。全材質が霧に対応する。品質変更は確保済みの上限を切り替える。新しいテクスチャ・外部素材・依存・通信はない。
## 確かめたこと

- 接地の順序、走りと歩きの差、波紋の間隔、粒子の寿命・水面の下限、乾燥時の砂ぼこり、水・海・草での抑制。
- 同梱Threeで生成・更新・品質切替・資源の1回破棄を確認。魚の法線、シェーダーへの差し込み、深さと透明度の単調性も確認した。GPUでのコンパイル・描画は未確認。
- 私有データは実行時だけ読み、実地形で魚の生息候補と毎コマの更新を確認する。地形や川の座標・派生データは保存しない。
- 開始時：`npm test` は1,022成功・11スキップ、`npm run check` は成功。smokeは `listen EPERM 127.0.0.1` で停止。
- 終了時：`npm test` は1,055成功・15スキップ・失敗0、`npm run check` は成功（415 JS構文検査）。`npm run smoke` は同じlisten EPERMで停止。

## 親が実機で確かめる手順

1. `?world=kamakura&pos=-534.0,-99.6&yaw=180` を開き、川に入って歩く。左右の接地で輪としぶきが出るか、走ると強くなるか、連続移動で後ろへV字が開くかを見る。
2. 立ち止まって魚を探す。近づいて散り、離れて約1秒で戻るか、しばらく待つと跳躍と輪が出るかを見る。
3. 岸と中央を同じ画角で比べ、浅い縁に川底・魚が透けるか、距離境界が変わらないかを見る。
4. 乾いた砂・土で走って砂ぼこりを見る。草の歩行・水中・海で砂ぼこりが出ないか確認する。
5. 同じURLに `&fx=0`、`&fish=0`、両方を付けて比較する。前者は波紋・しぶき・砂ぼこり、後者は魚を止める。`&water=0` でも魚は出ない。
6. `&q=light` で量を比較する。`&autoscale=0&adaptstep=2` と `&autoscale=0&adaptstep=3` でも比較する。段階2は半量の粒・波紋と魚14匹、段階3は全効果なし・透過だけ残ることを確認する。復帰時の資源増加・ちらつきも見る。
7. 同じ固定画角の前後撮影、通常端末とCPU6倍の390×844で性能比較、休止・飛行・長時間・谷・庭の確認を行う。
## 未確認と設計上の補足

ブラウザを動かさない契約のため、前後撮影、視認性、GLSLのGPUコンパイル、実機の+0.5ms／スマホ+3ms目標、聴感、長時間メモリは未確認。魚の底の余裕は準備時に区間内の複数点で検査するため、点の間の細かな地形との交差は実機でも見る必要がある。現時点で再現した機能上の既知不具合はない。

設計からの補足は、足の座標の近似、長い川区間の分割、読み込み時の128区間ごとの分割準備。次の最小ステップは、親が上記の川URLで接地反応・魚・透過を確認し、同じ画角でA/B撮影と性能測定を行うこと。

## 9d3：魚と水の反応を立体と粒へ変える

9d3依頼書を修正仕様として継承した。魚は青い線から暗いオリーブの背・銀白の腹へ変え、太い体・尾・背びれを60三角形で作った。背の明度は水より0.04以上低く制限し、水深に応じて水色を混ぜる。光で背が白くならないよう、魚は不透明の非照明材質を採用した。

- 体長25〜35cm／55〜70cm、向き±25°、速さ0.3〜0.9m/秒、色±10%、通常の深さ20〜45cm。24mゲートと近い群れの優先は維持した。
- しぶきは白い正方形の粒12／24個へ変更。走ると寿命0.4〜0.6秒の霧4個を同じプールへ足す。落下した粒は微小波紋を作る。主人公は地形追従で跳躍状態がないため、飛び込み専用の判定は追加していない。
- 波紋は角度と半径で太さが変わる二重輪とし、外輪を遅れて薄く出す。縦横比1.08〜1.16、滑らかな減衰、V字の引き波を同じ描画で扱う。魚の跳ねでは大きい波紋2個を出す。
