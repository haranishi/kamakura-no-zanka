# W2c-19f 縁の直し（edges）：検証記録

小さい地図で初めて目立った不具合を、3 つ直した。1 つ目は範囲の外の陸で、海の上に浮く黒い板に見えていた。2 つ目は港の中。白い波の筋が、輪になって出ていた。3 つ目は谷の霧で、町の山すそを白い帯で隠していた。あわせて、霧の濃さと範囲の外の陸の明るさを、地図ごとに決められるようにしてある。

- 旗：`&backdrop2=0`（範囲の外の陸を今までどおりに）・`&shelter=0`（囲まれた水面の扱いを切る）。
- 確認用：`&backdropdebug=1`・`&sea3debug=1`（囲まれた水面＝紫）・`?debug=1` の `__kzBackdrop()` と `__kzSea3()`。
- 調整する定数は、`kamakura-backdrop.js` の `BACKDROP`、`kamakura-shore.js` の `SHELTER`、`kamakura-mist.js` の `MIST`。

## なぜ必要か

設計した鎌倉は、約 2km 四方しかない。今までの地図（実寸の鎌倉・約 8km）では遠くて目立たなかった物が、すぐそこに見える。

- 範囲の外の陸は、端の高さが何であっても、端から 800m で山の高さまで持ち上げていた。そのため、陸の端が海へ入る所では外の陸が直線で終わり、すぐ後ろが山になって、浜からは暗い板が海の上に浮いて見えた。
- しかも、その面には模様が無い。暗い緑の一色で霞もほとんど掛からず、尾根のすぐ向こうに黒い壁として立った。
- 白波は、岸からの距離だけで出る。だから、石の堤で囲んだ港の中にも筋が出て、的の模様になった。
- 霧は「まわりより低い所」に出る。小さい地図では町の平地の全体がそれに当たり、社殿の前に濃い帯ができた。

## 作り

- **範囲の外の陸**。山の高さに、端の高さに応じた係数を掛ける。端が 0.5m なら 0、30m なら 1。これで、端が海へ入る所では、外の陸も海面の近くまで下がる。色には、樹冠のむら（12m と 40m のノイズで ±25%）と、遠景の地面と同じ式の霞を足した。
- **囲まれた水面**。岸からの距離の場に、「外海に開いているか」の値（0〜1）を足した。決め方は、こうだ。岸から 25m 以上離れた海の升だけをたどり、外海までつながる升を「開いた升」とする。すると、口の幅が約 50m より狭い港や川は、中が 0 になる。白波の筋と波打ち際の白波には、この値が掛かる。0 の所に残るのは水際の薄い泡だけで、浅瀬の色は変えない。
- **霧**。任意の `meta.mist = { gain, floor_m }` で決める。`gain`（0〜2）は、濃さの上限に掛かる。`floor_m` は、谷底がこれより低い所の霧を消すための値で、そこから 10m 上で元の濃さへ戻る。
- **明るさ**。任意の `meta.backdrop = { gain }`（0.5〜4）。範囲の外の陸の色に掛かる。

## 判断と、捨てた案

- **「端の外は必ず山」をやめた**。端が低い所では、外も低い。そのかわり、谷が端を横切る所は、外も谷のままになる。それでも、海の上の板が消えるほうがよいと判断した。実寸の鎌倉でも、岬の向こうに浮いていた平らな台が消えている。
- **テクスチャは増やさない**。外海かどうかの値は、今ある場の空いていた成分に入れた。海を描くときの読み取りは、今までと同じ 1 回。
- **地図ごとの値は、データで決める**。URL では上書きできない。知らない名前・範囲の外・数でない値は、読み込みで断る。指定の無い世界なら、シェーダーの文字列も場の中身も、今までと 1 バイトも変わらない。

## 実 Chrome で確かめたこと（夕方前）

設計中の地図（港の輪がある）には、霧と明るさの値を手で足して確かめた。

| 見た所 | 結果 |
|---|---|
| 港を高さ 48m から | 中の白波の輪が消え、浅瀬から深みへの色だけになった。堤の外側には、筋が巻く。`shelter=0` で輪が戻る |
| 設計中の地図の見渡し | 社殿を隠していた白い帯が消えた。尾根の向こうは、黒い面から、青く霞んだ面になった |
| 実寸の鎌倉の見渡し | 前と後で、ほぼ同じ画 |
| 実寸の鎌倉の浜から東西 | 西の岬の向こうの平らな台が消え、低い丘の線になった。東は、ほぼ同じ |
| 囲まれた水面の割合 | 設計中の地図で水面の 3.2%（港と川）。実寸の鎌倉で 0.6%（川口） |
| コマ時間（港・1280×720・上限なし） | あり 5.6〜5.8ms・切ると 5.3〜5.5ms |
| コンソール | エラー 0 |

## 試験

- `tests/kamakura-edges.test.mjs`（15 件）：端が低いほど外の陸が低い・端が 30m 以上なら切った結果と同じ・海の升に面を作らない・樹冠のむらの範囲と、遠くで平均へ戻ること・霞が遠景の地面と同じ式・輪の堤と川の中が 0、広い口と浜の沖が 1・筋の強さが値に比例・霧と明るさの値が、場とシェーダーと頂点の色まで届く・不正な値を断る・指定の無い世界は今までと同じ。
- 旗で切ったときのシェーダーと場は、固定したハッシュと照合する。今までの海の試験 3 件は、`shelter=0` を足した形で通る。

## 残っていること

- **実寸の鎌倉では、囲まれた水面の計算に時間がかかる**。開いてから 16 秒では終わらず、75 秒の時点では終わっていた。それまでは、今までと同じ白波が出る。
- 範囲の外の陸の霞は、一様な青。太陽の側を暖かくするのは、光と色の作業で行う。
- 設計した鎌倉の `gain` と `floor_m` の値は、地形のデータを決めるときに詰める。
- 朝・昼・夕方の色と、軽量の品質は、まだ見ていない。
