# 夕暮れの霧と海：検証記録

くぼ地にたまる霧の層と、夕暮れの海の色を足した。実際の Chrome（序幕・夕暮れ）で確かめたところ、海は空の下の端より暗い青紫になり、水平線が読めるようになった。霧は、置き方しだいである。薄く置けば、木の頂が霧の上に出て見える。濃く置くと、草地と道が白い水面のように見えてしまう。コンソールのエラーは 0。なお、水平線の上の帯は、谷の霧ではなく、低い雲の層だった。

## 要求と結果

| 要求 | 結果 |
|---|---|
| A1 くぼ地の霧（`meta.wisps`） | 実装。地形を開始のときに読み、岸で消える水平な 2 面（軽量は 1 面）。最大 16 個・描画 1 回 |
| A2 上向きの谷の霧 | 実装。仰角 0 度以上では、谷の霧を掛けない。地面の画素は変えていない |
| A2 帯の原因 | 特定した。低い雲の層のいちばん下の帯で、`&clouds2=0` で消える。雲は煙の奥にあり、薄くなった煙の先を透かして見えている。直していない |
| A3 夕暮れの海 | 実装。今ある天頂と霧の色から青紫を作り、光の道を足す前に、海の地の色を暗くする |

谷の霧の、広い範囲で谷を拾う仕組みの縮尺は変えていない。小さいくぼ地は、置き場所のデータで補う。

## 実際の Chrome で見た結果

- **霧の濃さ**：強さ 0.8・厚さ 3〜5m・半径 30〜40m を、道と草地の上にも置くと、白い霧が一面を覆った。草地は、白い水面に見えた。強さ 0.3〜0.35・厚さ 2.5〜3m に下げ、道から外れたくぼ地だけに置くと、木の頂が出る薄い霧になる。草地には置かない。
- **海**：直す前は、空と同じ桃色で、水平線が読めなかった。直したあとは、暗い青紫の海の上に、明るい空の帯が載る。日の真下に、光の道が見える。
- **光の筋**：海が暗くなった分、日から放射状に伸びる光の筋（後処理）が、海の上で目立つようになった。絵と並べた講評でも、「海の照り返しでなく、空中の光の筋に見える」と言われた。夕暮れの光の筋の強さを 0.7 → 0.2 に下げた（夕方は 0.7 のまま）。
- **海の暗さ**：空の下の端の 0.65 倍では、まだ「淡い平らな面」と言われた。0.5 倍に下げた。
- **帯**：`&mist=0`・`&clouds2=0`・`&horizon=0`・`&post=0` を 1 つずつ付けて撮り比べた。帯が消えるのは `&clouds2=0` だけだった。

## 帯を調べた数値（谷の霧の式）

合成の谷・目の高さ 105m・距離 1,200m・朝の強さ 0.8 で、式を評価した。

| 仰角 | 元の式（距離のある画素） | 直したあと | 空の画素（前後とも） |
|---|---:|---:|---:|
| 0° | 0.500000 | 0 | 0 |
| 1° | 0.303810 | 0 | 0 |
| 3° | 0.060614 | 0 | 0 |
| −1° | 0.500000 | 0.500000 | 対象外 |
| −5° | 0.500000 | 0.500000 | 対象外 |
| −20° | 0.477828 | 0.477828 | 対象外 |

空の画素には、直す前から谷の霧が掛かっていなかった。設計した序幕でも、仰角 0・1・3 度の寄与は 0 だった。

## 測った数字

- 序幕に 5 個置いたとき（実際の Chrome）：3,920 三角形・描画 1 回。
- 上限（Node）：標準は 16 個・12,544 三角形・描画 1 回・地形の読み取り 3,616 回。軽量は 12 個・3,456 三角形。
- 1,000 回の更新で、地形の読み直しは 0、頂点の書き換えも 0。海と後処理は、描画と三角形を足さない。
- 海の明るさ（線形の値）：空の下の端 0.276176 に対して、海の地は、その 0.5 倍（はじめは 0.65 倍）。画面に出たあとの比は、測っていない。
- 実機の FPS は測っていない。

## 試験

- 霧の層：検査（上限・範囲）・形（深さ 0 で透明・岸で消える・半径の外で 0・面が水平）・近づいたときの式・時刻の表・三角形の上限・旗・解放。
- 谷の霧：空の向きで 0、地面の画素は直す前と同じ値。直す前のシェーダーと比べる検査には、`&mistsky=1` を指定した。
- 海：夕暮れだけ色が変わり、ほかの時刻はシェーダーの文字列が同じ。
- GLSL は、括弧・予約語・未宣言の名前・数値の型・差し込む位置を、文字列で検査した。実機では、エラー 0 でコンパイルできている。
- 全体の試験・構文と配線の検査・スモークは、取り込みの前に通した。

## 確かめる手順

`/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1` を、霧を置いた世界で開く。

1. `&wisp=0` と見比べる。80〜300m 先のくぼ地で、木の頂が霧から出るかを見る。
2. `&wispdebug=1`＝霧の範囲が、濃さに関係なく桃色。`__kzWisp()` で、個数・三角形・描画・いちばん近い霧・時刻の倍率を読む。
3. 霧の面の上下 3m・中心から 25m 以内へ歩いて入り、画面が白い板で切れないかを見る。
4. `&duskair=0` と見比べ、水平線と海の色、光の道を見る。`&mistsky=1` で、谷の霧の直しを外せる。

## 見た目を詰める定数

| 名前 | 今の値 | 上げたとき |
|---|---|---|
| `WISP.opacityCap` | 0.336（2 面で 0.56 まで） | 霧が濃くなる |
| `WISP.noiseM / noiseStretch / noiseSpeedMps` | 40m / 1.4 / 0.9m 毎秒 | むらが大きく／横に長く／速くなる |
| `WISP.noiseBase / edgeStart` | 0.25 / 0.7 | むらの穴が浅くなる／外周のぼかしが狭くなる |
| `WISP.brightness / warmShare / warmBase` | 1.12 / 0.18 / 0.04 | 明るく／日の側が暖かく／全体が暖かくなる |
| `WISP.nearVerticalM / nearHiddenM / nearFullM` | 3m / 25m / 60m | 消える高さの幅／消える半径／戻りきる距離が増える |
| `WISP_TIMES` | 夕暮れ 1・朝 1・夕方 0.8・夕方前 0.3・昼 0 | その時刻の霧が濃くなる |
| `MIST.skyFadeDeg` | 0.5 度 | 谷の霧を消し始める角度の幅が広がる |
| `DUSK_SEA.luminanceRatio / blueShare` | 0.5 / 0.72 | 海が明るく／青紫へ寄る |
| `LIGHT_TIMES.dusk.shafts`（`kamakura-sky-fx.js`） | 0.2 | 夕暮れの、日からの光の筋が強くなる |
| `DUSK_SEA.startM / fullM` | 60m / 200m | 色の切り替えが、遠くへ移る |

## 置き方のめやす（設計した序幕で決めた値）

強さ 0.3〜0.35・厚さ 2.5〜3m・半径 28〜40m・底の高さ 1m。置く所は、切通しと集落の間・寺の裏のくぼ地・町の北の端。道の上と草地には置かない。

## 残る制約

- 霧は、水平な面である。斜めから近くで見ると、木の幹を切る線が見える。
- 低い雲の帯は、まっすぐな筋に見える。雲の形は、今回は変えていない。
