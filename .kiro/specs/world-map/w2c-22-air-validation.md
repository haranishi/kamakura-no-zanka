# 夕暮れの霧と海：検証記録

くぼ地の霧と夕暮れの海色を実装した。標準の霧は最大12,544三角形・描画1回。
水平線の帯の原因は未特定。真の空には、修正前から後処理の谷霧が掛かっていなかった。
実 Chrome は未実施。帯が消えた、森の間に霧が見えた、という判断はまだできない。

## 要求と判断

| 要求 | 結果 |
|---|---|
| A1 配置する霧 | 実装。地形を開始時に読み、岸の深さで薄める水平な2面。軽量は1面 |
| A1 検査・旗・品質・解放 | 実装。任意の最大16個、描画1回、適応品質で個数・面数・距離を減らす |
| A2 上向きの谷霧 | 実装。有限距離でも仰角0度以上の寄与を0にし、負の仰角の地面は変更しない |
| A2 帯の原因特定・解消 | 未完了。深度が空なら元から0。別の層の変更は指定範囲外なので行っていない |
| A3 夕暮れの海 | 実装。既存の天頂・霧色から青紫を作り、光の道を足す前に地の色を暗くする |
| 実 Chrome・前後画像 | 見送り。この環境では行わないという作業条件による |

大域的な谷検出の縮尺は変更しなかった。小さいくぼ地は、任意の配置データで補う。
既存の谷霧の検査を保った。登録一覧を更新し、旧シェーダーの固定値検査には `mistsky=1` を足した。

## 帯を調べた数値

合成の谷、目の高さ105m、距離1,200m、朝の強さ0.8で、元の式を評価した。

| 仰角 | 元の有限距離の霧 | 修正後 | 真の空（前後共通） |
|---|---:|---:|---:|
| 0° | 0.500000 | 0 | 0 |
| 1° | 0.303810 | 0 | 0 |
| 3° | 0.060614 | 0 | 0 |
| −1° | 0.500000 | 0.500000 | 対象外 |
| −5° | 0.500000 | 0.500000 | 対象外 |
| −20° | 0.477828 | 0.477828 | 対象外 |

設計した序幕の控えでも確認した。方位115〜200°を1°刻み、距離300・600・1,000・3,000・8,000mで調べた。
仰角0・1・3°の元の寄与は最大でも0だった。これは画面の帯が谷霧だという証拠にはならない。
候補の低雲は、同じ方位範囲の約76%で仰角1°の被覆率が0.2を超えた（時刻0秒）。画面の帯との同一性は未確認。
次は実 Chrome で `mist=0`・`clouds2=0`・`horizon=0` を1個ずつ比較し、帯の層を特定する。

## 試験と作業量

- 開始時：通常試験2,105成功・0失敗・71省略。`npm run check` 成功。
- 終了時：通常2,116成功・0失敗・71省略。私有データ指定2,182成功・0失敗・5省略。
- 関連7ファイル：62成功・0失敗・2省略。新規の霧の試験は6件。
- 全試験の初回は旧シェーダー比較が1件失敗。比較用の旗を指定して修正し、再実行で解消した。
- 濃さ上限・時刻の色の補完・旗の先読みの調整後も、関連7ファイルを再検証した。
- `npm run check`：成功。165モジュール・純粋層100個・構文686件を検査。
- `npm run smoke`：開始時・終了時とも `listen EPERM` で停止。ブラウザ検査の成功には数えない。
- 標準：16個・7,200頂点・12,544三角形・描画1回・地形参照3,616回。毎コマ最大16個を評価。
- 軽量：12個を描画・2,704頂点を用意・3,456三角形・描画1回・地形参照2,720回。毎コマ最大12個。
- 1,000回更新しても地形再参照0・頂点更新0。海と後処理は描画・三角形の追加0。
- 海の線形輝度：空の下端0.276176、海の地0.179515、比0.65。最終画面の輝度比は未測定。
- GLSL：括弧・予約語・未宣言名・数値型・同梱断片と差し込み位置を静的に検査。GPUコンパイルは未確認。
- 文章の機械検査は形態素解析の依存不足で停止し、手動チェックリストで確認した。

## 実 Chrome で確かめる手順

序幕のデータの作業用コピーに、末尾の `wisps` を足す。元データは上書きしない。
そのデータを既存サーバーの `KZ_WORLD_DIR` に指定して、次の同じ構図を前後で撮る。
`/valley/index.html?world=kamakura&time=dusk&fly=1&cam=overlook&debug=1`

1. `wisp=0` と比較し、80〜300m先のくぼ地で、木の頂が霧から出ることを見る。
2. `wispdebug=1` は不透明な桃色。`__kzWisp()` で個数・三角形・描画・距離・方位・時刻倍率を見る。
3. 霧の面から上下3m、中心から25m以内へ近づき、25→60mの間で戻ることを歩いて確認する。
4. `mistsky=1` は上向きの谷霧の抑制を外す。`postdebug=mist` と朝でも比較する。
5. `duskair=0` と比較し、水平線の境、暗い青紫の海、細く途切れる光の道を見る。
6. `time=morning|noon|golden|evening`、軽量品質、適応段階0〜3でも確認する。

## 見た目を詰める定数

| 場所・名前 | 今の値 | 上げるとどうなるか |
|---|---|---|
| WISP.opacityCap | 0.336（2面の上限0.559104） | 濃くなる。2面で0.56を超えないこと |
| WISP.noiseM / noiseStretch / noiseSpeedMps | 40m / 1.4 / 0.9m/s | むらが大きく／横長に／速くなる |
| WISP.noiseBase / edgeStart | 0.25 / 0.7 | 雑音の穴が薄まり／外周のぼかしが狭くなる |
| WISP.brightness / warmShare / warmBase | 1.12 / 0.18 / 0.04 | 明るく／日の側が暖かく／全方位が暖かくなる |
| WISP.nearVerticalM / nearHiddenM / nearFullM | 3m / 25m / 60m | 消える高さ範囲／完全に消える半径／戻り切る距離が増える |
| WISP.lowerShare / rangesM | 0.45 / [900,700,500,350]m | 下の面が低く／遠くまで残る |
| WISP_TIMES | dusk:1, morning:1, evening:0.8, golden:0.3, noon:0 | その時刻の霧が濃くなる |
| MIST.skyFadeDeg | 0.5° | 空用の角度の移行域が広がる。真の空は既存処理で常に0 |
| DUSK_SEA.luminanceRatio / blueShare | 0.65 / 0.72 | 海が明るく／天頂の青紫へ寄る |
| DUSK_SEA.startM / fullM | 60m / 200m | 色の切り替えが遠くへ移る |
| SEA_PATH.horizonWidths / nearWidthDeg / strength | 1.25 / 12° / 1 | 水平線側の幅／手前の幅／強さが増す（既存値を維持） |
