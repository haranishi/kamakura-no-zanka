# W2c-18h-2 町の物（焼け跡・直している家・畑・柵・天幕）：検証記録

町を埋める処理が決めた区画のうち、家の無い区画に物を置いた。焼け跡には、黒い柱と落ちた梁。直している家には、新しい木の骨組みと足場。畑には畝が並ぶ。加えて、区画の縁には柵を立て、大通りと浜の近くには天幕を張った。

- 旗：`&towndress=0`（層を作らない）。確認用：`&towndressdebug=1`（焼け跡＝赤・直している家＝黄・畑＝緑・柵＝水色・天幕＝赤紫）・`?debug=1` の `__kzTownDress()`。
- 置く場所は、区画の一覧（`data.townPlots`）と路地から、決定的に決める。区画の無い世界では、何もしない。
- 調整する定数は、`kamakura-town-dress.js` の `TOWN_DRESS`（数・距離）と、`kamakura-town-dress-kit.js` の `DRESS_ART`（形・色）。

## なぜこれを置くか

画の目標は「屋敷は柵で区切られる。焼け跡と、直している家が、町の中に点々とある。天幕。家の間に小さな畑」。物語の時期は 1335 年の夏。2 年前の戦で焼けた町が、直りつつある頃にあたる。だから、焼け跡は古い。草が生え始めている。新しい火事ではないので、煙は 10 か所に 1 か所だけにして、細く立てた。

## 判断と、捨てた案

- **色は、今ある家・小物・作物の色から作る**（新しい画像は足さない）。炭は古い木を暗く、灰は石と古い漆喰を混ぜる。
- **新しい木は、白木の色へ寄せた**。最初の版は、屋根の色を明るくしただけだった。実 Chrome で見ると、塗ったような黄色だった。
- 柵は数が多い（2 千区間ほど）。そこで、1 本ずつの形は 90m までにして、その先は縦筋のある板 1 枚で描く。同じ種類は、1 つのインスタンス描画にまとめた。
- 焼け跡・骨組み・天幕は、遠くでは小さな面にする。1.5 画素より小さく写るときは、画素に合わせて広げ、濃さを薄める。
- 柵は区画の内側に立てる。路地の幅 3.2m は、必ず残す。合成の町で、足したあとも路地を端から端まで歩けることを、試験で確かめている。
- 家・道・水に触れる物は置かない。そのぶんは、診断の `skipped` に数える。
- 天幕の柱には、当たり判定を付けていない（柵には付く）。

## 実 Chrome で確かめたこと（夕方前）

| 見た所 | 結果 |
|---|---|
| 路地から焼け跡を見る | 黒い柱と落ちた梁が、灰の地面に立つ。焼け跡と読める |
| 路地から直している家を見る | 白木の骨組み（柱・桁・屋根の合掌）と、足場・材木 |
| 路地から畑を見る | 畝と菜の列。手前に丸太の柵や板塀（入口があいている） |
| 町の上（高さ 60m）から | 畑の縞と骨組みは読める。柵と焼け跡は、小さくて読みにくい |
| 歩く視点のコマ時間（1280×720・上限なし） | 大通り 8.7ms（切ると 8.2ms）・路地 9.5ms（家の作り込みも切ると 8.4ms） |

## 試験

- `tests/kamakura-town-dress*.test.mjs`：状態ごとに置く・区画の内側・数と大きさの範囲・三角形の上限・決定的・柵の割合と種類・入口・路地を塞がない・当たりの箱・距離ごとの形・品質ごとの距離・描画命令の上限・色の範囲（炭が真っ黒でない・布が真っ白でない）・解放・1,000 回の更新で確保しない。
- 私有データ：例外なし・上限の内側・路地へ柵が入らない・天幕が家と重ならない。

## 残っていること

- 見渡す構図で、白い点（天幕・覆い）と暗い斑（焼け跡）が読めるかは、まだ数えていない。上からは、柵が読みにくい。
- 直している家の白い覆い（布）は、骨組みの片面だけ。遠くの布の重なりと、時刻ごとの白とびは未確認。
- 絵に比べると、柵で囲まれた屋敷は、まだ少ない（家の区画の 45% に、間口の柵だけ）。
