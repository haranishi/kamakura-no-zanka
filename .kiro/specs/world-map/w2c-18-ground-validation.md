# W2c-18 ground：遠景の色むらを消し、森と道を地面へつなぐ

G1〜G3・G5を実装した。G4は距離と画素幅をそろえる範囲で対応した。
見た目は、実 Chrome で確かめて 2 か所直した（下の「実 Chrome で確かめたこと」）。
対象はWW15の地面だけ。木・塊・川・海のコード、私有データは変更していない。

## 水玉の原因と採った設計

Node で読んだ時点では、`gtone` の 43m ノイズを使う `relief`（明暗を最大 ±85% へ広げ、1,500m まで減衰しない）を主因と見た。実 Chrome で、本当の原因は地面だけの霞の式だと分かった（下の「実 Chrome で確かめたこと」）。`relief` を距離で消す処理は、遠景を落ち着かせる効果があるので残した。
草の色むら、庭の色むら、岩の微弱なmacro項も、同じ距離の重みで弱めた。
カメラから各断片までの3次元距離で、250m以内は従来の式、700mで追加の斑をゼロにする。
`gfar=0`では変更前の頂点・断片シェーダーが3条件で完全一致した。固定するのは文字列のハッシュだけ。
従来式を確かめる既存試験2件には`gfar=0`を加えた。新処理は専用試験で確かめる。

森の色は、既存の`STAND_COLOR`の針葉樹・広葉樹の平均を線形空間で0.62倍にした。
木の描画範囲（標準450m・軽量300m）の外側100mで移り、密度0.25で混色なし、0.6以上で90%混ぜる。
自動段階3では、木と同じ`adaptPolicy().impostorRange`で境界を短くする。
新しい混色は高度と写真の旗に依存しない。岩・急斜面・砂浜・河岸を除外する。
7mの樹冠の粒は太陽の側を明るくし、画素幅が7mへ達すると平均色へ戻す。
町の土は元データの土の平均色へまとめ、Lambertの斜面・光・影を保つ。

全段階の植生から、24m以下の密度場を分割生成する。歩行範囲の外の林分・尾根も対象。
道は`kamakuraPaths(data)`の全線を幅つきで描き込む。画素より細い線は幅を広げ、その分だけ濃さを落とす。
道の平均被覆率をミップでも保つ。河岸は別の保護面で除外する。
テクスチャ枠を増やさず、既存の接地・近景の道と同じR8画像へ3つの遠景面を詰めた。
近景はLOD0を読み、接地・道が更新されたときだけ、確保済みの行を転送する。

## 実 Chrome で確かめたこと・直したこと（2026-11-11）

- **水玉の本当の原因は、地面だけに掛かる遠景の霞（`slope7Haze`）だった。** 彩度を保つ式の分母が 0 に近づき、利得が巨大か負になって、虹色の斑点になる。高い所から浅い角度で見ると顕著。43m のノイズではなかった（`&gtone=0` で消えたのは、霞も同じ経路にあるため）。
- 遠景の地面が有効なときは、この霞を掛けない。遠くの家と木の塊が地面の上に立つようになり、地面だけを霞ませると、青白い地面に茶色の家が載って見えた。霞は、家も木も共有するシーンの霧に任せる。`&gfar=0` では、霞も式も元のまま。
- 森の地面の色（`canopyShade`）を 0.62 から 1.05 へ上げた。木の塊を約 2 倍に明るくしたので、塊の無い遠い山が暗い茶に沈んで見えたため。
- 見渡す構図で、平地の水玉は消え、道の線が読める。歩く視点（大通り・峠）の足元は、変える前と同じに見えた。

## 見た目を詰める定数（`kamakura-ground-far.js`先頭の`GROUND_FAR`）

| 名前 | 現在値 | 上げたとき |
|---|---|---|
| `fadeFrom` / `fadeTo` | 250 / 700m | 斑が遠くまで残る |
| `canopyBand` | 100m | 樹冠色への移りが緩やかになる |
| `densityFrom` / `densityTo` | 0.25 / 0.6 | 樹冠色になる森が減る |
| `canopyMix` / `canopyShade` | 0.9 / 0.62 | 緑への置換が強まる／樹冠が明るくなる |
| `standLightGain` | 1.1 | 樹冠の元色が暗くなる（既存の塊の補正値） |
| `crownMeters` / `crownContrast` | 7m / 0.18 | 粒が大きくなる／明暗が強まる |
| `crownFilterFrom` / `crownFilterTo` | 0.35 / 1 | 粒を大きい画素幅まで残す（モアレに注意） |
| `rockNormalFrom` / `rockNormalTo` | 0.55 / 0.72 | 樹冠色にする斜面が緩い側へ狭まる |
| `texelMeters` / `maxSize` | 24m / 512 | 場が粗くなる／許容する画像の上限が増す |
| `densitySaturation` | 0.65 | 同じ木の配置で密度が下がる |
| `roadFilter` / `roadGain` | 2 / 1.22 | 道が太く薄くなる／道が明るくなる |
| `soilGain` / `soilLift` | 1.08 / 0.008 | 町の土が明るくなる |
| `bankMargin` | 6m | 変更しない河岸が広がる |
| `fineDistance` / `lightDistance` | 5,000 / 3,000m | 粒を遠くまで計算する |
| `fineFadeStart` | 0.8 | 粒が距離で薄れ始める地点が遠くなる |
| `adaptDistance` | 0.7 | 自動段階1以降の粒の距離が長くなる |
| `debugCanopy` / `debugRoad` / `debugTone` | 赤紫 / 黄 / 水色 | RGB各成分を上げると、その確認色が強まる |
| `sliceMs` / `sliceWork` | 1.5ms / 64 | 生成を長く続ける／時計を見る間隔が長くなる |

ぼやけの残因は地形LOD、元色の解像度とミップ、約200mで消える写真・90mで消える法線細部。
これらの描画距離と地形は維持した。細い道の読みやすさ、粒のモアレ、時刻ごとの緑、GPU負荷には自信を置けない。
