# W2c-16g 小物：実Chromeで確かめ、3周の調整で7種類とも画面に出た

結論：7種類とも、歩く視点の実Chrome（1920×1080）で形が分かる大きさで写った。
最初の版は Node の試験に通っていたが、画面では灯籠が0基・五輪塔と幟がほぼ無い状態だった。
原因は置き方の規則にあり、直したあとは全試験の失敗0、`npm run check` 成功。

## 実機で見つけた問題と直した点

|周|見つけたこと|直したこと|
|---|---|---|
|1|灯籠が0基。五輪塔・幟も大半が「箱の中」で見送られていた|塀（fence）と回廊（kairo）の記録は輪全体を囲む1つの箱だった。中の境内が丸ごと置き場所から外れていた。この2種類は帯（塀1.2m・回廊7m）だけを除外し、中は空き地として扱う|
|1|起動から数十秒「物 配置中」のまま。施設1件ごとに1コマを使っていた|1コマあたり3msまで、置き場所の計算を続けて進める（`PROPS.budget`）|
|1|石が緑がかった暗い青緑に見えた|石の色を灰色寄りの `#968f82` に変えた。日陰でも浮かず、昼に白飛びしない|
|2|煙が細く薄く、町を歩いていても見つからない|板の幅・不透明度・見える高さを広げた。3周目に、空に溶けない灰色へ戻した（`#c4c1b8`・0.26）|
|2|舟の向きが海の方向から最大約50度ずれる懸念があった（海の距離場が粗い）|向きの勾配を前後6mで取る。実機で舳先224°・海の方向225°を確かめた|
|3|門の脇の幟が、門の軒の下に入っていた|門の端から3m離した|

見送り理由の内訳（`why`）を `__kzProps()` の配置結果に足した（箱・道・歩けない・急斜面・水・近すぎ・門の先・浜で見つからない）。
`?debug=1` の `__kzProps().nearest` は、種類ごとにいちばん近い1個の距離・方位・画面上の位置・向きを、呼ばれたときだけ返す。

## 種類ごとの見え方（実機）

- 灯籠：鶴岡八幡宮の舞殿の前で対になって並ぶ。主人公（1.7m）と並べて約1.8m。夕方は火袋が暖かく光り、光りすぎない。
- 五輪塔：大仏殿の塀の内側の隅、朝夷奈切通の道端に群れで立つ。大小が混ざり、昼の石が白すぎない。
- 地蔵：八幡宮の西の道端で確認。赤い前掛けは5〜10mで分かる。切通の端には置かれていない（道の端が歩ける範囲の外）。
- 幟：楼門の脇で竿は動かず、布が波打ち、突風で大きく振れる（録画で確認）。
- 煙：朝、屋根の棟から立ちのぼり、突風で傾く（録画で確認）。太い柱や白飛びにはならない。
- 薪と桶：壁ぎわの日陰に置かれる。浜の家では読めるが、草の高い町では草に半分隠れる。
- 舟：材木座の砂の上に、海へ向けて引き上げてある。脇に網を干す枠。
- `&props=0`：同じ画角で小物だけが消える（差分画像で確認）。どの撮影でもコンソールのエラーは0。

## 速さ

`w2c_perf_uncapped`（小物なし／ありを交互に、2回）の1コマの時間の中央値。
立ち止まり：あり 7.6・7.1ms、なし 7.2・7.9ms。歩き：あり 7.9・9.1ms、なし 7.1・8.8ms。
回ごとの揺れが±1ms以上あり、+0.3ms以内かどうかはこの方法では判定できない。悪化は揺れの範囲に収まる。

## 試験で変えたこと

- 輪の箱の帯だけを除外し、中は空き地になることを確かめる試験と、見送りの内訳の合計が見送り数と一致する試験を足した。
- 私有データの試験に、灯籠・五輪塔・幟が「1基以上ある」ことを足した（件数は書かない）。
- 視点の試験で、`nearest` の距離と方位が有限で範囲内かを見る。既存の試験は弱めていない。

## 残る制約と、人の判断が要る点

- 円覚寺・建長寺・極楽寺・浄智寺の堂は歩ける範囲の外にあり、規則どおり小物を置かない。
- 八幡宮の鳥居から石段までの広い参道には灯籠が無い。規則が「堂から最寄りの門まで」なので、参道に並べるかは人が決める。
- 煙は低い視点では屋根に隠れやすく、遠くでは細い筋に見える。もっと目立たせると模様に見える恐れがある。
- 当たり判定は無い（依頼どおり）。灯籠・五輪塔・舟は通り抜けられる。
- Node 単体では私有データの浜で舟が0艘になる（ブラウザでは置かれる）。浜の判定がブラウザ側の地形の状態に依存するため。

## 確かめ方

1. `KZ_WORLD_DIR=… node tools/serve.mjs --port 8176` で立て、`/valley/index.html?world=kamakura&debug=1` を開く。
2. `__kzProps().nearest` で近い小物の方位を見て、`&pos=東,北&yaw=方位` で向けて撮る。
3. 場所：八幡宮 `&pos=-347,368&yaw=180`、大仏殿 `&pos=-2169,-630&yaw=337`、切通 `&pos=2472,535&yaw=180`、浜 `&pos=-1029,-1800&yaw=281`。
4. 夕方は `&time=evening`、煙は `&time=morning` で録画、`&props=0` で前後を比べる。
