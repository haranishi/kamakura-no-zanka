# 設計した鎌倉の磨き：検証記録

石段・大仏の段の色・町の値と木・退路の足元を更新した。実 Chrome で、石段が草の斜面に収まり、町が家で埋まる（帰還 167 軒・序幕 169 軒）ことを確かめた。山の起伏と岩壁の形は、次の変更で扱う。ゲーム側は変更していない。

| 要求 | 実装／見送りと理由 |
|---|---|
| Q1 山 | 谷の木を高く暗く、尾根の木を低く明るくした。樹種の設定割合は維持。地形の変更は見送り。重なりを増やす案が歩行・傾斜・構図の既存基準と両立せず、再調整後も失敗したため元へ戻した |
| Q2 石段 | 両脇4mの地面を鼻先の線へ寄せ、幅0.4m・高さ0.25mの連続した石の縁に交換。石は約1.5倍明るく、段ごとの明暗は±8% |
| Q3 大仏 | 幅4mの敷石・砂利・幅3mの草を2mで混色。合成模型では8本植樹。実模型の堂は段全体を占めるため、安全に植えられる位置が無く0本。段・模型を拡張せず未完了とした |
| Q4 町 | 指定の町並みの値と家の描画方針を両場面へ出力。庭木の印を直接受け取り、広葉樹を置く。印が無い版では空配列へ戻す |
| Q5 退路 | 裾の岩112個（うち大岩10個）・頂の小岩20個・手前の低木12本と岩20個。角のある岩壁と棚は見送り。試作が壁の高さと既存の視線余裕を満たさず、元の形へ戻した |

## 数字は書き出した設計世界をゲームと同じ読み方で測った

- 山の重なり：変更前53/96列（55.2%）、最終53/96列（55.2%）。60%未達。固定の画面上端26%を96列×80行で測り、隣接する縦の線の最初の着地点が30m以上離れる列を数えた。
- 石段脇の最大差：0.087m（6,834点）。細かな升目でも段の下は元の地面を保持し、端の地面だけを鼻先へ寄せた。
- 帰還：家167軒、町の木143本、庭木の印6個に6本。序幕：家169軒、町の木143本。同じ地形・配置・模型を使う。
- 屋根の投影割合：帰還42.78%、序幕44.12%（町に当たる線8,576本）。家の箱を同じ画角から測った値で、実画面の屋根画素率ではない。
- 石段：1,032→392三角形。材料ごとの描画群は5→6。GPUの実描画回数・FPSは未測定。
- 帰還の町の作業量：区画候補1,168、地面13,402、箱87,232、道16,689回の確認。屋根の計測は10,040,644回の作業。
- 作り物の配置：769候補、585回の高さ確認、20組。実配置した岩392個。裾・大岩・手前の岩は予定数と実数が一致。
- 家の試験範囲は合成100〜125軒、模型付き150〜190軒へ。屋根割合は34%から40%へ強化した。指定の区画・小家・揺れを使う町へ変わったため。
- 小さな座標差を許して庭木の位置を確認する（1mm未満）。バイナリにした行列から区画を再計算すると、浮動小数の末尾だけが変わる。
- 密集した町の区画色が畑を上書きしたため、畑の色を後から塗る順へ直した。畑の縞の既存試験は弱めていない。

## 実Chromeで確かめる

実Chromeは未実施。透視図は地形と配置の確認用で、光・霧・屋根の細部・火・人の見た目を再現しない。

1. `KZ_WORLD_DIR=.world-out/kamakura-return node tools/serve.mjs` を起動する。
2. `/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1` を開く。明るい石段が斜面に収まり、町の家と木、大仏の敷石・砂利・草が読めるか見る。
3. 歩く視点で浜から石段を上り下りする。縁の石の浮き・段の横の露出・地面の継ぎ目を確認する。
4. `KZ_WORLD_DIR=.world-out/kamakura-escape` へ切り替え、同じURLで見る。右下の低木と岩が道・町・海・火元を隠さないか確認し、退路を往復する。
5. `&veg=0`・`&works=0`・`&townfill=0` を一つずつ付けて差を比較する。追加の単色デバッグ旗は無い。新しいゲーム層は追加していない。
