# R11 設計メモ：人と生き物・参道・川の形・主人公の動き（W2c-17・2026-11-10）

要件は `requirements-web-polish.md` の WW14。検証の数字は `w2c-17-*-validation.md` に書く。

## 誰の、どんな場面のためか

「私は鎌倉の町を歩いている。道の先から町人が歩いてきて、すれ違うときに会釈する。八幡宮へ続く敷石の参道の両側に灯籠が並び、堂の前で人が手を合わせている。川は曲がりながら流れ、浅瀬に白鷺が立っている。だから、ここは人が暮らしている町だと感じる」。

R10 の盲検で、全部入りの版は平均 5.7 点だった。講評が挙げた最大の差は「広場と斜面が単一の模様のままで、人の営みが無い」こと。R10 は風・光・音・小さな生き物を足したが、人と、人が作った地面（参道）と、川の形は手つかずだった。

## UX の5階層から決めたこと

| 階層 | 決めたこと |
|---|---|
| 戦略 | 成功の物差しは、本人が歩いて「人が暮らしている」と感じること、盲検の講評で寺社と町の場面が +1 点、川沿いの場面で「階段状」の指摘が消えること。 |
| 要件 | 人は、物語の相手でなく風景として置く（話しかけ・売買・依頼は作らない）。川は見た目だけでなく、歩ける場所・水の深さも同じ形にそろえる。 |
| 構造 | 人の置き場所は、すでにある道・家・施設・場所の性格から決める（新しい私有データを足さない）。参道は、灯籠を並べるのに使っている「門から堂への線」をそのまま使う。 |
| 骨格 | 人は主人公の近く（約 60m）だけ出し、動かすのは近い数人だけ。近づくと会釈する（こちらを見ている、と分かる合図）。白鷺は水の上の白で、遠くからでも見える。 |
| 表層 | 人の服は、すでにあるモデルの色のまま。敷石は灯籠と同じ灰色の石。白鷺は白。 |

この表を通して、実装が 6 つ決まった。①人は、まず第一章（谷）の町人・子どものモデルと所作を使う（新しい人物は、主人公の候補を見てから）。②人のモデルは遅れて読み込む（合計で約 20MB あり、最初の表示を待たせない）。③会釈を入れる（置物でなく、こちらに気づく人にする）。④参道は新しいデータを作らず、施設の並びから導く。⑤川は、地形の升目（約 3.9m）のままで、岸を 2 升ぶんの幅のなだらかな斜面に彫り直す（細かい升目の追加はしない）。⑥主人公の動きは位置を変えず、姿勢だけを足す（R10 の「しぐさ」の層の続き）。

## 主人公：前に試して退けられた直し方と、今回の直し方

本人の追加の依頼（同日）：「刀の持ち方、走る時のモーションを直してほしい。人物自体も変えてよい。既存のものを使わなくてよい」。

近くから撮ると、小走りと走りは、上体が後ろへ反り、あごが上がり、両手を胸の前に出して指を開いたままだった。構えは顔の高さで、右ひじが頭の横まで上がる。立ち姿は腕が体から浮く。鞘は、ただの筒が腰の横に浮いて見える。

走りの腕は、第一章の磨き（M3・2026-11-04）で一度直そうとして、盲検で退けられている。「腕を前へ大きく振る・ひじを伸ばす」版は、手が首の高さまで上がり、開いた手のひらを前へ差し出す形が棒に見えた。今回は、同じ道を通らない。

| 決めたこと | 理由 |
|---|---|
| 左手は鞘を握る（立つ・歩く・小走り・走り） | 振る腕が 1 本になり、鞘も暴れない。刀を差した人の所作として自然 |
| 右手は軽く握り、手の高さを腰〜みぞおちへ下げる。ひじは畳んだまま | 退けられたのは「ひじを伸ばして開いた手を前へ出す」形。ひじを畳む形は好まれていた |
| 前傾を、小走りの速さから入れる（今は 3m/秒を超えてから。既定の小走り 2.5m/秒では 0） | 上体が反って見える主因 |
| 構えは中段にする。技・受け・回避の間は、元の動作へ 0.1〜0.15 秒で戻す | 技の動作は高い構えから作られているので、立っている間だけ置き換える |
| まず鎌倉の散策だけに入れる（第一章は変えない） | 第一章には、姿勢を数字で固定した試験と盲検の記録が多い。本人が見て良ければ、次に広げる |

## 捨てた案

- **動物（馬・鹿・犬）のモデルを外から足す**：権利が放棄された低ポリゴンの動物の素材集はあるが、角ばった簡略な造形で、いまの人物と並ぶと浮く。まず白鷺（手続きの形で足りる）だけを入れ、馬などは素材の選び方を本人と決めてからにする。
- **川に沿って細かい升目の地形を足す**：切通の道で使っている仕組み（升目を 4 分割）を川の全長に広げる案。データが約 8MB 増え、川と切通が交わる所の扱いが要る。岸を幅のある斜面にすれば、いまの升目でも水際は曲線になるので、先にそちらを試す。
- **走り出しと止まりに慣性を入れて位置を変える**：操作の手応えが変わり、当たり判定と歩ける範囲の試験をやり直す必要がある。姿勢の傾きだけで「勢い」は伝わる。
- **人に話しかける・店を開く**：物語と仕組みが要る。散策の「気配」には不要。

## 既知の制約（始める前から分かっていること）

- 人物のモデルは 1 体あたり約 5MB で、骨で動かす（重い）。同時に動かす数と描く距離に上限を置く。スマートフォンでは、さらに減らすか切る。
- 川を彫り直すと、川の近くの家・木・道・小物の位置との関係が変わる。家が水に入らないことを、書き出しの中で確かめる。
- 白鷺・人・主人公の動きは、静止画の講評では評価しにくい。録画のコマで確かめる。
