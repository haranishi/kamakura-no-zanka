# W2c-9c3 草の水玉を群生と高さの差へ置き換える

9c3依頼書を仕様として引き継ぎ、草の担当範囲を実装した。
Nodeで分布・被覆・品質・谷の互換性を確認した。画質の受け入れとGPU性能は親の実機確認が残る。
world-kamakura.js、他担当のコード、依存、外部素材、通信、commit・pushは変更していない。

## 距離と環境で草を分ける

丸い同形の株が並ぶ原因を、形と分布の両方から直した。世界座標のハッシュを保ち、
カメラの距離は草種の混合と間引きだけに使う。境界前後2mでは形を補間する。

|距離|高い株|中くらい|低い株|
|---|---:|---:|---:|
|12〜30m|30%|50%|20%|
|30〜70m|20%|80%|0%|
|70〜120m|0%|100%|0%|

高い株は地上0.45〜0.75m、中くらいは0.25〜0.40m。幅と色は独立に0.6〜1.8倍。
道・家・塀・木・水際の取り残しの帯は70mまで高さ0.5〜0.8mを優先する。
根元を0.12m埋め、その分を板の高さに足して、低い株が地中へ消えるのを防ぐ。
先端を黄緑〜金色、根元を暗くする。遠方へ薄い青灰を混ぜ、弱い発光項で夕方の下限を補う。
9c2の地面色×0.68・最大40%混色は維持した。最終画素の明度保証はしていない。

3mと12m尺度の場にしきい値を設け、群生・疎な場所・空地を分ける。
各1m升の根は従来の99.8%ジッターを保ち、板数を1升最大1株へ減らす。
30m以遠で間引きを増やし、95mで残存率12%、102〜120mで消す。
急斜面は30〜32°で薄くし、従来の32°セル除外・36°四隅除外を維持する。
稜線は4m離れた4方向との高さ差で近似し、凸な地形を薄く、谷を濃くした。

道の中心から2.5mを道端とし、その外0.4〜1.2m、箱／幹の外1.2m、
川岸から0.25〜1.5mを縁とする。町の道は土と草の境界を0.75／1.2mで調べる。
家裏・塀沿い・川沿いを濃く、開けた土を薄くする。草地の近景密度は旧設定を下限にする。
縁を残すため、lookありだけ衝突物・川の広い除外余白を狭めた。

## 実行結果と性能の限界

- 開始時：npm testは1,103成功・20省略。check成功。smokeはlisten EPERM。
- 担当試験：GLSLフックと全include展開後の括弧・条件分岐対応を確認。
  patch・sample・input・output・common・filter・activeの予約語宣言を拒否する。
  生成したGLSLの草種計算をJSで評価し、70m以遠の高い株の率が0になることも検査する。
- 最終npm test：私有なし1,128成功・21省略、KZ_WORLD_DIR指定は1,149件すべて成功。
  npm run checkも私有なし／ありで成功。終了時smokeはlisten EPERM（HTTP待受け禁止）。
- FILES_SHA256.jsonを指定スクリプトで再生成。git diff --checkも成功。
- 日本語文書lintはsudachipy未導入で実行できず、目視で確認した。依存追加は行っていない。
- 全体試験の途中は海側が失敗。1分以上後の再実行では私有なし／ありとも全件成功した。
- 私有3地点の初期送信：芝1,701〜5,369、葉4,655〜9,004、花0〜2、中景261〜1,108株。
  三角形82,920〜166,752。初回warm143〜340ms。初期窓の値であり全域の上限ではない。
- 同じ合成草地で保存した9c2とのNode比較：定常0.000517→0.000570ms/コマ、
  25m移動の平均0.928→0.747ms/コマ。送信合計173,103→69,550、三角形1,367,124→767,640。
  描画APIは代役、同時作業・JITの影響あり。GPU込み+0.2ms達成の証拠にはならない。
