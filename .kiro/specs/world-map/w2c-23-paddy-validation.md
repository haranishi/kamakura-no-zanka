# 棚田の検証（2026-11-12）

棚田を、黄金色の稲の田にした。実際の Chrome で、見渡しと歩く視点を撮って確かめた。見渡しでは、黄金の田が区画ごとに色を変え、その間を緑の畦が走り、刈った田に稲架が立つ。歩く視点では、畦は草の土手に見える。刈田には、切り株が列になって並ぶ。エラーは 0。

## 実際の Chrome で見て直したこと

最初の版は、見渡し 40m と南の低い空 14m では、黄金の田・緑の畦・区画・稲架が読めた。
歩く高さでは、次の 4 点が作り物に見えたので、直した。

1. 石積みが、畦の上に寝かせた明るい灰色の四角い板に見えた。
2. 畦が、角の立った暗緑の箱に見えた。
3. 刈田の円錐が、大きく疎らな交通標識に見えた。
4. 刈田が、濃い橙色の平らな運動場に見えた。

既存の地形には、0.55mの段差がない平坦部と、南端で逆向きに上る部分がある。

石の固定2層・固定落差を要求していた旧試験は、この実測と1段積みを検査する内容へ変更した。
道路・6本の列・長さ・範囲の検査は維持。描画量は予約容量ではなく実際の提出範囲で検査する。
地色の配線だけ `terrain.js` を変更し、地形の高さ・既存の地色処理は保った。
地形試験のNode用読込も追従させ、検査内容は変えていない。

## 実Chromeで確かめる手順

1. `/valley/index.html?qa=1&autostart=new&intro=0&cam=concept` を開く。固定画角未統合なら `__valley.camera([-50,40,110],[12,5,-80],50); __valley.step(30)`。
2. 同じ条件で `&paddy=0` と通常色を撮り、遠景の黄金色・6段・緑の線・稲架が保たれているか比べる。
3. `&paddydebug=1` は黄=立ち稲、茶=刈田、橙=途中、緑=畦、灰=石、赤=稲架。道が残るかを見る。
4. `__valley.camera(null); __valley.teleport(-10,49)` と `__valley.teleport(-55,62)`。石が畦の上に出ないか、草の土手と細い藁株に見えるかを歩いて確かめる。
5. 40m・150mの石の切替、株と地色の条の接続、風の明暗、南側の浅い石の埋まりを往復して見る。
6. `__valley.quality('light')` と標準、品質段階0〜3を比較し、`__valley.paddyStats()` と画面の数を照合する。
7. 統合後に `capture-concept.mjs` の8枚と移動動画を撮る。元の画角との比較で遠景の良さを判定する。

## 見た目を詰める定数（すべてpaddy.js先頭）

| 定数 | 現在値 | 増やすとどうなるか |
|---|---|---|
| `stoneMin / stoneMax / stoneDepthMin / stoneDepthMax` | .3 / .7 / .25 / .45m | 石が幅広く／厚くなる |
| `stoneHeightMin / stonePitch / stoneTilt` | .18m / .52m / 12度 | 浅い石が厚く／疎に／傾きが強くなる |
| `rockGain / rockVariation / rockSoil / rockGrass` | .65 / .12 / .12 / .10 | 石が明るく／色差が強く／土色へ／草色へ寄る |
| `bundWidth / bundHeight / bundGrassDensity` | .75m / .19m / 4株毎m | 畦が太く／高く／草が密になる |
| `bundJitter / bundHeightJitter / bundSoil` | .10m / .02m / .25 | 横の蛇行／高さの起伏／土のむらが強くなる |
| `grassMin / grassMax` | .15 / .4m | 畦の草が高くなる |
| `stubbleStep / stubblePitch / stubbleHeight / stubbleDiameter` | .3 / .26 / .11 / .10m | 条と株が疎に／高く／太くなる |
| `soil / soilGain / cutRiceMix / cutGain` | #967850 / .42 / .35 / 1 | 土の各色成分／土の明度／稲色の割合／刈田の明度が増える |
| `cutPatch / patchGain / rowDark` | .15 / 1.25 / .12 | 落ち藁の面積／明度／条の暗さが増える |
| `tintA / tintB / tip / riceGreen / groundGain` | #b8963c / #d6b658 / (.84,.64,.27) / .18 / 1.10 | 稲の各色成分／緑の残り／地色の明度が増える |
| `waveShade / variation / strawWhite` | .14 / .08 / .35 | 風の明暗／区画差／藁の白さが増える |

直したあと：畦は、緑の丸い土手に見える。刈田は、土の上に短い切り株が列になって並ぶ。田の色は、橙が弱まり、黄金色になった。
残った点：畦は、まだ平らに塗った緑で、草の房が少ない。石積みは、見渡しでは細い線にしか見えない。Safari・Firefox と、実機の性能は確かめていない。
