# W2c-9r3 ground：実機で見えなかった地面の追加修正

踏み跡・縁・色むらの振幅を増やし、12の前方に補助の踏み跡を加えた。
`&gyard=2`で赤＝踏み跡、緑＝縁、青＝色むらを確認できる。
Nodeでは振幅と12への帯の追加を確認した。実画像の合格判定は親のChrome検証に残る。

## 親の実測を受けて変更した理由

前回ef5cdddの合成標本は低周波2.905倍だったが、親の実画像は11で1.0倍、12で0.92倍だった。
合成標本だけでは画面上の改善を保証できない。今回のCOMMON・GROUND・GROUND-FIXを修正仕様とした。
色の計算は線形色なので、倍率をそのまま増やすと表示色では変化が縮む。
今回の18%・9%は表示色に近い明るさで扱い、2.2乗した倍率で線形色へ反映する。
踏み跡では輝度を保つ灰色を10%混ぜ、縁では緑の比率を少し上げる。
色むらは37/113mから70/150mへ広げた。振幅を増やしても細かな帯域を増やしすぎないため。
光・霧・後処理を含む最終画面では、この変化率と一致するとは限らない。

鳥居→堂の軸だけでは、12の入口側の広場を通らない。
施設の箱の長軸で、建物の寄りから遠い側を入口と推定し、最も近い床の箱の中心へ補助帯を引く。
床の箱がない場合は広場の中心へ向かう。門のない施設でも同じ処理で1本補える。
これは配置から推定した視覚表現で、史実の経路や実際の入口を主張しない。
既存の入口→堂の帯を残し、4m格子では符号付き横距離を補間してから3〜5mの帯へ変換する。
補助帯との間で横距離の符号が替わる遠い場所に偽の帯を作らないよう、横方向の支持域は8〜12mとした。

## 維持した条件と確認用表示

R2の不規則な石・密度のむら・RGB8/RGBA8・準備前の中立値・1.2秒の混合・資源破棄を維持した。
追加テクスチャはなく、毎コマのCPU処理も足していない。新しい倍率計算のGPU時間は未測定。
`&gyard=0`でR2相当、`&gtone=0`で旧経路へ戻る。light・適応2は0.45、適応3は停止する。
`&gyard=2`は照明・霧・出力変換の後でマスクの色を表示する。既定では表示しない。
赤はvalidを含む踏み跡、緑は縁、青は色むら。準備前は中立、準備後に混ぜ込む。
適応3では診断表示も停止する。通常表示と同じ資源・シェーダーを使う。
谷・庭・保存・共用ファイル・world-kamakura.jsは変更していない。
外部素材・依存・通信は追加していない。私有値の固定化・転記もしていない。

## 実行した検証

全Node試験・check・smokeに `NODE_OPTIONS=--max-old-space-size=1536 timeout 300` を付けた。
開始時：npm testは1260成功・27省略、npm run check成功、npm run smokeはlisten EPERM。
終了時：npm testは1263成功・28省略、npm run check成功（452構文・101モジュール・59純粋層）。
KZ_WORLD_DIRを指定したnpm testは1291成功・省略なし。地面の追加試験は9成功。
終了時のnpm run smokeもlisten EPERM。HTTP確認・ブラウザ起動・撮影は実施していない。
通常試験と私有試験を同時に走らせた際、担当外の水際試験が1件失敗した。
固定2回のupdateで準備完了を要求する箇所で、時間予算の影響が疑われる。
通常試験を単独で再実行すると全件成功した。水際コードと試験は変更していない。
踏み跡・縁・色むらをそれぞれ旧振幅へ戻したモジュールをメモリ上で読み、各下限が失敗することを確認した。
補助軸を除いた版では12の追加帯の同じ条件に失敗する。R2の帯域試験は維持した。
同梱Threeの組み立て・GLSLの括弧と条件分岐・A/B・診断表示・品質復帰・破棄を検査した。
git diff --checkは成功。文書lintはsudachipy不足で起動できず、クイック工程の手動確認を行った。
Git addは管理領域のindex.lockを作れず失敗。コミットは親に引き継ぐ。push・PR・マージなし。

## 親の実機検証（実Chrome・ヘッドレス・地面の用意後）

撮影は1280×720・`&autoscale=0`。比較の相手は、この修正の前の main（R2）。広場の低周波は、キャラ・影を除く左側（11＝x60〜470・y330〜640、12＝x60〜470・y380〜640）の、ガウシアン差σ8−σ24の輝度の標準偏差で測った。

- **最初の実装は、実機で効果が見えなかった**（11で 1.45→1.45、12で 1.09→1.00）。実データでは11のカメラ位置が踏み跡の範囲内（`valid=255`）なのに、シェーダーの振幅が小さかった（踏み跡 +7%・縁 −4.5%）。追加の直しで、振幅を（踏み跡 +18%・縁 −9%・色むらの標準偏差 5.7%）へ強め、色むらを70/150mへ広げた。
- **直した後**：11は 1.45→1.84（R2の約1.27倍。目標3.2には届かない）。ホールへ向かう、淡く明るい踏み跡の帯が見える。`&gyard=2`のマスクでも、帯がカメラ位置からホールへ伸びる。12は 1.09→0.99で、**帯がカメラ位置を通らず、広場に踏み跡は出ない**（マスクでは、右上の遠くにだけ出る）。
- 高周波（1〜3px帯・3〜8px帯）は R2 の 1.01／1.02倍（11）・0.93／0.91倍（12）で、水玉には戻っていない。広場の暖かさ（R−B）は 48.8→48.8（11）・35.4→34.5（12）。上空の陸の平均色は R2 と同じ（旧との差 −2.8／−2.8／−3.3）。01・02・07・08・09の平均輝度は不変。8画角の撮影でGLの警告・誤りは0件。
- **未達**：12の広場の踏み跡・両方の目標値。次の周で、12の帯の通し方（軸の取り方）を見直す。性能は、ほかの担当と並行していたため未測定（統合後に測る）。
