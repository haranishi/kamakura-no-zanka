# 森の構成と描画の検証

斜面に、群れの紅葉と古い杉を入れた。実際の Chrome で、見渡しと歩く視点を撮った。左上と奥の斜面に、赤と黄の広葉樹の塊が見え、杉の中に、頭ひとつ高い古い杉が立つ。エラーは 0。
保護域879本と、旗を切った全15,830本の種類・色・行列が従来と一致した。

## 要件と作り方

|要求|結果|
|---|---|
|G1 斜面の紅葉|実装。100m間隔で中心をずらし、半径25〜35mの楕円を位置雑音で変形。沢・緩斜面・窪みを優先|
|G2 群れの色|実装。既存の楓・欅から5段を作り、群れごとに隣接2段。全LODに同じ個体色|
|G3 杉のばらつき|実装。既存5形を利用。丈と幅を独立させ、古杉は太い幹と下半分の少ない枝葉。影にも同じ倍率と切り抜き|
|G4 松と林床|松を実装。林床は担当外のため見送り。調整箇所は下記|

位置・総数・kind・当たり・遮蔽・任務・セーブは変更していない。
新規モジュール、素材、依存の追加なし。変更は指定された木の3ファイルと試験・本記録のみ。
既存の固定本数と三角形の試験は切り戻し側に残し、有効側の割合・予算を別に検査した。
全体の広葉5〜12%という旧試験だけ、今回の18〜28%に改めた。

## 実Chromeで確かめる

`/valley/index.html?qa=1&autostart=new&intro=0&cam=concept` を開き、同条件で `&forest2=0` と比較する。
`&forest2debug=1` は杉＝緑、古杉＝青、楓＝赤、欅＝黄、松＝紫。`forest2=0` が優先する。
`__valley.treeStats().stats.forest2` に外側の前後本数、群れ、古杉、作業量、描画中の数と予算を出す。
標準と `&q=light` で群れの主色が同じか、下の緑との境、尾根の輪郭、古杉の枝の切れ方を見る。
近づく動画で48/150m（軽量32/100m）の色と輪郭、古杉の下枝、影の跳びを確かめる。
固定画角は `tools/scenarios/capture-concept.mjs` で前後を撮る。FPS は測っていない。

## 調整する定数と残件

調整値は全て `config.js` の `TREES.forest2`。値と増やしたときの効果は次のとおり。
群れ：`radius=[25,35]`mで広葉率と塊が増す、`cell=100`mで間が広がる、`warp=9`mで輪郭が崩れる。
`habitatGain=.22`で沢と肩を優先、`edge=.14`で縁の混在が増す。割合は半径と地形適性から出す。
色：`tones=[3,2.65,2,2,0]`は既存パレットの参照位置、`toneMix=[.18,0,0,0,.24]`は深紅と黄緑の混色率。
深紅・朱・橙は楓、黄・黄緑は欅から作る（基準色 #92432a/#ae502c/#c2652c/#c2a040/#86883c）。欅の橙段相当は既存の枯れ茶。
`neighbourTone=.3`で隣の色が増す。`leafBrightness=.10/leafHue=.06`で明るさ／色みの個体差が広がる。
杉：`height=[.7,1.45]`、`width=[.8,1.25]`。上限を増すと丈／幅が増す。
`oldRate=.045`で古杉が増す、`oldHeight=[1.5,1.9]`で古杉が高く、`oldWidth=1.45`で太くなる。
`oldCrown=.5`で下枝を落とす高さが上がる。`pineRate=.06`で松が増す。
`cedarBrightness=.09/groupBrightness=.07`で杉の個体差／群れの明暗差が増し、`shadeBlue=.06`で陰が青くなる。
林床は `terrain.js:221` の近景RGB係数 `.66/.5/.7` と、`:255` の遠景 `fcol` の `.1/.14/.11`。
講評 1 周目で「斜面が、茶色の急な壁に見える」と言われ、森の下の暗さを強めた（`terrain.js` の `FOREST_FLOOR`：近景の倍率 1.5・急斜面で戻す量 0.5→0.15・遠景の倍率 2.6）。
残った点：見渡しの画面は、まだ半分が濃い緑の杉で、絵ほど紅葉が多くない。遠い斜面は、木がまばらで、木の間の地面が黒く見える。近景と遠景の地面の色に、段がある。近づいたときの、形の切り替えの跳びは、動画では確かめていない。
