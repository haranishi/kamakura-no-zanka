# 要件：鎌倉を歩く（Web 取り込み・W2c）

2026-11-06 ドラフト。[world-map の要件](requirements.md) WM7・WM9 と [鎌倉の要件](requirements-kamakura.md) WK5 の続き。EARS で記す。数値は受け入れ目標で、実測の記録ではない。調査（`craft/report/w2c_survey.md`）のあとで数値を直す。

## 前提と決定

- 本人の言葉（2026-11-06 夜・音声）：「ただ、歩いたりはできない感じ。マップは作ってない感じですか？」「まだじゃあマップは作ってないのね？歩けるね」。Blender の中に世界はあるが歩けない、と伝えた上でのこの発言を、**歩ける形にしてほしい**という意向と読む（聞き取りの誤りがありうるので、最初の試作を見せて確かめる）。
- 歩ける範囲は案A（七切通の内側・約11km²）に決定済み（2026-11-06）。
- 変えない決まり：commit・push・公開・デプロイは本人が明示するまでしない。**国土地理院の標高を加工したデータはリポジトリの外に置く**（公開してよいかは未確認＝測量法）。素材は CC0／OFL。手本のゲームの画像・コード・数値は使わない。
- 既定のゲームは変えない。取り込みは切替（`?world=on`）で入れる（WM7.2）。

## ユーザーストーリー

1. プレイヤーとして、URL を開くだけで、若宮大路に立ち、歩いて・走って、鶴岡八幡宮・長谷の大仏・七切通まで行きたい。
2. 手元の PC でも、スマホ（指）でも、同じ世界を歩きたい。
3. 画面は、Blender の12枚（光・霞・木・家）に近い見た目であってほしい。
4. 待たされず、カクつかず歩きたい。
5. 家や壁や水に突っ込まず、坂を歩けて、いま自分がどこにいるか分かりたい。

## WW1 世界の取り込み

1.1 `?world=on` のとき、歩ける範囲（案A）の地形・家・木・草・道・水・主な施設を、Blender の書き出しから読み込んで表示する。`?world=on` でないときは、いまのゲームと同じ動作・性能のままにする。
1.2 世界の座標は Blender と同じ（x 東・y 北・z 上、1升目 3.89785m）。縦の強調（1.8倍）は Blender 側の見た目の値なので、Web では歩く高さを実際の高さ（強調前）で扱うか、強調したまま扱うかを設計で決め、記録する。
1.3 読み込む元データは、リポジトリの外の置き場から読む。国土地理院の標高を加工したものは、公開用のリポジトリ・公開サーバーへ置かない（本人が許可するまで）。

## WW2 歩く

2.1 プレイヤーは地形の上を歩く・走る。地面の高さに沿って足が付く。
2.2 勾配40度以上の斜面は歩けない（ゲームの規則）。壁・家・水の中には入れない。
2.3 七切通を通って、境界の外へ抜けられる。範囲の外れ（案Aの縁）には、見えない壁ではなく地形・海で止まる所を選ぶ。
2.4 PC は既存の操作（キー・マウス）、スマホは既存の指の操作で動かせる。マウス固定（ポインターロック）の自動試験は、ガードを使って本人のカーソルを動かさない。

## WW3 見た目

3.1 光（太陽の向き・色）・霞・空は、Blender の `lighting.json` の値から決める。
3.2 木・家・草は、インスタンス（同じ形の部品の繰り返し）で出し、距離で間引く。
3.3 風は `wind.json` を使う。**揺れ幅は距離で調整する**（遠い木は見えにくく、近い植物は強すぎた）。植物ごとに周期をずらす。
3.4 画面が重いときは、見た目を落とす順（影・草・遠い木・霞）を決めて自動で下げる。

## WW4 重さと読み込み

4.1 最初の画面が出るまでの待ち時間・通信量・歩いているときのコマ数の目標は、調査と測定で決める（既存の目標：追加の容量は合計10MB以内〔WM7.1〕。足りなければ理由を添えて見直す）。
4.2 読み込みは、いる場所のまわりを先に。歩いて近づくほど細かく。
4.3 実機（PC の Chrome）と、可能ならスマホ実機で測り、記録を残す。測っていない数字は目標として書かない。

## WW5 検査と見せ方

5.1 世界の位置が Blender と1m以内で一致する（地点・道・高さ）。
5.2 歩けない場所（水・急斜面・家の中）に入れない。落ちる穴・空中に浮く足場がない。
5.3 画面付きの確認と採点は、実機で遊んで10項目を採点する別役（Opus）の周回（体験→見た目の順・3周まで）。最後の判定は本人が歩いて決める。
5.4 本人に見せるのは、歩ける試作のページ1つと、歩いている動画1本。

## WW6 この後の段階

6.1 既存の1章（里・戦闘）との接続、時代の層（1333・1334・1335）の切り替え、住民、全体マップの画面は別の単位。
