# W2c-9e2 海・波打ち際の修正と検証

泡と濡れを8mの符号つき岸距離へ切り替えた。担当Node試験は私有データ込み12件成功。
合成岸の位置は±1m以内。ただし私有全域の曲がった岸には最大約1.78mのずれが残る。
実画面の合否・GPUコンパイル・1コマ追加0.3ms以内は親の実機確認待ち。

## 設計と変更範囲

- 9aの16m音用格子は維持。描画には8m・±240mの符号つき格子を追加した。
  海判定と高さ0の交差だけを使い、陸海の隣接標本間を高さで補間して初期距離を得る。
  その後3–4 chamferで伝搬する。川は初期値に含めない。
  完成後terrain.shoreSignedへ公開。海と地面でR16F・LinearFilterの1枚を共有する。
- 高さ勾配だけによる初期値は、浅い海底と陸の傾きの差で位置がずれたため採用しなかった。
  8m格子の双一次補間では曲折部の±1mを全域保証できない。追加照合の中央値約0.10m、95%点約1.22m。
- 海は浅瀬の緑青から沖の暗い青へ。粗さ0.22・環境反射0.5。
  夕方の空色・太陽色・太陽高度は既存の大気設定から取り、海の色と照り返しへ渡す。
  海平面を200kmに広げ、有限平面の端が水平線に出るのを避けた。霧は既存のまま。
- 異なる方向の2つのうねりと、ドメインワープしたノイズの小波を使用。
  画素幅で振幅を絞る。泡は海の照明から独立した白い水膜として霧の前に合成する。
- 砂・湿砂のクラス0/1だけに符号つき距離の濡れ・満潮線・風紋を適用。
  草・土・岩の関数と最後の合成行は変更していない。
- 川岸は川リボンの外へ1.5m、地面から1.5cm上の独立した帯。
  外へ透明になり、泥・小石のむらは画素幅で平均へ戻る。海の所有物として生成・破棄し、
  world-kamakura.jsと川の透け方には最終的な変更なし。water=0でも帯を作らない。
- 小物は地表クラスに依存せず、陸側0〜16m、海と川を除外。標準300／軽量120個まで。
  軽量は小波を省き風紋を減らす。段階2は小波・散った泡・小物なし、段階3は泡・濡れを固定。
  seav=0で今回の見た目・川岸・追加格子を切る。毎コマの新規確保なし。

## Nodeの証拠（v24.22.1・GPUを含まない）

- 合成の直線と3方向の斜め岸：位置誤差±1m以内、符号・単調性・上限・範囲外を検査。
  川だけの地形が海岸の初期値にならないことも検査した。
- 5時刻×0〜12m、強度0.1超の被覆率：泡は全時刻24.0%、濡れ25.9〜43.9%。
  JSとGLSLで泡・濡れ・満潮線・風紋の定数を共有。寄せ引きの位相はwaveEnvelopeと共通。
- 担当試験を単独実行：格子1363×1045、作成191.71ms、R16F 2,848,670バイト。
  海の升13.7%。準備は分割し、851回・215.30ms、最大update 0.411ms、定常平均0.00017ms。
  60Hzで準備約14.2秒に相当する。最終の全体並行実行では作成544.04ms、986回、最大update 62.526ms。
  割り当て・GC・他作業の影響は未切り分けで、0.25msは厳密な上限ではない。
- 指定2地点の小物は53／63個（424／504三角形）。上限は標準2,400／軽量960三角形。
  前回の0個という試験はURLのnorthを内部のz=southへ反転していなかった。今回修正した。
- 海・地面・小物・川岸の生成後シェーダーを同梱Threeで取得し、波括弧・丸括弧をスタックで検査。
  #if/#ifdef/#ifndef/#endifの対応も検査。不正な括弧・未閉鎖条件を確実に拒否する。
  生成と各1回の破棄、無効化、品質切替も確認。GLSL実コンパイルは行っていない。
- 全体再実行：私有なし1,098成功・20省略、私有あり1,118成功。checkは両方成功。
  初回は並行担当の草の試験が失敗。その後の全体試験でも地面担当の試験が一時失敗したが、
  1分以上後の再実行で成功した。担当外ファイルは修正していない。
- smokeは開始側・終了側ともlisten EPERM。ブラウザ・撮影・性能・聴感は実行環境の制約で未確認。

## 親の確認と残件

基点 `/valley/index.html?world=kamakura&debug=1` に以下を付ける。
準備完了まで15秒程度以上待ち、同じ画角で0／5／10／15／20秒を撮影する。

1. `&pos=-1057.2,-1809.4&yaw=180` と `&pos=-1849.2,-1465.4&yaw=120`：白い泡と暗い濡れの移動、小物。
2. `&time=evening`：空と合う暗さ、太陽方向の光の道、水平線。seav=0と比較する。
3. `&pos=-521.0,-2.5&yaw=45`：川の外側の濡れ帯、地面への接地、川の透け方の維持。
4. `&q=light`、`&autoscale=0&adaptstep=2`、同3と復帰。GPUエラーと増分費用も比較する。

次の最小ステップはこの実機比較。曲折岸の残る位置ずれとGPU予算を判定する。
