# 切通しの岩壁：傾いた地層と崩れた輪郭の検証

岩の塊に、傾いた地層・内へ倒れる壁・張り出しと窪み・乱れた頂と輪郭を足した。実際の Chrome（序幕・夕暮れ）で確かめた。見渡しでは、箱の形だった岩が、高さの違う岩の塔が寄り集まった形に変わった。歩く視点では、斜めの層が走る、内へ倒れた岩の壁に見える。コンソールのエラーは 0。設計した切通しの 2 範囲は、62 個の塊・12,740 三角形・描画 1 回。

## 要求と判断

| 要求 | 状態・判断 |
|---|---|
| K1 地層の傾き | 実装。頂・壁・岩肌で同じ層の座標を使う。既定9度、任意の向きも読める |
| K2 壁と強い層 | 実装。3〜9度の傾き、4〜6層に1層の強い出入り、標準で下面も作る。共有する角の移動量は細い領域が交差しない範囲へ制限する |
| K3 頂と輪郭 | 実装。35%の頂を変え、道以外の外周の約45%を下げる（角の選択を優先）。角も下げる。道の保護と地形から0.15mの余裕を優先する |
| K4 色 | 実装。下面と窪み−30%、縁と棚の上+10%、岩の暖冷差±4% |
| 旗・量・品質 | 実装。`cragdip=0`で従来の形。属性4個、描画1回。上限を超えると幅を一律に広げる |

- 地形から必要な余裕ぎりぎりの頂を下げると、全件が安全補正で元に戻った。最低高の上に2層分の余裕を置いてから崩す判断をした。新しい頂は、その余裕の分だけ高くなり得る。
- 角ごとに別の方向へ縮めると、細い塊で頂の三角形が重なった。共有する角の移動を周囲の辺までの距離で制限し、凹んだ頂は凹みを保つように分割する。重なりを実際の出力で検査する。
- 水平な頂と垂直壁を前提にした既存試験は、旗で切った場合にそのまま残した。傾いた場合には、層の座標・地形からの余裕・実際に送る継ぎ目の頂点を別途検査する。属性の期待値は3個から4個へ変更した。

## 実際の Chrome で見て直したこと

はじめの版で見て直したこと：

- **最初は、色だけの平らな面だった。** 近くでは、淡い色の板を積んだコンクリートの壁に見えた。岩肌の模様と起伏を足した。
- **岩肌を足した直後は、石垣に見えた。** 同じ厚さの層に、等間隔の縦の割れ目が並んだためである。層の厚さを高さで変え、溝を所々で途切れさせ、割れ目の 6 割を間引いて傾けた。
- **色が明るい薄紫だった。** 夕暮れの青い光の下で、樹脂のように見えた。岩の明るさを、元の崖の色の 0.56 倍にし、半分を暖かい灰色へ寄せた。
- **壁の裾に、地形の三角形がのこぎりの歯のように出た。** 高さの表の崖が、升目に対して斜めに走るためで、この層を入れる前からあった。範囲の道の側の縁を、道の中心から 1.75m → 1.45m へ寄せると、岩の壁が歯を隠した。
- 面取り（0.12 → 0.2）と層の出入り（最大 0.10 → 0.20m）を強めた。見渡しで、塊の縁と段が読める。

絵と並べた講評のあとで、形を直した版（傾いた地層など）で見たこと：

- 講評では、「四角い板を水平に積んだ石積みか塔。上面は敷石のように平ら。近くでは、横線の入った巨大な平らな板」と言われた。
- 直したあと：見渡しでは、頂の高さがばらつき、外周が段々に下がるので、箱の輪郭が消えた。歩く視点では、壁が内へ倒れ、層が斜めに走る。
- 残った点：細い塊が、薄い板のように 1 枚だけ高く立つ所がある。面は平らなままで、近くでは切り出した石に近い。

## 実Chromeで確かめる手順

1. 岩の範囲のある設計した世界で`/valley/index.html?world=kamakura&debug=1&fly=1&cam=overlook&time=dusk`を開く。同じ画角で`&cragdip=0`の前後を撮り、斜めの層・不ぞろいな頂・外周の段差を比べる。
2. 歩く視点で壁から2〜10mへ寄り、張り出しの下面と窪み、継ぎ目や地形の露出を見る。`&craglook=0`で岩肌だけ切り、形による差も確かめる。
3. `&cragdebug=1`は岩の頂が水色・土の頂が緑・面取りが黄・壁と棚が桃。`__kzCrag()`で`dip`・`strong`・`lowered`と描画量を読む。
4. 軽量品質と適応段階0〜3でも確認し、`&crag=0`で層が消えることを確認する。

## 残る制約

実機の FPS は測っていない。草木は追加していない。共有角の移動制限に達すると壁の倒し・強い層の出入りは指定値より小さくなる。道に接する角は道の保護を優先して下げない。地形の安全補正により、指定段数を下げられない塊もある。
