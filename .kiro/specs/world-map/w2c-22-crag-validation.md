# 切通しの岩壁：岩の塊の層の検証

切通しの岩壁に、段と角のある岩の塊を重ねて描く層を足した。実際の Chrome（序幕・夕暮れ）で確かめた。見渡しでは、灰色の円錐だった壁が、棚のある岩の塊に変わった。歩く視点では、層のある岩の壁に見える。コンソールのエラーは 0。岩の範囲は、地図の作り物のデータ（`crags`）で決める。範囲の無い地図は、今までと 1 ビットも変わらない。

## 何を作ったか

- 範囲（凸多角形）の中を、れんが積みのようにずらした点のボロノイ領域へ分け、領域ごとに 1 つの塊を立てる。
- 塊の頂は、下の地形より高く、範囲で共通の層の刻みにそろえる。となりの塊と頂がそろうので、棚と層に見える。
- 壁は、となりの塊の頂より上だけを作る。層ごとに少し出し入れし、頂の縁は面取りする。
- 色は、その場所の地面の色を、今ある「急な斜面を岩にする」色の作り方に通してから、暗い灰色へ寄せる。頂の一部は、土と草の色のまま残す。
- 近くで見える岩肌（粒・層の溝・割れ目）は、位置から手続きで作る。画像も、頂点の追加の値も使わない。同じ起伏で、陰影の向きも曲げる。
- 当たり判定は持たない。歩ける範囲は、地形と歩行範囲のデータが決める。

## 実際の Chrome で見て直したこと

- **最初は、色だけの平らな面だった。** 近くでは、淡い色の板を積んだコンクリートの壁に見えた。岩肌の模様と起伏を足した。
- **岩肌を足した直後は、石垣に見えた。** 同じ厚さの層に、等間隔の縦の割れ目が並んだためである。層の厚さを高さで変え、溝を所々で途切れさせ、割れ目の 6 割を間引いて傾けた。
- **色が明るい薄紫だった。** 夕暮れの青い光の下で、樹脂のように見えた。岩の明るさを、元の崖の色の 0.56 倍にし、半分を暖かい灰色へ寄せた。
- **壁の裾に、地形の三角形がのこぎりの歯のように出た。** 高さの表の崖が、升目に対して斜めに走るためで、この層を入れる前からあった。範囲の道の側の縁を、道の中心から 1.75m → 1.45m へ寄せると、岩の壁が歯を隠した。
- 面取り（0.12 → 0.2）と層の出入り（最大 0.10 → 0.20m）を強めた。見渡しで、塊の縁と段が読める。

|---|---:|---:|---:|
| 設計した鎌倉の切通し 2 範囲（実際の Chrome） | 2 / 60 | 6,877 / 1 | 12.28m |
| 合成の 4 範囲・標準（Node） | 4 / 663 | 上限 36,000 以内 / 1 | — |
| 同・軽量（Node） | 4 / 200 | 上限 18,000 以内 / 1 | — |

合成の入力は、合計 4,900m²・幅 1m・層 0.4m・高さ 12m で傾き 75 度の面を含む。上限を超えるときは、塊の幅を同じ倍率で広げて収める（標準で 1.82 倍・軽量で 3.32 倍）。描画の数は本体だけで、影は別。輪郭は、面積の誤差 1e-5m² 以下で埋まり、領域の重なりは 1e-6m² 未満だった。実機の FPS は測っていない。

## 試験

- 個別の試験 15 件（成功 14・省略 1。省略は、私有データを渡さないときの 1 件）。データの検査・割り付け・高さ・形・色・旗・解放・品質の段階を見る。
- 岩肌のシェーダー：差し込む印が実在し 1 回だけ入ること、起伏を読む前に計算すること、層の厚さの乱れで層の順が入れ替わらないことを見る。括弧・数値の型・未宣言の名前は、文字列の検査と `glslc` のコンパイルで見る（`glslc` が無い環境では省略）。
- 私有のデータでは、例外を出さないことと上限だけを見た。由来する値は、記録していない。
- 全体の試験・構文と配線の検査・スモークは、取り込みの前に通した。

## 確かめる手順

1. 岩の範囲のある世界で `/valley/index.html?world=kamakura&debug=1&fly=1&cam=overlook` を開く。
2. `&crag=0` と見比べる。`&craglook=0` で、岩肌の模様と起伏だけを切れる。
3. `&cragdebug=1`＝頂（岩）が水色・土の頂が緑・面取りが黄・壁が桃。`__kzCrag()` で、範囲・塊・三角形・描画・幅の倍率・いちばん高い壁・いちばん近い塊を読む。
4. 歩く視点で、壁から 2〜10m へ寄る。継ぎ目から地形が見えないか、岩肌が石垣に見えないかを見る。

## 見た目を詰める定数（`kamakura-crag.js`）

| 名前 | 現在値 | 上げたとき |
|---|---|---|
| `CRAG.stretchMin / stretchMax` | 1.5 / 2.6 | 塊が、層の向きへ長くなる |
| `CRAG.acrossMin / acrossMax / jitter` | 0.8 / 1.25 / 0.3 | 塊の幅と、並びの乱れが増える |
| `CRAG.bevelRatio / bevelMin / bevelMax` | 0.2 / 0.12m / 0.5m | 面取りが広く深くなる |
| `CRAG.offsetMin / offsetMax / offsetShared` | 0.04m / 0.2m / 0.6 | 層の出入りと、となりとの向きの一致が増える |
| `CRAG.bandVariation / blockVariation / darkShade` | 0.10 / 0.06 / 0.18 | 層ごと・塊ごとの明暗の差、暗い層の暗さが増す |
| `CRAG.footHeight / footShade`・`seamWidth / seamShade` | 1.2m / 0.25・0.12 / 0.12 | 壁の下の暗い帯・継ぎ目が、広く暗くなる |
| `CRAG.soilRate / soilHeight` | 0.65 / 1.2m | 土の頂の割合と、対象になる高さが増える |
| `CRAG_LOOK.tone / grey` | 0.56 / 0.5 | 岩が明るくなる／灰色へ寄る |
| `CRAG_LOOK.bed / uneven / unevenGain` | 0.5m / 0.85 / 1.25 | 層が厚くなる／厚さの変わり方が速く、大きくなる |
| `CRAG_LOOK.groove / grooveDark` | 0.08 / 0.3 | 層の溝が太く／暗くなる |
| `CRAG_LOOK.joint / jointKeep / jointSlant` | 2.3m / 0.62 / 0.5 | 割れ目の間隔が広がる／間引きが増える／傾きが増す |
| `CRAG_LOOK.relief / bump` | 粒 0.022・溝 0.04・割れ目 0.035m / 1 | 起伏が深くなる／陰影が強くなる |
| `CRAG_LOOK.fineFrom / fineTo` | 0.03 / 0.14m 毎画素 | 遠くまで、細い線を残す（ちらつきやすくなる） |

## 残る制約

- 塊の面は平らで、垂直に立つ。近くでは、まだ「切り出した石」に近い。面を傾ける・角を欠く、という作り込みはしていない。
- 岩の頂の草木は、この層では作らない。地図の植生のデータで置く。
- 高さの差が 100m を超える範囲がいくつもある入力は、塊を粗くしても上限を超え、例外になる。切通しの大きさを対象にしている。
- 地面の色の無い世界で岩の範囲を指定すると、例外で知らせる。代わりの色は足さない。
