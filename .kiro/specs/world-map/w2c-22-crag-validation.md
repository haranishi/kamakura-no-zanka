# 切通しの岩壁：折れた頂・壁・岩肌・草色の検証

頂を3〜4面の屋根へ折り、外周の長い壁に折れを足した。遠景の細線を消し、大きな明暗と草色を加えた。実際の Chrome（序幕・夕暮れ）で確かめた。見渡しでは、レンガのような細かい線が消え、暗い縦の割れ目の入った岩の塊に見える。コンソールのエラーは 0。設計した切通しは、標準で 62 塊・14,602 三角形・描画 1 回。

| 要求 | 実装／見送りと判断 |
|---|---|
| L1 頂 | 実装。3〜4枚の平面を、内側の1点へ集まる三角形で描く。7割を高く・3割を低くし、地形から0.15mの余裕を補正する |
| L2 壁 | 実装。共有辺を変えず、外周の2.2m以上の辺だけに中点を足す。軽量では省く。頂との接合面も折れた高さへつなぐ |
| L3 岩肌 | 実装。細線は0.012〜0.05m/画素で消す。大きな帯・途中で切れる縦割れ・頂の風化色を追加。細かな割れ目は8割を間引く |
| L4 草 | 実装。上向きの面へ地面の色を混ぜ、棚は半分の強さ。`craggrass=0`で追加の混色を切る |
| 旗・品質・予算 | 実装。`cragdip=0`でL1・L2を含む形状を戻す。`craglook=0`でL3・L4を切る。描画1回・属性4種類・適応4段階・三角形上限を維持 |

- 凹んだ輪郭を単純な重心の扇形で埋めると、隣の塊にはみ出す。全辺が見える内側の領域に折れの点を置く。ほぼ一直線の方向で面をまとめると端が深く下がるため、端の高さ変化が最小になる分け方を選ぶ。
- 軽量は面取りが無いため、頂の縁と共有する壁の縁の間を閉じる面を足した。追加中点の出入りも頂の接合部で0へ戻し、棚の面を中点で分けて閉じる。
- 地面の色と頂の高さを渡すため、`cragBed`を1成分から4成分へ拡張した。色はRGB各8bitでまとめ、属性の種類は増やさない。草色の丸め誤差は各色1/255以内。
- 既存23試験は残した。「全頂点が同じ層の面」の期待値だけを、基準高の刻みと折れた各点の高さの検査へ変更した。属性の成分数も更新し、継ぎ目・法線・予算の検査は維持した。

## 実際の Chrome で見て直したこと

はじめの版で見て直したこと：

- **最初は、色だけの平らな面だった。** 近くでは、淡い色の板を積んだコンクリートの壁に見えた。岩肌の模様と起伏を足した。
- **岩肌を足した直後は、石垣に見えた。** 同じ厚さの層に、等間隔の縦の割れ目が並んだためである。層の厚さを高さで変え、溝を所々で途切れさせ、割れ目の 6 割を間引いて傾けた。
- **色が明るい薄紫だった。** 夕暮れの青い光の下で、樹脂のように見えた。岩の明るさを、元の崖の色の 0.56 倍にし、半分を暖かい灰色へ寄せた。
- **壁の裾に、地形の三角形がのこぎりの歯のように出た。** 高さの表の崖が、升目に対して斜めに走るためで、この層を入れる前からあった。範囲の道の側の縁を、道の中心から 1.75m → 1.45m へ寄せると、岩の壁が歯を隠した。
- 面取り（0.12 → 0.2）と層の出入り（最大 0.10 → 0.20m）を強めた。見渡しで、塊の縁と段が読める。

絵と並べた講評のあとで、形を直した版（傾いた地層など）で見たこと：

- 講評では、「四角い板を水平に積んだ石積みか塔。上面は敷石のように平ら。近くでは、横線の入った巨大な平らな板」と言われた。
- 直したあと：見渡しでは、頂の高さがばらつき、外周が段々に下がるので、箱の輪郭が消えた。歩く視点では、壁が内へ倒れ、層が斜めに走る。
- 残った点：細い塊が、薄い板のように 1 枚だけ高く立つ所がある。面は平らなままで、近くでは切り出した石に近い。

3 周目の講評（「レンガの線が入った四角い柱を積んだ塔」）のあとで、頂と壁を折った版で見たこと：

- 頂の起伏を、層の 0.4〜1.1 倍にした最初の値では、どの塊も四角錐にとがり、水晶の群れに見えた。0.12〜0.5 倍に下げると、割れた岩の頭に見える。
- 見渡し（95m 先）では、細かい層の線が消え、右の塊に暗い縦の割れ目が 1 本通る。歩く視点では、明暗の帯と、折れた壁の面が読める。
- 残った点：全体の輪郭は、まだ塔に近い。斜面に埋まった崖には見えない。

## 実Chromeで確かめる手順

1. 岩の範囲がある設計した世界で`/valley/index.html?world=kamakura&debug=1&fly=1&cam=overlook&time=dusk`を開く。同じ画角の95m先と望遠で、頂が平らな台に見えず、細かい格子が消え、大きな縦割れと草色が読めるか撮影する。
2. `&cragdip=0`で形、`&craglook=0`で岩肌、`&craggrass=0`で草色だけを順に切って比較する。`&crag=0`で層全体が消えることも確認する。
3. 歩く視点で2〜10mへ寄り、壁の折れ・棚・割れ目の途切れ・地形の露出と継ぎ目を見る。軽量と適応段階0〜3でも往復する。
4. `&cragdebug=1`は岩の頂＝水色、従来の土の頂＝緑、面取り＝黄、壁と棚＝桃。草色の混合は単色表示では切れる。`__kzCrag()`の`folded`・`bent`と描画量・最近傍の距離と方位を読む。

## 見た目を詰める定数

いずれも`kamakura-crag.js`先頭の凍結した定数。値を変えたら個別試験と同じ画角の撮影を行う。

| 名前 | 今の値 | 上げると |
|---|---|---|
| `CRAG.foldFacesMin / foldFacesMax` | 3 / 4面 | 頂の折れる面が増える |
| `foldLowRate / foldShift` | .3 / 幅の.3 | 低い頂／内点のずれが増す |
| `foldMin / foldMax` | .12 / .5層 | 頂の起伏が強くなる（.4 / 1.1 では、水晶のようにとがった） |
| `bendLength / bendMin / bendMax` | 2.2 / .12 / .35m | 対象の辺が減る／壁の折れが深くなる |
| `CRAG_LOOK.fineFrom / fineTo` | .012 / .05m毎画素 | 細線が遠くまで残る |
| `jointKeep / jointSlant` | .8 / 25度 | 細かな割れ目が減る／傾く |
| `broadBand / broadTone` | 2.7m / .09 | 大きな帯が厚く／明暗差が強くなる |
| `crackSpacing / crackJitter / crackDark` | 8m / .3m / .35 | 大割れが疎になる／間隔が乱れる／暗くなる |
| `crackWidthMin / crackWidthMax` | .25 / .6m | 大割れが太くなる |
| `crackSwayMin / crackSwayMax / crackWave` | .3 / 1.2 / 7m | 揺れ幅／揺れの長さが増す |
| `crackPeriod / crackGap / crackDirection` | 9m / .3 / .37 | 途切れの周期／途切れる割合／平面上の向きが変わる |
| `weatherHeight / weatherGain` | 1.5m / .08 | 明るい風化部分が広がる／明るくなる |
| `grassStrength / grassSize` | .8 / 2m | 草色が強くなる／むらが大きくなる |
| `grassFrom / grassTo / grassNormal / shelfGrass` | .35 / .65 / .87 / .5 | 草色が減る／緩い面だけに出る／棚の草色が強くなる |

## 残る制約

GPU の描画回数と FPS は測っていない。割れ目の式は一致するが、GPUの浮動小数の丸めまでCPUと同一とは保証しない。地形の安全補正で一部の頂は高くなる。草色は面への混色で、草や低木の模型は増やしていない。
