# 里の物と働く人の検証（W2c-23e・2026-11-14）

見渡し（`&cam=concept`）から読める「かまどの煙」と「働く人」を、見た目だけの層として足した。座標・当たり・任務は変えていない。`&yard=0` で消える。

## 要求と判断

| 要求（WW18.4） | 結果 |
|---|---|
| かまどの煙が上がる | 実装。炉（hearth）と茅葺きの家の棟から、高さ約 14m の細い柱。頂点シェーダーだけで立ち上がる |
| 働く人が、見渡す構図からも数えられる | 実装。棚田・脱穀の平場・干し場・薪・道に影絵を最大 12 人。遠景では実物の約 1.55 倍 |
| 茅葺きの家のまわりの垣・干し場・井戸・薪・俵 | 既存の `WORLD.props` / `life` を維持。今回は見渡しの欠け（煙・人）だけを足した |
| 切り戻し | `&yard=0`。`main` 配線と更新は残るが、メッシュは置かない |
