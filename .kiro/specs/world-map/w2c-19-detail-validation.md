# W2c-19g 作り込み（detail）：段のある石段・沖の側だけに立つ波：検証記録

2 つ足した。1 つは、段と耳石のある石段の模型を、形のまま置いて上り下りできる仕組み。もう 1 つは、白波を、沖に向いた岸だけに立たせる仕組み。どちらも地図のデータで指定する。指定の無い世界（実寸の鎌倉）は、今までと同じ画になる。

- 旗：`&steps=0`（石段を今までどおり地面に沿わせる）・`&swell=0`（波の向きを見ない）。
- 確認用：`?debug=1` の `__kzStairs()`（今いる石段・歩く高さ・地形の高さ）と `__kzSea3()`（波の向きで弱めた水面の割合）。`&sea3debug=1` では、弱めた所が橙になる。
- 調整する定数は、`kamakura-stairs.js` の `STAIRS` と、`kamakura-shore.js` の `SWELL`。

## なぜ必要か

- **石段が、筋の入った敷物に見えた**。歩く面の施設（石段・参道・台）は、頂点を「地面から 12cm まで」に押さえている。主人公は地形の上を歩くので、盛り上がった模型に足が埋まらないようにするためだ。その結果、高さ 7.5m の石段も押しつぶされて、段が出なかった。
- **丸い堤のまわりに、白波の輪が何重にも巻いた**。白波の筋は、岸からの距離だけで出る。沖から来る波が砕けるのは、沖に向いた側のはず。ところが、堤の陸の側にも同じ筋が出ていた。

## 作り

- **石段**。施設の石段に、任意の項目 `steps`（下の端と上の端の中心・高さの差・幅）を足した。これのある石段は、押しつぶさずに、堂と同じ置き方で置く。歩く高さは、その四角の中だけ、段の鼻先を結ぶ坂にする（橋の床と同じやり方で、歩く地形に重ねる）。勾配も、その坂に合わせる。
- **坂の基準は、模型を置いた高さ**。基準点の地形の高さに `rel_anchor` を足した値で、模型の置き方と同じ。任意の `base_m` は、模型の中での、いちばん下の鼻先の高さ。任意の `landing_m` は、上の端の先の踊り場の長さで、そのあいだは最後の鼻先の高さのまま平らに歩く。
- **波の向き**。任意の `meta.sea = { swell_from_deg }`（波が来る方位）。岸からの距離の場を作るとき、升ごとに、岸の外向きと波が来る向きの内積を取る。その値で、白波の強さを弱める。沖に向いた岸はそのまま、横向きは半分ほど、風下は 0。水際の薄い泡と浅瀬の色は、変えない。

## 判断と、捨てた案

- **坂の基準を、下の端の地形の高さにはしない**。最初はそうしていた。段の下の地面は、踏み面より下へ逃がしてある。その低い地面から測ったので、坂が 23cm 沈み、主人公は段の中を歩いた。模型と同じ基準にすれば、段の下をどう掘っても、坂は動かない。
- **石段を、ぶつかる物にはしない**。段ごとの箱を足すと、歩く経路を塞ぐ。橋の床と同じに、歩く高さを重ねる形にした。水と、歩ける範囲の決まりは、元の地形のまま。
- **歩く高さは坂で、踏み面ごとの段ではない**。足は、踏み面から最大で蹴上げの半分ほど浮くか沈む。主人公の動きがなめらかなほうを採った。
- **波の向きは、「外海に開いているか」の値に掛けた**。海を描くときの読み取りと、描画の段は増えない。
- **施設を検査する道具も、同じ決まりに合わせた**（`tools/lib/kamakura-facility-validation.mjs`）。`steps` のある石段は、形のまま置かれていることを確かめる。直さないと、石段のある世界が、この検査で落ちた。

## 実 Chrome で確かめたこと（夕方前・設計中の地図）

| 見た所 | 結果 |
|---|---|
| 石段を下から・横から | 段の影が並ぶ。横からは、階段の形の輪郭になる。切る（`steps=0`）と、筋の入った平らな面に戻る |
| 石段の足元 | 手前の平らな所から、くぼみなく 1 段目へ続く |
| 石段の途中に立つ | 主人公が段の上に立つ。歩く高さは、鼻先の線の 5cm 下（地形は、その 18cm 下） |
| 石段の上の端 | 踊り場を平らに歩き、上の段へ 5cm の差でつながる |
| 石段の横の土手から | 階段の形の側面と耳石が見える。横へ出入りできる |
| 港を高さ 60m から | 堤の陸の側の輪が消え、白波は沖の側だけになった。切る（`swell=0`）と、輪が戻る |
| 見渡す構図 | 浜には筋が立ち、港の陸の側は静か |
| 弱めた水面の割合 | 水面の 3.5% |
| コマ時間（石段の上・1280×720・上限なし） | あり 7.0〜7.1ms・切ると 6.6ms |
| コンソール | エラー 0 |

## 試験

- `tests/kamakura-stairs.test.mjs`：`steps` の読み方と断り方（石段以外・範囲の外・急すぎる勾配）・`steps` のある石段は頂点が変わらない・歩く高さが下の端で地形と同じ、上の端で高さの差に届く・四角の外は地形のまま・坂の基準が模型を置いた高さであること（下の端の地面が低くても沈まない）・踊り場が平らで、長さの先は地形へ戻ること・回した石段と重なる石段・実際の移動の関数で上り下りできる・`steps=0` で今までと同じ・施設を検査する道具が、形のまま置いた石段を受け入れる。
- `tests/kamakura-swell.test.mjs`：方位の読み方と断り方・南向きの浜の沖はそのまま、輪の陸の側は 0、東西はその間・値が 0〜1・決定的・指定の無い世界は場が今までと同じ・`swell=0` で同じ。
- 起動の順番の試験（距離の場が先に出て、そのあいだは全部の水面が「開いている」）は、波の向きを足した形でも通る。

## 残っていること

- 46 度より急な石段は、上れない（今ある上りの制限のため）。データの検査は、勾配 1.2（約 50 度）まで通す。
- 岸からの距離の細かい場ができるまでは、波の向きは効かない。設計中の地図では、開いて数秒。
- 石段の両脇は、砂利の斜面のまま。石垣や植え込みは、地形のデータで作る。
- 朝・昼・夕方の色と、軽量の品質は、まだ見ていない。
