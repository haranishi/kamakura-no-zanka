# 退路と場面の書き出し：検証記録

同じ設計図から、2 つの場面（帰還・序幕）を書き出せる。北西の退路は、集落・切通し・谷戸と草地・物見の岩・峠の口を通る山道に作り直した。序幕の見渡しカメラから、町の屋根の点 99 のうち 97、海の 4 点、火元 5 つへ線が通る。往復 8 経路を歩ける。道具の試験は、模型あり・なしとも失敗 0。ゲーム側は変えていない。

実 Chrome での確認手順：
1. `KZ_WORLD_DIR=.world-out/kamakura-escape node tools/serve.mjs`を実行し、`http://127.0.0.1:8080/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1`を開く。既定のdusk・日の円盤・町と海の帯・岩壁・草地の木・枠を確認する。
2. `&worksdebug=1`：岩=桃、柵=水色、床=黄、支柱=橙。`__kzWorks()`で数を確認。`&firedebug=1`：炎=赤、煙=紫、照り=黄。`__kzFire()`で火元5点を確認する。
3. `&flightdebug=1`は避難する人=橙。`__kzFlight()`を確認する。`&works=0`・`&fire=0`・`&flight=0`、軽量品質と適応段階でも見比べる。
4. 飛行を外して岩→集落→町、岩→峠、枝→寺を往復する。returnでも同じ見渡しURLを開き、南の海からの構図を確認する。

## 実 Chrome で見た結果（2026-11-11 深夜・夕暮れと夕方前）

序幕の見渡しカメラで、手前に草地と小屋・柵のある道と人の組、左の中ほどに岩の門と集落、中央に燃える町と黒い煙、上に海と夕日が写る。出発点から集落まで、歩く視点で下りられる。コンソールのエラーは 0。

まだの所：切通しの岩は、なめらかな円錐に近く、絵の切り立った岩壁には届かない。右手前の斜面が空いている。町は、絵より近く大きく写る（要件のとおり、距離は合わせていない）。
