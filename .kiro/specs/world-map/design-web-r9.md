# R9 設計メモ：草の生え方・種類・足音（W2c-15・2026-11-09）

要件は `requirements-web-polish.md` の WW12。検証の数字は `w2c-15-{stream,variety,sound}-validation.md`。

## 草の生え方（`&grass9=0` で戻る）
- **半径30mは世界に固定する**：距離で変わる密度・高さ・幅をやめ、世界座標の乱数（`grass9Retain`）で刃の23%を固定。30〜45mでなだらかに中景へつなぐ（`grass9Blend`）。近づいて生えて見える原因は、刃の出し入れを距離の帯で決めていたこと。
- **LODは2段**：根が12m未満は12三角形、外は4三角形。同じ根のバッファを2つのメッシュで共有し、根・丈・幅・顔料はバイト一致。
- **先読み**：進行方向へ「速度×3秒+10m（最大60m）」の帯も区画に入れる。構築の時間枠は、40m以内が6ms・外が2ms（区画の間で判定する協調予算）。
- **区画で計画する**：近景は6m・中景は12mの区画を矩形の距離で選び、再計画（1m動くたび）を34msから4msにした。読み込み済み約33万本の再コピーは、位置で結果が変わる区画（12mの詳細円と、半径+13〜+16mの輪）だけ。旧（タイル単位）と同じ区画を選ぶことと、飛ばした結果が全部やり直した結果と一致することを試験で固定している。
- **捨てた案**：①1mのタイル約3万個で選ぶ（1回34ms）。②細い刃（0.9px未満）を捨てる処理は、外したままでは中景の細い刃が逆光の夕景で白い点として散り、動くとちらつく。戻すと今度は中景が疎らに見え、盲検講評で旧より低く評価された。**細い刃は残し、表示の明るさに上限（0.32）を付けて**白い点だけを消した（直射の光を弱める案は効きが弱かった）。

## 草の種類（`&grass10=0`）
- 短い草・普通・長い草（0.1〜1.0m）を、群落（2〜8mの斑）で混ぜる。花（4色）は全体の約2%。ススキ・シダ・穂・たんぽぽ・クローバーは、独立した乱数でまばらに（刃の並びで決めると斜めの帯に並び、画面を覆う株ができた）。
- 本人の言う「杉」は、ススキの聞き違いと解釈した。杉の若木は未対応。
- 花の茎は、0.9pxより細いと捨てられて頭だけ浮く。距離とともに茎を太くした（12mまで見える）。

## 足音（`&steps9=0`）
- 川は、低い「ぼちゃ」・しぶき・しずく（2〜4個）の合成。足元の草の重みで、草（さらさら）と土（鈍い音）を連続的に混ぜる。歩きと走りで強さと長さが変わる。`?debug=1` に足元と直近の種類を出す。聞こえ方は本人の試聴で決める。

## 未解決（次の周回・盲検講評3回目で新しい版は6組中6組で上、残る欠点）
- 中距離から先で草が薄くなり、遠い地面が平らに見える。遠い地面に草の縞・揺らぎを描き、草が減る距離で地面の色を草の平均色へ寄せる。
- 花・穂の形と大きさがそろい、同じ密度で散る（白は紙片のよう）。大きな周期のノイズで群生する区画と無い区画を分け、白の彩度と明度を下げる。
- カメラ直前で、背の高い長い草（最大 1.0m）の淡い穂先が、画面の下端で大きな葉のように見える。シダ・ヨモギの縮小やカメラ近くでの縮小では変わらなかったので、長い草の最大の高さか穂先の色で調整する。
- **足音が川の環境音に埋もれる**（本人の試聴・最優先）。足音の音量を上げ、川の近くでは足音の間だけ環境音を下げる。聞き分けの試聴はそのあと。
- 歩行時の p95（区画構築の枠のぶん）と、足元の草の濃さ（旧より疎ら）。
