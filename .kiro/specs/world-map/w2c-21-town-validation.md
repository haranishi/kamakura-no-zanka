# 町並みの配置改善：検証記録

設定のない町の家一覧を維持し、地図ごとに家の向き・まとまり・町の縁・裏庭を調整できるようにした。
指定された控えに試験値をメモリ上で適用すると、家は111軒から108軒（97.3%）になった。
新たな家の重なり、孤立した追加区画、移動後に戻れなくなる場所は0件。実Chromeの見た目は未確認。

## 要件と判断

| 要件 | 結果 |
|---|---|
| T1 地図ごとの設定 | 実装。10項目の範囲と下がり幅の大小関係を検査。設定なしの合成町は変更前の全10軒・全行列成分と一致 |
| T2 まとまり | 実装。3〜6区画で向きと下がりを共有。全軒の場所を確保してから共通の回転を試すので、回転だけで隣の家が消えない |
| T3 でこぼこの縁 | 実装。40m・90mの波で外側を削る。中心と大通りは残し、孤立区画を先に除く |
| T4 家の裏 | 実装。物置の割合を指定できる。物置のない区画に庭木の印を返し、全配置後に間隔を検査 |
| 庭木の描画 | 対象外。印の描画・読み込み側への受け渡しは別の作業 |
| 実Chrome・前後画像 | 未実施。サーバーの待受が禁止されており、後述の手順で別環境で確かめる |

向きが大きい家は、角度・横ずれ・下がりを半分ずつ戻して試す。入らなければ同じ種類の小さい模型を1回だけ試す。
区画の全体が障害物に掛かる場合も、家本体と通れる外周が安全なら使う。庭や焼け跡は全体の場所を確保する。
町の屋根を減らしすぎないよう、縁で捨てる家は追加家数の3%×指定率までとした。区画全体は12%×指定率が上限。
すべて起動時だけの計算。家数・路地長・遠景三角形の既存上限を維持し、描画の品質調整は既存のものを使う。

## 指定された控えでの集計

試験値：`yaw:9, groupYaw:8, shift:1.4, setbackMin:1, setbackMax:4.5, bend:3, bendWave:70, annexRate:.55, edgeFray:.8, yardRate:.6`。
元のファイルは変更せず、`meta.town_fill` をメモリ上で合成した。以下は設計した地形・模型の数字。

| 指標 | 変更前 | 試験値 |
|---|---:|---:|
| 家の総数（追加数） | 111（72） | 108（69） |
| 向きの標準偏差 | 13.99度 | 16.02度 |
| 縁の距離の標準偏差 | 17.21m | 28.94m |
| 物置 | 5 | 5 |
| 庭木の印 | 0 | 7 |
| 捨てた区画 | 0 | 3 / 69（4.35%） |
| 大通り沿いの追加家区画 | 17 | 19 |
| 遠景の予算計算 | 1,724三角形 | 1,676三角形 |

向きは90度ごとの道への向きを折り返して計算した。縁は南北12mの帯ごと・左右別に最も外の家区画を選ぶ。
標準偏差は輪郭や向きの違いを比べる指標で、美しさの採点ではない。物置は割合を上げても空きがなければ増えない。
描画命令の追加は0。家は既存の遠景1命令に入る設計で、GPUでの命令数・FPSは未計測。
探索：候補133・地面8,198・箱14,631・道8,469・回転試行1,020・縁の近隣890・庭の候補19。
路地118区間。移動は5m格子3,290点を実際の移動関数で検査し、到達2,751点・新たな帰還不能0点だった。
既存の模型同士の箱の交差は据え置き、新しい家と既存の家・新しい家同士の交差を検査した。

## 実Chromeで確かめる手順

1. 配信側の確認用`meta.town_fill`に上の試験値を適用する。本作業ではデータを変更していない。
2. `/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1&townfilldebug=1`を開く。同じ画角で、設定なしと比較撮影する。
3. 数軒の向きがそろい、境で向きが変わること、町の縁が欠け、屋根の量が保たれることを見る。
4. `&housefardebug=1`は遠景の家が桃色、塀・門が黄色。`&towndressdebug=1`は柵が水色。`townfilldebug`自体は数値だけ。
5. `__kzTownFill()`の`edge`・`yards`・`annexes`・`work`を確認。`__kzHouseFar()`と`__kzTownDress()`で描画量も確認する。
6. 路地を歩き、傾いた家に柵が刺さらず、戸口へ入り戻れることを確かめる。`&q=light`でも見直す。
7. `&townfill=0`で追加の町を切れる。`&towndress=0`で柵を切れる。庭木の印はこの変更だけでは画面に出ない。
