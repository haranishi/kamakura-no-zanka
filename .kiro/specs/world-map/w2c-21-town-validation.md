# 町の道沿いとすき間：検証記録

道沿いの空白を埋め、指定の控えで家数・屋根面積率・東西道沿いの目安を満たした。
追加の設定がない町は、家の種類・順序・全行列成分を維持する。実Chromeでの見た目は未確認。

## 要求と設計の判断

| 要求 | 結果 |
|---|---|
| X1 道沿いの区画 | 実装。大通り以外の3種類の道が対象。つながった同一路線の断片は、並びの間隔を共有する |
| X2 すき間の小家 | 実装。道・路地に戸口を向け、前から置いた家と庭などの占有を優先。小家が入らない細い空きは残す |
| 設定なしの互換 | 実装。2項目の既定は0。旧家一覧の全成分照合と、明示的な0・設定省略の一致を検査 |
| 先の配置と大通りの維持 | 実装。従来の配置・まとまりの回転・縁の判断を終えてから追加。先にあった全家の行列は一致 |
| 通行・間隔・橋 | 検査済み。戸口への直線、家の間隔、道との交差、川、施設、橋の前後8mの除外を合成町で検査 |
| 起動時の上限・品質 | 実装。家数と遠景三角形の既存上限を共用。路地長と追加走査の合計は60,000m以下、軸探索は12,000回以下 |
| 実Chromeと前後画像 | 未実施。この環境ではサーバー待受が禁止されるため、下記手順を残す |

広い区画の全体を要求すると、道を横切る区画の端だけで家を断ってしまう。
前回と同様、家本体と通れる外周が入るかで判断し、奥行きが足りない道沿いでは12mの小家を試す。
すき間では6mの間口、次に12mの間口で小家を試す。2m刻みでずらし、先に置いた家の場所は再利用しない。
外周を膨らませた家にもう一度余白を足すと、使えるすき間が必要以上に狭くなるため、追加分は安全距離の二重加算を除いた。
既存配置の検査幅は変えていない。追加分も家間1.2m、既存家から1.5m、施設から6mを守る。
道沿いの追加は先に置いた家を動かさないので、前回確認された向きのまとまりを維持する。

## 設計した控えでの比較

控えは`world-return-0`。元データを変更せず、読み込んだ`meta.town_fill`へメモリ上で試験値を重ねた。

変更後だけ`roadPlots:1, infillRate:.8`を加える。以下はすべて自作の設計データの測定値。
この控えは元の家が42軒あり、前回の記録に使った39軒の控えとは違うため、変更前は108軒ではなく111軒になる。

屋根率は町の幅300m・大通りの全長206mの同じ61,800m²を、1m格子の中心で測った。
家の回転した箱の内側を屋根とし、重なる箇所は1回だけ数えた。屋根の庇・施設の屋根・見た目の採点は含まない。
沿道数は両路線の全断片から道幅の半分＋15m以内に中心がある家の合計で、同じ家は1回だけ数える。
描画命令は新設0、既存の遠景1命令へ入る設計。GPUの実測値・FPSは未確認。
追加走査：候補1,168、地面13,402、箱87,232、道16,689、回転9,384回。追加の走査8,940.49m・2,962候補、軸探索2,432回。
追加の2,962候補のうち56軒を配置。断った2,906候補：範囲外1,397・率536・既存の占有621・施設72・道68・水104・斜面3・橋105。模型不足・寸法不一致・上限・探索予算は各0。各候補は最後に断った理由で1回だけ数え、回転を試した回数とは区別した。
移動は5m格子3,290点を実際の移動関数で検査し、到達2,651点・新たな帰還不能0点。
元の模型同士の交差は据え置き、新しい家同士・元の家との交差を検査した。

## 実Chromeでの確認と調整

1. 配信側の確認用データに上記設定を適用し、2項目が0の版も用意する。データは本作業では変更していない。
2. `/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1&townfilldebug=1&housefardebug=1`を両版で開き、同じ画角で前後を撮る。
3. 遠景の家は桃色、塀・門は黄色。東西道の両側に家が増え、屋根の量が増えていることを見る。`townfilldebug`自体は数値表示用。
4. `__kzTownFill().supplemental`で追加数・除外理由を確認。`__kzHouseFar()`で遠景の数・三角形・命令数を確認する。
5. `&towndressdebug=1`の柵は水色。東西道・橋の前後・路地を歩き、戸口へ入り戻れることと、柵が家や道に刺さらないことを確認。
6. `&q=light`と適応品質0〜3でも確認。`&townfill=0`で追加の町全体を切れる。2項目を0にすると今回の追加だけ切れる。

| 定数・設定 | 既定 → 今回の値 | 上げたときの効果 |
|---|---|---|
| roadPlots / infillRate | 0 / 0 → 1 / .8 | 道沿いを有効化 / すき間候補の採用率が増える |
| compactDepth | 12m | 奥行きのある小家を選べる。実際に入らなければ置かない |
| infillWidth / infillWidthMax | 6 / 12m | 最初 / 次に試す間口が広くなる |
| infillDepth | 7m | 橋のたもとを横方向に広く空ける。すき間の最小奥行きの基準も兼ねる |
| infillStep | 2m | 探索が粗くなり、試行数とすき間の家が減る |
| bridgeGap | 8m | 橋の前後に空ける範囲が広くなる |
