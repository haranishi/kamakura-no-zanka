# W2c-8 飛行カメラの実装引き渡し

BRIEF-W2C8-FLY.md の確定済み設計を引き継ぎ、鎌倉専用の飛行と全体図を実装した。
実装・Node検証までが今回の担当。ブラウザ・画像・性能の受け入れは親が実機で行う。
既存の未コミット変更を保持し、commit・push・他worktreeへの書き込みは行っていない。

## 目的と設計

本人がマップ全体を見渡し、調べたい地点へ降りて歩けるようにする。
飛行・全体図・降下の計算は純粋な層に置き、入力と描画の配線を鎌倉側でまとめた。
谷・庭・保存の経路は変更せず、worldなしではfly指定があっても元の入口へ進む。

- Fは主人公をその場に残したまま飛行へ移り、再度Fで元の歩きへ戻る。
- fly=1は出発点の地面から900m上、北東向き・35°下向きで始める。
- Mは北を上にした全体図と元の飛行位置を往復する。fly=topでも開始できる。
  全体図は固定視点で、移動・視点入力を止める。Mで通常の飛行操作へ戻る。
- Gはカメラ直下の歩ける点へ降りる。pointDepartureの探索半径だけ80mに広げて再利用する。
  従来のpos指定の半径40mは維持する。失敗時は位置を変えず2.2秒案内を出す。
- 全体図は高さ7,500mを維持し、地形の高さと画面比率から画角を広げる。
  固定58°では縦画面に全域が収まらないための補完で、通常の飛行・歩きは58°へ戻す。
- 飛行中は主人公の表示・歩行更新を止める。区画・家・大気の追従先はカメラ位置へ切り替える。
  木・林分は既存のcamera引数、川は既存のcameraPositionを使うシェーダーで追従する。
- 地形LODは飛行時に高さも距離へ加える。全体図ではLOD8、低空の近景は詳細を保つ。
  歩きへ戻すと表示距離・遠端・地形の生成予算を復元する。
- 入力はAbortSignalで解除する。飛行の切り替えと休止で押下・ホイールの残りを消す。
  自動品質3段階と自動解像度は既存の更新経路を使う。

## 数値

| 項目 | 値 |
|---|---|
| 基本速度 | 80m/秒、ホイールで×1.25／×0.8、5〜2,000m/秒 |
| 加速 | Shift／タッチの加速で×5 |
| ピッチ | 通常飛行±89°、全体図は真下90° |
| 高さ | 地形＋2m以上、上限12,000m、全体図7,500m |
| 地形の表示距離 | 飛行14,000m、歩き3,300m |
| 地形の生成 | 飛行最大8枚/コマ、歩きは既存の標準3ms／軽量2ms予算 |
| カメラ遠端 | 飛行30,000m、歩きは既存の10,000m／7,000m |

8枚は縫合のための隣接区画の再生成も含む。新しく表示される枚数とは一致しない。
川・家・木・林分の描画距離は既存値を維持する。地形の14kmとは別の制限である。

## 親の実機確認と残件

私有データを指定して既存のサーバーを起動し、次のURLを開く。
http://127.0.0.1:8095/valley/index.html?world=kamakura&debug=1

1. &fly=1で開始。WASD、Q/E・C/Space、Shift、ホイール、R、矢印・IJKL、マウスを確認。
2. Fで往復し、主人公が動いていないこと、表示と通常の視点が戻ることを確認。
3. Mを押し、全域の読み込み、北向き、遠景の山と海、川の筋、七切通の位置を確認。
   &fly=topで直接開始し、縦横の画面変更でも全域が収まることを見る。
4. Mで元の飛行位置へ戻り、Gで降りて歩く。海・範囲外では失敗案内を見る。
5. P・Esc・休止ボタン、タッチの左右ドラッグ・上昇・下降・加速を確認。
   q=light、段階の自動変化、飛行往復後のメモリ、worldなしの谷と庭も確認する。

未確認：実ブラウザ、GPU、固定画角の前後撮影、性能、実機の指操作と長時間メモリ。
見た目の不具合は未判定。川などの遠距離制限と霞は既存のまま。
設計への補完は全体図の画角調整と、高さを含めた地形LODの選択。
