# W2c-18i 浜と港：小舟・網を干す枠・沖の帆の舟

浜舟・網枠・沖の帆舟・港の配置と、遠景への引継ぎを実装した。ブラウザは動かしていない。
合成世界では浜舟72艘・枠25基・帆舟2艘・港舟6艘、桟橋と小屋が成立する。
主描画は最大6命令、方向光の影を含めても最大9命令。実機の見え方は、下の「実 Chrome で確かめたこと」。

## 要求と判断

|要求|結果|
|---|---|
|B1 浜舟|実装。3〜6艘の組、町寄りを密にし、地面・箱・道・河口・既存舟・舟同士を避ける。地面に縦の傾きを合わせ、横に4〜10度傾ける|
|B1 当たり判定|見送り。既存の小物舟も衝突を追加しておらず、同じ舟用の追加・撤去の口が無い|
|B2 網枠|実装。組の陸側、丸太4本と横木2段、透過を使わない粗い網面|
|B3 帆舟|実装。航路全体を陸までの距離で検査。300mの往復、最高0.6m/秒、端で滑らかに反転、波による上下・縦揺れ・横揺れ|
|B4 港|実装。堤の箱内の水面から8方向へ岸を探し、6方向以上が囲まれる所を使う。舟・係留索・桟橋・小屋・荷を生成|
|B4 代替|4艘を安全に収められない水面も「使える内港なし」と扱う。港舟を岸へ引き上げ、桟橋・小屋は作らない。私有データではこの経路になった|
|B5 遠景|実装。カメラの3次元距離、品質別距離・組の間引き、40mの帯で形を引き継ぐ。遠景は頂点で幅を1.5画素以上にし、枠の高さも補う|
|B6 口|実装。旗、単色の種類分け、数・三角形・命令・最近点の距離と方位、見送り理由、解放時の削除|

要件はWW15.5・15.9〜15.13と依頼書B1〜B6を継承した。変更は指定の8ファイルのみ。
配置→形状→層の順に分け、合成世界→層とGLSL→私有データ→全試験の順で確認した。
海の基準面は高さ0で、現行の海には頂点の上下移動がない。舟の揺れは指定された振幅の独自の周期式にした。
既存の`seaDistanceAt`は海では0を返す。沖では別に陸までの距離場を作り、補間誤差と船体の長さも余裕に含めた。
既存舟は、小物の配置器を時刻・`props`の指定まで合わせて再実行して避ける。

## 実行結果

`NODE_OPTIONS=--max-old-space-size=1536 timeout 600 npm test`：1,690成功・0失敗・43スキップ。
`KZ_WORLD_DIR=… NODE_OPTIONS=--max-old-space-size=1536 timeout 600 npm test`：再実行で1,733成功・0失敗・0スキップ。
私有指定の初回は1,732成功・1失敗。変更外の`valley-lunge`の若い世代の確保量の測定で落ち、試験を変えずに再実行すると通った。
`npm run check`成功（126モジュール、586構文検査）。最後の`npm run smoke`は`listen EPERM`で失敗。文章lintは依存不足で実行できず、手動で点検した。
開始前は`npm test`が1,676成功・0失敗・42スキップ、`npm run check`成功。
開始前の`npm run smoke`は`listen EPERM`で失敗した。サーバー待受の制約であり、画面の成否を示す結果ではない。

## Nodeで確認した費用

合成世界は15組、配置の走査9,443点、準備の区切り192回、航路の検査62点。
同じ世界・同じ指定で配置が一致する。1,000フレームの行列更新は8,000回、1フレーム8回以下。
合成世界の送信形状は近景21,428三角形・遠景1,296三角形。高空では遠景のみ3命令。私有データの集計は近景19,560・遠景1,142三角形で上限内。
全上限まで配置した場合も近景28,604・遠景1,692三角形以内。影の再描画はこの三角形数には含めない。
舟の共用形状は近224・遠14三角形。遠景の船体は12で、残る2三角形は帆用（小舟では頂点を畳む）。
帆舟と小舟を同じインスタンスへまとめることで、影を含む命令数も10以下に抑えた。
GLSLは同梱ThreeのLambert・Basic・Depthで差込み口、括弧、予約語、未宣言名、数値の連結、整数の混在を検査した。
これはGPUでのコンパイル成功を保証しない。描画数もNode上の送信見積もりであり、実測FPSではない。

## 実 Chrome で確かめたこと（2026-11-11）

浜の舟 69 艘・網を干す枠 23 基・帆の舟 2 艘が出る。コンソールのエラーは 0 件。
見渡す構図では、浜の舟は小さな点で、数は読めるが形は読めない。
港（石積みの島）は、囲まれた水面が見つからず、舟を岸へ引き上げただけになった。絵にある「丸く積んだ石の堤の港」は、別の作業で作る。

## 狭い浜にも舟を置く（2026-11-11 に足した）

設計した鎌倉の浜は、奥行きが 16m しか無い。舟の組は海から 22m の線に置く決まりなので、町の前の浜には、置ける砂が 1 か所も無かった。空だった。そこで、いつもの線に置けず、近くに組も無い所だけ、海から 13m、だめなら 9m の線で置き直す。広い浜の舟は動かない。先に、今までどおりの線で全部を試すからだ。実 Chrome（設計中の地図）では、浜の西の端に 4 艘の組が増えた。組どうしを 74m 離す決まりは変えていないので、浜の中央は空のままだ。
