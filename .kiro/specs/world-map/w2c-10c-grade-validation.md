# W2c-10c grade：暗部の引き算を弱める（トーンマップの toe）— 検証記録（2026-11-08）

## 原因（実測）
three.js の Neutral トーンマップは、最小の成分から `x−6.25x²`（最大 0.04）を全成分から引く。暗い色（影・草の葉の裏・濃い緑）ほど最小成分が削られ、**暗く・緑に・高彩度**になる。
- 地面の色を単色にして光だけを測ると、鶴岡（12）の影／日なたの比（線形）が R 0.085・G 0.17・B 0.137。光の理論値（0.24・0.32・0.43）より 2〜3 倍暗く、緑に偏る。
- 画面の HSV 彩度の平均が草の画で 0.83（写真の屋外は 0.3〜0.6）。「色がアニメっぽい」の主因のひとつ。
- 影だけを灰色にする後処理（暗い画素の彩度を落とす）は、暗い草・葉まで全部灰色にして不採用。緑だけの彩度を下げる後処理（色相 50〜170°）も 0.7 で鈍く不採用。

## 変更
- `kamakura-post.js`：`POST_DEFAULTS.toe=.6`、`neutralToneChunk(chunk,toe)`（バンドルの `NeutralToneMapping` の `color -= offset;` を `offset * toe` に。冪等・範囲 0〜1・行が無ければ例外）、`postOptions().toe`（`&ptoe=0〜1`・無指定は null）、`neutralGray` の鏡に `toe`。
- `kamakura-atmosphere.js`：時刻ごとの `postToe`（朝・昼 0.6／**夕方 1＝従来**）。
- `kamakura-post-view.js`：作成時にグローバルのチャンク `tonemapping_pars_fragment` を差し替え（最初の描画より前＝プログラムのコンパイル前）、dispose で戻す。**最終パスと、後処理なし経路（軽量・`&post=0`）の両方**が同じ式になる。
- 旧に戻す：`&ptoe=1`。
