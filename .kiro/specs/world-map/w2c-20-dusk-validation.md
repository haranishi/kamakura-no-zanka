# 夕暮れの場面の土台：検証記録

地図の既定時刻・夕暮れ・低い日の円盤・自由な見渡し・建っている大仏殿を実装した。見た目の合否はまだ判断していない。次は実 Chrome で固定画角を撮り、青い暗部と暖かい光の分離を確認する。

| 要求 | 結果 |
|---|---|
| D1 既定時刻 | 起動の最初に検索条件へ補い、下流が同じ時刻を読む。URL が優先。不明な地図時刻は読み込みで断る |
| D2 夕暮れ | 青紫の空と環境光。夕方の蛍・灯籠・煙色・鐘・階調を引き継ぐ。既存4時刻の値は保持 |
| D3 低い日 | 円盤・にじみ・画面のグレア・水面反射だけを別の方向へ置く。影の光は保持。0で消せる |
| D4 見渡し | 6項目の自由な位置と従来の形を受け付け、混在・欠落・範囲外は断る |
| D5 大仏殿 | 地図の hall を既存の旗へ渡す。URL で戻せる。合成模型で堂が残り骨組みが出ないことを確認 |

空の描画は共用の `atmosphere.js` にあるため、任意の材質生成関数だけを追加した。渡さなければ元の関数を使う。谷の空のシェーダーと一様変数は変更前と一致する。新しいモジュール・依存・素材・データ出力はない。

## 実 Chrome での確認手順

1. 序幕のデータを通常の方法で配信し、`/valley/index.html?world=kamakura&fly=1&cam=overlook&debug=1` を開く。URLに時刻がなくても「夕暮れ」と出ること。時刻ボタンを押し、朝へ進んで位置と向きが保たれること。
2. 同じ番地へ `&time=dusk&sundisc=1` を足す。青い森・読める岩と道・紫と桃色の雲・橙の水平線を見る。夕方前の場面も並べる。
3. `&sundisc=0.5` と `&sundisc=3` を同じ画角で撮る。円盤と海の光だけが上下し、家と木の影の向きは一致すること。`&sunturn=20` では影も円盤も横へ動くこと。
4. `&sundebug=1`：円盤＝黄、にじみ＝赤紫、海の光の道＝水色。`__kzSun()`・`__kzSunPath()` で数、三角形、描画、距離と方位を見る。空の距離は球の半径、海の距離は真下の面までの距離。
5. `&sundisc=0` で円盤・にじみ・グレア・きらめきが消えること。`&time=evening` でも確認する。`&time=golden` だけの従来の地図は前と同じ画になること。
6. 大仏に近づき堂が建ち、骨組みが無いこと。`&buddha=` で露座と骨組みに戻ること。標準と `&q=light`、`&autoscale=0&adaptstep=0`〜`3` を比べる。

## 実 Chrome で見て直したこと（2026-11-11 夜）

設計した鎌倉の北西の山から、日（方位 182 度・円盤の高さ 1.5 度）へ向かって町を見た。

- 序幕のカメラに写る空は、水平線から 4 度までしか無い。水平線の色を橙にすると、空の帯が全部、橙になった。水平線は、くすんだ薔薇色にした。橙は、日のにじみと、日の側の霞に任せる。
- 木の葉が、日を背にしても明るい黄緑のままだった。夕暮れだけ、葉の色を暗く青く寄せる補正（`foliage`）を掛けた。
- 日の円盤は、白く飛んでいた。明るさを下げ、にじみを広げた。
- 空からの光まで下げると、実寸の鎌倉の出発点で、足元の道が真っ黒になった。高さ 6 度の日は、平らな地面をほとんど照らさない。空からの光は夕方に近い強さへ戻し、暗くするのは木の葉だけにした。
- 設計した鎌倉の大通りと浜、実寸の鎌倉の出発点と見渡しで、人・家の明かり・火の照り返しが読める。
- コンソールのエラーは 0。

まだ見ていないこと：朝や昼への切り替えを一巡・軽量の品質・音・描く時間（GPU）。海の光の道の太さと、雲の形は、詰めていない。
