# 谷の霧を視線に沿って積む：機械検証と実画面の判定を分ける

2026-11-12。WW18.7〜18.9。面の点から量を決める近似をやめ、視線の途中の霧を積む。
霧の向こうの層外の物もかすむことを数値で確認した。配置と保護域は引き継いだ。
修正後に、実際の Chrome で撮り直した。雪に見える木は消え、霧は、森の斜面と北の谷あいに、やわらかいかたまりで見える。

## 実際の Chrome で見て直したこと

白い板・こぶ・水平の筋は消え、真上では白い斑と置き場所がよかった。一方、斜めでは雪に見えた。
層内の木と地面だけが白く、暗い背景に木の輪郭がくっきり出ていた。
原因は、面の位置の層だけで霧量を決め、視線の途中にある霧を読んでいなかったこと。
そのため層外の遠い斜面は白まず、層内の木だけを塗る結果になった。上限0.8も過剰だった。
今回は視線積算に替え、上限を0.62へ下げた。配置を変えて症状を隠す案は採らなかった。
自動3でも14点で継続する。停止すると、川・窪地の旧い帯を消したまま局所霧まで消えるため。
視線に沿って積む版を撮ると、北の谷あいの霧が、両側の斜面をはい上がる 2 本の白い筋（滝）に見えた。層を地形に沿わせていたため。
北の谷あいだけ、層の上の面を水平にした（川面から 42m）。濃さは、1m あたり 0.012 から 0.014 へ上げた。

## 実際のChromeで次に確かめる手順

1. `/valley/index.html?qa=1&autostart=new&intro=0&cam=concept&w=1280&h=720&q=standard`を開く。
   同時刻の`&mist3=0`と比較し、板と水平線が戻らず、斜面に6〜12個の柔らかい塊が読めるかを見る。
2. `&mist3debug=1`は黒=量0、灰=積んだ不透明度、最大0.62。霧の向こうの木と斜面の両方がかすむかを見る。
   高い空・尾根には掛からず、前景の木は暗い輪郭のまま残ること。空でも霧を横切る方向には量が出てよい。
3. `__valley.game.post.stats().mist3`でactive・reason・steps・heightBounds・読み取り上限を読む。
   `__valley.game.atmosphere.stats().mistBandKinds`は川0・窪地0・段間のみ。軽量はsteps=14。
4. 里を歩き、25m以内と里・棚田の中が白まず、森のすそと川の上下流にだけ薄く残るかを見る。
   真上では修正前と同じ柔らかい斑か、標準／軽量で縞・ざらつき・移動中のちらつきがないかも比較する。
5. `&lk=mist3:0.008,mist3t:0.85`で薄く、`&lk=mist3:0.016,mist3t:1.2`で濃く厚く試す。
   `tools/scenarios/capture-concept.mjs`で同条件の前後を残してから、下の定数を詰める。
