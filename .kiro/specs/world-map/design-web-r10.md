# R10 設計メモ：風・光・主人公・音・命（W2c-16・2026-11-10）

要件は `requirements-web-polish.md` の WW13。検証の数字は `w2c-16-*-validation.md` に書く。

## 誰の、どんな場面のためか

「私は鎌倉をただ歩いている。葉が風に流れ、草の波と同時に風の音が強まり、足音が地面ごとに変わり、遠くで鐘が鳴る。立ち止まると主人公が息をして、布が揺れる。だから、目的が無くても歩き続けたくなる」。

散策には、戦いも目的も無い。価値は「その場所に居る感じ」だけで決まる。R9 までは面を1つずつ磨いたが、止まった画の質感が上がっても、歩いている間の感じは変わりにくかった。

## UX の5階層から決めたこと

| 階層 | 決めたこと |
|---|---|
| 戦略 | 成功の物差しは、本人が歩いて「綺麗・気持ちいい」と言うこと、盲検の講評が +1.0 点、10 秒の録画に止まった物が無いこと。 |
| 要件 | 歩いている間じゅう目と耳に入るもの（風の粒・光・主人公・足音と環境音）を先に作る。特定の場所へ行かないと見えない小物は後にする。 |
| 構造 | 風と場所の性格は、それぞれ1つの出どころから全部の層が読む。層は互いを知らず、差し込み口の一覧だけが束ねる。 |
| 骨格 | 粒は突風の帯が通るときに増える（約 7 秒の周期）。カメラの直前には出さない。ゆっくり歩きは C の切り替え（Shift の走りと対になる）。生き物の声は間を空け、同時に鳴く数に上限を置く。 |
| 表層 | 粒の色は場所の主役の色から取る。布は生成りの白。光の筋は淡くして白飛びさせない。声は日本の夏の種にする。 |

この表を通して、実装が7つ変わった。①突風の式を共有の部品にした（見える風と聞こえる風を同時にする）。②場所の性格を共有の部品にした（見える物と聞こえる物を食い違わせない）。③粒の量を一定でなく突風に連動させた。④「動きを減らす」で粒と揺れを弱める。⑤作る順を「常に見えるもの→場所の小物」に入れ替えた。⑥ゆっくり歩きのキーと、操作の案内の文。⑦生き物の声の同時数と間隔の上限。

## 差し込み口（`kamakura-layers.js`）

R4〜R9 は、担当ごとに `world-kamakura.js` の同じ行を触って衝突した。R10 は層が5つ増えるので、層を1つの一覧から作り、起動のファイルは一覧を呼ぶだけにした。層が作れない・動作中に例外を出すときは、その層だけを閉じて1回だけ報告する（コンソールのエラー1件＝CI の描画検査が拾う）。

- **捨てた案**：①各担当が起動のファイルへ自分の行を足す（衝突する）。②動的 `import()` で在るファイルだけ読む（無いファイルの 404 がコンソールに出て、描画検査が落ちる）。
- 骨の後処理（主人公のしぐさ）は、人物の `cinePose`（動作の骨の後・握りの層の前に呼ばれる既存の口）を使う。谷と共用の `actors.js`・`characters.js` は変えない。前のコマの補正は、`beforeHero` で戻す。
- ゆっくり歩きは、速さの表（`SPEED.walk`）を層が書き換え、閉じるときに戻す。鎌倉では谷の物語が同時に動かないので、共用の表を一時的に変えても他へ波及しない。

## 突風と場所の性格

- 突風の帯は、草と木のシェーダーが既に持つ式（波長 約 140m・速さ 20m/秒・約 7 秒に1回）を、そのまま純粋な関数にした。草・木のシェーダー側は書き換えていない（試験が数字の一致を見張る）。
- 場所の性格は、地面の分類（その場と半径 14m の8点）・川と海までの距離・家の密度・地名（寺社・切通）から、0〜1 の重みを出す。1点だけの分類だと、升目の境で答えが跳ぶ。

## 光と空気（後処理で作る）

雲の影と光の筋は、材質ごとのシェーダーへ足さず、後処理の最後の段で、深度から作る。雲の影は、画素の明るさで重みを付けて掛ける（日なたは暗く、既に影の所はほぼそのまま）。

- **捨てた案**：①全部の材質の光の計算へ雲の式を足す（材質が20種以上あり、R4〜R9 の罠の再発が多い）。②影の地図へ雲の板を描く（縁が硬く、影の地図は近くしか覆わない）。③霧の uniform に時刻を紛れ込ませる（three の内部の持ち方に依存する）。

## 音

- 足音が埋もれた原因は、足音の上限（−6.4dBFS）だけを決め、環境音との差を測っていなかったこと。R10 は、足音と環境音を別の束（バス）に分け、**差**を数字で決めて試験する。足音が鳴る間だけ、環境音を少し下げる。
- 川は、帯域雑音1本をやめ、泡の粒（短い正弦波の上昇音）の重ね合わせ＋弱い雑音にする。風は、聞き手の位置の突風の強さで音量と音色を動かす。
- 音源のファイルは足さない（合成のみ）。**捨てた案**：CC0 の録音を同梱する。日本の夏の種（ヒグラシ・トビ・ウグイス）で権利の確かな録音が揃わず、容量も増える。合成で足りないと本人が判断したら、見直す。

## 持ち越す罠

Node の試験が緑でも、GLSL は実機でしか壊れない。Codex はブラウザを動かせない。効果が画面で見分けられないことがある（前後の差を強調して見る）。音は私には聞こえない（数字と波形で確かめ、最後は本人が聞く）。
