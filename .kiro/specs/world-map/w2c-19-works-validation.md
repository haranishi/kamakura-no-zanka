# W2c-19d 港と岩の作り物（works）：検証記録

石を積んだ堤・岩場・桟橋・つないだ舟を、地図ごとの任意のデータ（`works.json`）から置く層を足した。データの無い世界（実寸の鎌倉）では層を作らないので、画は今までと変わらない。

- 旗：`&works=0`（層を作らない）。確認用：`&worksdebug=1`（岩＝赤紫・桟橋の床＝黄・杭＝橙・舟＝水色）・`?debug=1` の `__kzWorks()`。
- 調整する定数は、置き方が `kamakura-works.js` の `WORKS`、形と色が `kamakura-works-kit.js` の `WORKS_ART`。形を図にする道具は `node tools/preview-mesh.mjs --works <出力先>`。

## データ

`meta.works = { file: 'works.json' }` があるときだけ読む。座標は、ほかのデータと同じ（x＝東・y＝北・m）。

- 岩の組：輪（中心・半径・帯の幅・口の向きと幅）・円（中心ほど大きい）・線（折れ線に沿った帯）。組ごとに、数と大きさの範囲を持つ。
- 桟橋：折れ線・幅・床の高さ。つなぐ舟：位置・向き・種類（小舟か、帆を下ろした舟）。
- 上限は、岩の組 32・岩の合計 2,000・桟橋 8・舟 24。形式や範囲が不正なら、読み込みを断る。

## 作り

- **岩**。輪は、頂に石を 2 列並べて裾に小さい石を置き、口はあけておく。海の上に置くのは、頭が水面から出る石だけ。大きさ・縦横の比・傾き・明るさは石ごとに違い、水面から 0.6m までは濡れて暗い。当たり判定は円。
- **桟橋**。板の床・杭（3m おき・海の底まで）・横木・先端のもやい杭でできている。付け根が陸に掛かる所には杭を立てず、床をそのまま地面に載せる。
- **舟**。船体は、浜の小舟と同じ。帆を下ろした舟は、帆桁に帆を巻いた姿で、どちらも喫水 0.25m で浮き、3〜5 秒の周期で上下と横にゆっくり揺れる。
- **遠い形**。カメラから 400m より遠い石は、10 三角形の塊に替える。4km（軽量 2.5km）で消す。

## 判断と、捨てた案

- **輪の `count` は、最低の数として扱う**。頂の 2 列をすき間なく閉じるのに足りなければ、足す（足した数は `__kzWorks()` の `supplemental` に出る）。向こうが透ける堤より、数が増えるほうがよい。
- **川の石の形は使わない**。最初は、川の岩の形と色をそのまま使った。ところが幅 2〜4m にすると、苔の付いた丸い塊が並び、刈り込んだ植木に見えた。海の堤は、割った石を積んだ物だ。そこで角ばった形を新しく作り、色は、川の石の乾いた面の色だけにした（新しい色表は無い）。
- **石は、面ごとの陰影で描く**。石の形は 4 種類あり、1 つの描画命令の中で、石ごとに形を選ぶ。最初は形ごとの法線も頂点に持たせたため、頂点の属性が 16 になり、実機が描画プログラムを断った。面の向きから陰影を計算する描き方に替えて、法線の属性をやめた。今は 12。
- **桟橋は、今回は歩けない**。床の下が海で、歩ける範囲の外にあるため。歩けるようにするには、歩ける範囲・床の高さ・縁の扱い・木の足音が要る。

## 実 Chrome で分かって直したこと

確認には、設計中の地図（港の輪と船着場がある）に、手で作ったデータを足して使った。Node の試験は全部通っていた。それでも、実機では 4 つの不具合が出た。

| 不具合 | 原因と直し |
|---|---|
| 層が丸ごと止まる | 桟橋の付け根を船着場に置くと、「杭の底が床より上」の検査で例外になった。陸に掛かる所は、杭を省く |
| 石が 1 つも描かれない | 頂点の属性が多すぎて、描画プログラムが作れなかった。上のとおり、法線の属性をやめた |
| 石が緑の丸い塊に見える | 川の石の形と苔の色のため。角ばった灰色の石に作り直し、大きさ・比・傾き・明るさにむらを付けた |
| 遠くの堤が、小さな天幕の列に見える | 遠い形が、とがった二重の錐だった。傾いた平らな頂の塊に替えた |

## 実 Chrome で確かめたこと（夕方前）

| 見た所 | 結果 |
|---|---|
| 船着場に立つ | 人の背より高い、角ばった石の列。すき間から向こうは見えない |
| 高さ 48m から港を見下ろす | 輪の形の堤・口・小島・桟橋・舟 3 艘が読める |
| 水面の高さから桟橋を横に見る | 杭が水の中へ届く。付け根は、床が岸に載る |
| 380m・450m・600m から | 近い形と遠い形が混ざる距離でも、堤は石の列に見える。軽量の品質でも同じ |
| コマ時間（船着場・1280×720・上限なし） | 層あり 5.5ms・なし 5.4ms |
| コンソール | エラー 0 |

## 試験

- `tests/kamakura-works.test.mjs`：データの読み方と断り方・置き方が決定的・輪の口に石が無い・頂の 2 列が閉じる・海では頭が出る石だけ・石の座り（見える形の 2〜5 割が埋まる）・当たりの円・桟橋の床と杭・**付け根が陸でもよい／全部が陸なら断る**・舟の揺れの幅と周期・更新で確保しない・形（退化した三角形なし・色の範囲）・解放。
- **頂点の属性の数**：どの描画プログラムも 12 以下（実機が 16 を断ったので、数える試験を足した）。GLSL は、差し込み口・括弧・宣言した名前を検査する。
- 層の一覧の試験を直した（`props` の次に `works`）。データの無い世界で `null`。

## 残っていること

- **港の中に、白い波の筋が輪になって出る**。白波は、岸からの距離だけで出るため。囲まれた水面で白波を出さない直しは、別の作業で行う。
- 舟の揺れは、止めた画でしか見ていない。朝・昼・夕方の色も、まだ見ていない。
- 石が、堤の頂にだけ並ぶ。斜面や水際へこぼれた石は、データの帯の幅を広げて置く。
- 桟橋を歩けない（上のとおり）。
