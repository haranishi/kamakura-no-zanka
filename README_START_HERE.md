# 残火の鎌倉 — 隠れ谷の灯

山あいの庭で、桶を拾い、井戸の水を届ける、小さな3D体験です。
v16の実モデルを引き継ぎ、v17で水運び・進行保存・効果音と谷の風景を追加しました。

## ブラウザで遊ぶ

Node.js 18以上で、このフォルダから起動します。

```sh
npm start
```

表示された `http://127.0.0.1:8080` を開きます。
ポートが使用中なら `npm start -- --port 8081`。終了はCtrl+Cです。
依存インストール、ビルド、APIキー、外部CDN、ログインは不要です。
`file://`の直接起動は非対応。WebGL2対応ブラウザが必要です。
最初に約20MBのモデルを読み込みます。

## 桶から始まる、ひとつのしごと

1. 庭の桶に近づいて拾う。
2. 井戸の東側で、水をくむ。
3. 縁側の前の小さな目印へ届ける。

WASD／矢印で歩く、マウス固定またはドラッグで見回す、Eで操作します。
タッチでは方向ボタン・画面のドラッグ・対象の操作ボタンを使います。
Shiftで早歩き、Escで一時停止、Hで表示の切替、Rで出発点に戻ります。
Rは水運びの進行を保ちます。最初からのやり直しはメニューで確認を挟みます。

進行・表示・音設定は同じブラウザの同じURLに保存されます。
別ポート・別ブラウザへの同期はありません。保存が拒否されても、その場では遊べます。

## 検証する

```sh
npm test
npm run check
npm run smoke
```

通常実行に追加パッケージは不要です。ブラウザ検証だけは、任意の開発用PlaywrightとChromeを使います。
既存のPlaywright ESM入口を`PLAYWRIGHT_MODULE`で指定して`node tools/browser-check.mjs`を実行できます。
検証結果は[今回の記録](reports/VERIFICATION_JA.md)、SDDは[要件](.kiro/specs/valley-water-carry/requirements.md)・[設計](.kiro/specs/valley-water-carry/design.md)・[タスク](.kiro/specs/valley-water-carry/tasks.md)を参照してください。

## 素材と現在の範囲

元GLBと衝突データを保持し、既存の家・井戸・稲・道具を使用しています。
Three.js 0.180.0はMIT。素材の出典と扱いは[素材の記録](docs/05_ASSETS_AND_LICENSES_JA.md)を参照してください。
プロジェクト全体や独自素材をオープンソース公開する指定ではありません。

歩けるのは庭と道です。室内、縁側、田、水路、戦闘、人物、全5章の物語は含みません。
標準品質では自然光・影・水と風、軽量では影や装飾負荷を抑えます。
OSの「動きを減らす」設定も反映します。端末ごとの性能は検証記録の条件を確認してください。
