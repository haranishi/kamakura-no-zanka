# 新機能の受け入れチェック

**下記は今後の実装に対する完成条件です。現行v16で成功した項目ではありません。**

各項目に「成功／失敗／未実施」、確認方法、環境、必要なら証拠を記録します。テスト実行のために安全制限を解除しないでください。実行できない項目は理由を明記し、未確認のまま完了保証をしません。

## A. 状態遷移と操作（自動＋ブラウザ）

- [ ] 開始 → 桶へ移動 → 拾う → 井戸へ移動 → くむ → 指定場所へ移動 → 配達 → 完了まで通常操作で一周できる。
- [ ] 桶なしの給水、空桶の配達、二重取得、二重配達は状態を変えない。
- [ ] 範囲外からの操作は無効。距離の境界直前・直後でも一貫している。
- [ ] 家などで遮られている対象は使えず、正面の井戸自体が誤って操作を妨げない。
- [ ] 対象が複数近い時は一つだけ選び、予告と実行先が一致する。
- [ ] 予告表示後に離れてから押しても実行されない。振り向いた場合も再判定される。
- [ ] E連打、長押し、タッチ連打、操作直後の再入力で状態を飛び越さず、演出や保存が重複しない。
- [ ] 拾う・空・満水・配達済みの表示が状態と一致し、桶の39部品が取り残されない。
- [ ] 所持表示と目標表示が、音や色だけに頼らず理解できる。

## B. 中断と再開（各進行状態で確認）

- [ ] 未取得／空桶所持／水入り所持／完了のそれぞれでEsc停止 → 再開できる。
- [ ] pause中にWやEを押しても移動・進行しない。再開時に押しっぱなし入力が残らない。
- [ ] ウィンドウ離脱、タブ切替、pointerlock解除で停止し、戻っても勝手に操作しない。
- [ ] タイトルへ戻る → 続きから、再読込 → 再開で、所持・進行・見た目が一致する。
- [ ] R／出発点に戻るでは所持と進行を保ち、安全な開始点へ戻る。
- [ ] 「最初からやり直す」は確認後に進行・配置を初期化し、表示と音設定は保つ。キャンセルなら変わらない。
- [ ] 完了後も散策とメニューが使え、再挑戦を繰り返せる。
- [ ] 上記のどの中断順でも桶が消失したまま、操作不能、目的達成不能にならない。

## C. 保存（自動＋実ブラウザ）

- [ ] 正常な各状態を保存し、復元できる。保存スキーマ版を持つ。
- [ ] 空値、壊れたJSON、null、配列、想定外の型、不正な状態、未知の版を安全に扱う。
- [ ] 保存領域が使えない／容量不足でもクラッシュせず、セッション内で一周できる。
- [ ] 保存中断や二重操作で中間状態を残さない。成功した遷移だけを保存する。
- [ ] 位置を保存する場合、NaN・Infinity・範囲外・水中・建物内の座標は安全な開始点へ戻す。
- [ ] 表示設定の保存とゲーム進行の保存が互いを上書きしない。

## D. UI・入力・音

- [ ] キーボード、クリックpointerlock、ドラッグ視点、タッチ操作で同じゲーム操作を行える。
- [ ] フォーカスが設定の入力欄やメニューにある時にゲーム操作が誤発火しない。
- [ ] HでHUD非表示でも再表示／メニュー復帰ができ、タッチ端末で詰まらない。
- [ ] 狭い横幅・縦長画面・横向きで文字やボタンが重ならず、横スクロールが発生しない。
- [ ] Tab操作、フォーカス表示、ラベル、タッチ領域を確認する。
- [ ] 音は明示的ユーザー操作後に開始。自動再生が拒否されても進行できる。
- [ ] ミュート、保存後の再読込、pause／離脱時の音停止が実際に機能する。
- [ ] 足音は停止中に鳴らず、同時音声が無制限に増えない。音なしでも状況が伝わる。

## E. 回帰と負荷

- [ ] 既存 `npm test` の衝突11件＋設定5件が成功する。
- [ ] 新しい状態遷移、範囲・遮蔽、保存検証に自動テストを追加する。DOM／E2Eがなければブラウザ手順で補う。
- [ ] 家・縁側・井戸・水路・田・外周を通り抜けず、地面高さと段差制限を保つ。
- [ ] 給水・配達に、立入不可の場所や登れない段差への到達を要求しない。
- [ ] 開始点から各対象までの**連続した経路**を歩いて確認する。地点の有効判定だけで済ませない。
- [ ] タイトル、設定、エラー、読込、再開、R、Hが引き続き動く。
- [ ] 無関係な稲のインスタンス化、モデル品質、衝突データを壊していない。
- [ ] ブラウザの実行時エラーを確認できた環境では記録し、確認できなければ「エラー0」と書かない。
- [ ] 実機を測定できる場合、機種・OS・ブラウザ・画面解像度・品質設定・測定方法・区間・結果を記録する。
- [ ] スマートフォン/Safariを未確認なら明記。クラウドのソフトウェア描画を実機FPSとして扱わない。
