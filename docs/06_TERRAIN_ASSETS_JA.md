# v18の地面素材と環境表現

庭の近距離の土と外周の林床に、Poly Havenの1K地面素材6画像を使用する。中遠景の枝葉に1Kのdiff/alpha atlas 2画像を使う。
取得日: 2026-10-22。画像は加工せず保存し、実行時に色・粗さ・法線の強さを調整する。

| 素材 | 作者 | 用途 | 出典 |
|---|---|---|---|
| dirt_floor | eye-candy.xyz | 土の色、OpenGL法線、粗さ | [公式ページ](https://polyhaven.com/a/dirt_floor) |
| forest_leaves_02 | Rob Tuytel | 林床の色、OpenGL法線、粗さ | [公式ページ](https://polyhaven.com/a/forest_leaves_02) |
| fir_tree_01 | Rob Tuytel / Rico Cilliers | 枝葉の色とalpha | [公式ページ](https://polyhaven.com/a/fir_tree_01) |

素材は[Poly HavenのCC0](https://polyhaven.com/license)。商用利用・改変・再配布が可能で、クレジット表記は必須ではない。
これは上記の素材の条件であり、元の独自モデルやプロジェクト全体のライセンスを変更しない。
ファイル別の取得URL・容量・SHA256は[素材記録](../provenance/terrain-v18.json)を参照する。
高ポリゴンの樹木モデル、4K原本、外部HDRI、追加ライブラリは導入していない。

## 実行時の扱い

- baseColorだけをsRGBとして読み、normalとroughnessは色変換しない。
- 地面6枚と枝葉2枚の読み込みがすべて成功してから材質を適用する。失敗時は成功分を解放し、既存の読み込み失敗画面へ返す。
- 元の地面2材質の焼込mapを保持し、world XZで土と林床を重ねる。UVの島や三角面ごとに模様が途切れない投影にする。
- 変位は使わない。元のGLB、衝突、高さデータ、稲の共有geometryは変更しない。
- 地面画像は繰り返しとミップマップを使い、遠距離の法線の強さを抑える。
- 中遠景の枝葉atlasは上記CC0画像の枝5領域だけを使い、幹や下部の別の島は除外する。木の形状、近景の単葉、山、草、落ち葉は本作独自の手続き生成。外部ゲームのコードや素材は使わない。
- 木立は近中遠の群落と低木をインスタンス化する。軽量品質で表示数を減らす。
- 水路、田、泥の水たまりは粗さ・反射・動きの速さを分け、動きを抑える設定と休止を反映する。
- 水際接続は試作を撤去した。z=7の元水面の切端と外周の継ぎ目は残件で、解消を確認していない。

実ブラウザの画角・品質・環境と性能の確認結果は、今回の検証記録に残す。
