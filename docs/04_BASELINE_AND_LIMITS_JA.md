## 既存の自動テスト16件

衝突11件：開始点、自由移動、家・縁側、井戸、西端、水路側、南北端、大移動時の通り抜け防止、壁沿い移動、道路の地面追従、22cm超段差。

設定5件：初期値、数値範囲、不正値、真偽値、nullからの復帰。

注意：設定テストは `sanitizeSettings()` の単体テストです。壊れたJSONのlocalStorage読込やUIの復元を自動検証しているわけではありません。衝突理由を全件厳密に特定するテストでもありません。ゲーム進行、対話対象、所持品、音、DOM操作、実ブラウザE2Eは未実装／未検証です。

引き継ぎ時の実行結果は `reports/HANDOFF_VALIDATION_JA.md` に記載します。`npm run check` と `npm run smoke` は配布パッケージの検査で、既存16件や新機能の受入テストとは別です。

## シーンの既知の制約

- 元モデルの井戸は粗く明るめ。今回の範囲で作り直す必要はない。
- 縁側に約74cmの段差があり、階段・ジャンプなし。縁側と室内は立入不可。
- 庭と道に材質の境目が残る。
- 田・水路・外周は立入不可。水は静止している。
- 小さな道具や草には個別の当たり判定がない。
- ブラウザ用の材質は簡素化され、元のBlender静止画と完全一致しない。

対象を遠い／立てない場所に置くことで遊びを長くしないでください。目的地は既存の安全な庭と道の中に収めます。
