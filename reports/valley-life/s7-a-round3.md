# S7-A 第3周の記録：煙を細く残し、三つの道に目印、注連縄と鍋を大きく

2026-11-03。決めたことと捨てた案は [s7-a-design.md](s7-a-design.md) の「第3周」、第1・2周は [s7-a.md](s7-a.md)。

## 結論

本人の決定2つ（家の煙は1〜2軒だけ細く残す／見1の岩棚は変えない）と、担当の判断2つ（三つの道の目印・注連縄と空の鍋を大きく）を実装した。
盲検の採点と「何が起きているか」の読み取りは、まだ受けていない（別役が行う）。ここにあるのは自分の目と数値の確認だけで、合格とは言わない。

## 変えたこと

| 項目 | 前 | 後 |

## 検証

- `npm test` は715件すべて合格。直した試験は、煙・注連縄の寸法・流れ旗と柴垣の寸法と当たり・出し入れ・下草の固定値。`npm run check`・`npm run smoke`・`git diff --check` も合格。
- 変異試験は `verify-life-rules-mutations` 49件と `verify-life-view-mutations` 37件で、すべて検出した。足したのは、煙の数と細さと家の選び方、流れ旗の出し入れ、柴垣の当たりと置き場所、注連縄と旗の寸法。
- 回帰シナリオ21本（`--strict`）はすべて合格。攻撃の論理（斥候の320コマ）は、作業前の写しと作業後で一致した。
- 性能の8試行は回していない。増えたのは呼び出しの最大1回と三角形の最大2,516で、第2周の測定（`s7-a-perf.json`）の余裕の内と見ている。ただし未測定。

## 残ること

- 見晴らしの固定画角（08・25）には、北と南の柴垣が入らない。北は画角の下、南は右の外にある。08だけで三つの道の違いを読ませるには、画角か置き場所を見直す必要がある。今回は「見1を触らない」決定に合わせ、画角を変えていない。
- 家の細い煙は、08では奥の2軒の上に淡く見える程度。細さは本人の決定どおりだが、遠目で読めるかは盲検で確かめる。
