# S7-A 設計メモ：見晴らし岩と里の入口を「物の置き方」で語らせる

2026-11-01。正本の設計は `docs/valley-life-plan`（PR #35）の design-valley-life*.md と research-valley-life-period.md。
ここには、その表を実装へ落とすときに決めたことだけを書く。結果と数字は [s7-a.md](s7-a.md)。

## 分担

| ファイル | 層 | 受け持ち |
|---|---|---|
| `world-data.js` の `life` | data | 置く物の表（items）・地面の跡（marks）・小石と草とススキ（stones/tufts/susuki）・踏み固めた土（trodden）・烏（crows） |
| `life-rules.js`（S7-0） | 純粋 | 場面と選択から「出す物・状態・数」を決める。今回は変えない |
| `world-colliders.js` | 純粋 | items の `hit` から当たりを作る（膝より高い物だけ） |
| `terrain-height.js`・`grass-field.js` | 純粋 | trodden を土の地面にし、草を生やさない（各1行） |
| `life-kit.js` | view | 小物の型（形と絵を手順で作る）・地面の跡の帯・揺れる草の材質 |
| `life-view.js` | view | 型を batchParts で置き、状態と距離で1つずつ出し入れする。烏・燠・ススキを動かす |
| `game.js` | app | 任務が変わるたびに `lifeScene(lifeInputFromQuest(...))` を配る。煙を場面で切り替える |
| `main.js` | app | 組み立てを1行（と import） |

## 表の約束

- `show` の無い物は、どの場面でも出す。当たり（`hit`）を付けてよいのは、この「いつも出る物」だけ（消えた物の当たりが残らないように。試験で見張る）。
- `show = { item, state?, min?, max? }`：life-rules のその物の状態と数で出す。数で増える物（俵の5・6個目）は、下の俵の上に積み、新しい当たりを要らなくする。
- 柵の2区画目は、立っている姿と傾いた姿を出し分ける。当たりは別の行（`kind: 'hit'`）で、どちらの姿でも同じ箱を置く。

## 場所ごとの落とし方（番号は design-valley-life-places.md）

- 見1 平らな岩（大岩の模型を平たく）。見3 北＝畑の縁の杭5本と細い踏み跡、南＝ススキの列（畦は土のまま。石積みは裏取りが無い）、正面＝流れ旗と荷車と轍。
- 見4 襲撃中は家の煙を止め、野営の燠から灰色の煙を1本。救ったあとは家の煙が戻る。見5 烏24羽が南の棚田の上を回る。結末では烏峰の方へ去る。
- 見6 板碑（飯田の例に倣う細長い薄い板石。紋や文字は架空の印）。見2（一本松）は PR #33 のあとなので今回は置かない。
- 入1 俵：蔵の戸口から荷車へ4個（1つは破れて米がこぼれ、荷車まで米の筋が続く）、兵1の手もとに1個。荒れるほど下の俵の上へ積み増す（5・6個目）。外した戸板を蔵の壁に立てかける。野営の外回りの流れ旗を2本足して5本にする。
- 入2 炊き場：石の輪・灰・燠（炎なし）・筵2枚。空の鉄鍋は火から下ろして横に倒し、口から底まで空なのを見せる（柄杓は地面に）。救ったあとは燠が消える。
- 入3 祠の注連縄：祠を道の縁から1m外へ出し、前に杭2本。襲撃中は縄が切れて垂れ、救ったあとは張り直す（藁の房3つ）。
- 入4 家1の柵が1区画倒れ、荒れ方3でもう1区画が傾く。畑に曲物の桶・倒れた籠・散った菜。荒れ方2・3で踏み跡と散らばりが増える。
- 入5 祠の脇に柴の束（背負子の枠は出さない）と足半を片方。入6 弥十郎の弓と矢筒を荷車に立てかけ、仲間になると消える。
- 入7 轍2本（蔵→荷車、荷車→東の道）と野営の踏み固めた土。入8 入口の道の両脇20mに小石・苔の石・背の低い草むら。

## 時代の裏取りの反映

幟→流れ旗（props.js の3本を、横木から細長い布を垂らす形へ）、村境の縄→祠の注連縄、桶→曲物、布→麻（今回は使わない）。
使わない形：千歯扱き・石の挽き臼・内耳鍋・備中鍬・木綿。背負子・草鞋・柄杓・矢筒の形は未確認なので、目立たない形で使い、出所台帳に「未確認」と書く。

## 費用の約束

小物は影を落とさず、足もとに暗い円（地面の跡の1つ）を敷く。本物の明かりは足さない（燠は光る材質だけ）。
小さい物は25mより遠くで描かない（軽量15m）。俵・柵・板碑・ススキ・烏・煙は遠くから読ませるので消さない。
質感は1枚の絵（16区画）を全部の型で共有する。Blender が使えなかったため（下記）、形と絵は `life-kit.js` の手順で作る。

## Blender を使わなかった理由

依頼は「v02 の小道具と同じく Blender の手順書きで形を組む」だったが、この機の Blender（外付けSSD上）が読み出しエラーで起動できなかった。
同じ考え（形も絵も手順で作り、出所が手元で閉じる）を、読み込み時に three.js で組む手順に置き換えた。外部の素材は使っていない。
