## 再現

```sh
node tools/compress-characters.mjs --in .work/original-characters --out dist/assets/characters --report reports/character-compression/compression.json
node tools/verify-compressed-characters.mjs --original .work/original-characters --compressed dist/assets/characters > reports/character-compression/verification.json
```

`--dry-run` はGLBを書かずに計測する。元は履歴から復元可能で、配布物には含めない。
画像の再圧縮・キーフレームの間引き・固定トラックの省略は行っていない。
完全一致するアクセサとバイト列の共有・animation/skin用bufferViewの統合は値を変えない。
ウェイトは読み込み時と同様に合計を正規化してCPU比較する。
元には2キーのSTEPと、複数キーのLINEAR平行移動もあった（すべて1キーという前提と相違）。

- **見た目**：ラボ画面（`lab.html`）で、人物7体×動作3つ（歩き・走り・立ち話）×視点2つ（斜め前・後ろ）の42枚を、圧縮の前後で同じ条件で撮って比べた。撮影は決定的で、圧縮前を2回撮った差は全画素0だった。圧縮後との差は、平均で最大0.046/255・8段階超の画素は最大0.073%・最大差60（装甲の細かい縁の画素）で、差を20倍に強調しても全体の濃淡のずれは無く、縁にまばらな点が出るだけだった。
