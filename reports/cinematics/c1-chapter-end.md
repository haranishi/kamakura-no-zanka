# C1：帰還の区切り（章末の演出）を結末につなぐ

2026-11-04。判断と捨てた案は [design-cinematics-c1.md](../../.kiro/specs/hidden-valley-slice/design-cinematics-c1.md)。
本人の確認（区切りの文・火から灯への結び・全分岐の読み）と、別役の盲検採点は未。合格の記録ではない。

## 変えたこと

- 表 `CINEMATICS` に `chapter1_end`（種別 end・第1章・復帰先 result）。断片の数で3版：0〜2個 8.4秒／3〜4個 9.0秒／5個 9.4秒（準備・移行・復帰を含む）。
- 結末：result → ending_truth →（演出・自動）→ ending_coda（手送り3行）→ 保存・結果画面。章末の7行のうち4つ（無言2つ・「もう、いい。」・最後の語り）を演出へ移した。
- 人物の見た目だけの動き（息づかい・視線・うなずき・袖印を差し出す手）、焚き火の炎、袖印が手から火へ落ちる動き（5個の版だけ）。
- 「続きから」：章末を見ていなければ出し直し、見ていれば結果へ直行（保存と結果画面は各1回）。

- 全版：完走・飛ばしとも結果画面へ1回、保存1回・結果画面1回（120コマ待ってから数える）。断片は減らない。章末の完了を記録。
- 世界の停止：演出の30コマごとと終わった直後に、時刻・乱数の呼出数・タイマー・任務・断片・資源・信頼・人物の位置と向き・体力・矢の数が開始時と一致。
- 袖印：5個の版だけ板が出て（139コマ）、約2.9秒（175コマ目）で火に触れて炎が上がる。0〜4個では出ない。5個を火の前で飛ばしても、くべた結末として扱う。
- 飛ばし：0.6秒前（20コマ目）の押下では飛ばず、45コマ目の新しい押下で飛ぶ。飛ばした E は手送りの最初の行を送らない。案内は36コマ目に出る。
- 動きを減らす設定（模擬）：5つのショットとも30コマの間カメラと頭の骨が不動。字幕OFF・音量0でも「もう、いい。」と最後の語りが出る。
- 再開：演出の途中で閉じた続きは章末を出し直す（540コマ・完了を記録）。手送りの会話の途中で閉じた続きは、演出も会話も出さず結果へ直行（保存1・結果1）。
- わざと壊す：飛ばし後に保存を二重に→「2 saves」、袖印が燃えない→「badge burned false」、自動部分11秒（上限を一時的に12秒へ）→「660 frames」で、3通りとも落ちる。各回、元へ戻して差分なし。

## 遊びは変わらないこと・性能（main の写しと交互に3回。別担当の計測と同時）

- attack-timing：斥候320コマ・侍大将520コマとも main と一致。
- 戦闘の場面1800コマの p95（ms）：標準 main 23.3/23.8/20.4・本版 21.3/20.5/23.6、軽量 main 13.8/16.1/17.1・本版 16.8/17.1/17.4。呼出・三角形は同じ（標準441・386万、軽量407・319万）。
  同じ版の中で3〜4ms揺れ、順番も入り乱れる。main も標準で20msを3回とも超えるので、この環境では絶対値で合否を決められない。
- 結末の場面564コマ：本版は演出の全尺、main は同じ場面の結びの会話。標準 p95 main 17.2/18.1/14.9・本版 13.8/19.8/18.5、軽量 main 8.8/13.8/13.3・本版 11.3/13.3/14.2。演出中の呼出378・三角形344万（標準）。
  本版の最初のコマだけ 78〜232ms。調べると main でも真相の会話が閉じた直後のコマが 151ms（同じ手順）で、演出が足したものではない（人物の動きを止めても 146ms）。
- 実読込 77.7MiB（90MiB 以内）。新しい素材・依存・外部通信はない。
