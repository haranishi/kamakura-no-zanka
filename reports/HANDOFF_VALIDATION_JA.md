# 引き継ぎパッケージ検証

検証日：2026-10-21。Node.js 24.19.0、npm 11.9.0、Linux。

- 元v16の `dist/` 全20ファイルとバイト単位で一致。ゲーム機能は変更していません。
- `npm test`：衝突11件、設定5件、合計16件成功。
- `npm run check`：必要ファイル、JavaScript構文、GLBヘッダーと画像内蔵を確認。
- `npm run smoke`：11ルートのHTTP 200とMIME、HEAD、404、許可しないHTTPメソッド、親ディレクトリへのアクセス拒否を確認。
- ZIPのCRC検査に成功。空白を含む新しい解凍先で、上記3コマンドを再実行して成功。
- 解凍先で `npm start -- --port <空いているポート>` を起動し、HTTP 200と日本語タイトルを確認。サーバーを終了。
- `.git`、公開用設定、キャッシュ、node_modulesを除外。文書・コード・JSONから制作環境の絶対パスや内部ファイル識別子、主要な秘密情報パターンを検査し、該当なし。GLBのJSONにもそれらのパス・識別子なし。
- ハッシュ一覧 `FILES_SHA256.json` は自己参照を除く全同梱ファイルを対象にし、解凍後に照合。

この検証は配布・起動・既存ロジックの確認です。ブラウザのWebGL画面を今回再試験したわけではありません。過去の画面・操作確認と限界は `docs/04_BASELINE_AND_LIMITS_JA.md` を参照してください。将来の桶・水くみ・配達などの受入試験は未実施です。

Node.js 18以上の標準APIを使用していますが、実行確認したNodeバージョンは上記のみです。この環境ではnpm自身から環境設定 `http-proxy` に関する警告が出ましたが、各コマンドは終了コード0でした。プロジェクトの依存インストールやネットワーク取得は行っていません。
