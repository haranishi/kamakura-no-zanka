# オープニング（S3・S4）の検証記録

設計は `.kiro/specs/hidden-valley-slice/design-opening.md`、実装の判断は同じ所の `design-opening-impl.md`。

## 一段目（2026-10-30）：進行・語りの枠・記録・結線・仮の舞台

舞台はまだ仮のもので、場面A〜Dは地面・空・霧の色だけを変えている。燃える町や寺は二段目で作る。この段で確かめたのは、描画の切り替え・解放・谷への戻りの経路と、語りの枠の読みやすさ。

- `stage1-A-history-line.jpg`：場面A（仮）と史実の語り（生成りの字）。上下の帯と、右上の「飛ばす」の案内。
- `stage1-C-fiction-line.jpg`：場面C（仮）と創作の語り（朱の字）。
- `stage1-title.jpg`：題名と注記（暗転の上）。
- `stage1-wake.jpg`：既存の目覚め（オープニングの最後の区間）。暗転から明ける途中。
- `regress-stage1.json`：`tools/scenarios/regress-opening.mjs` の測定値。

測った値（M4 Pro・Chrome ヘッドレス・1280×720・DPR1・標準品質）：

- 区間の始まり（0.1秒刻みの観測）：A 2.1・B 11.5・C 21.1・D 30.6・題名 42.1・目覚め 47.1・遊び 52.3秒（設計は 2・11.5・21・30.5・42・47・52.2）。短い版は A 1.0・D 4.6・題名 8.1・目覚め 10.5・遊び 15.7秒。
- 飛ばしてから目覚めまで：E・Space・クリックとも0.617秒（37コマ）。
- 字と帯の比：生成り 16.57:1、朱 6.18:1。6画面とも下の帯の中に収まる（760×560でも1行）。
- 仮の舞台の描画：呼出14・三角形974（予算は呼出300・三角形150万）。
- 解放後の谷（同じ固定カメラ）：呼出433・三角形3,122,449はオープニング無しと同じ。3回上映しても形295・画像175のまま増えない。
- 既存の回帰14本（`--strict`）と、戦闘の論理の一致（320コマ）は、変更後も通る。
- オープニング中の1コマ（仮の舞台）：p50 1.9ms・p95 6.9ms（`perfSamples`、3000コマ）。目覚めの最初の1コマは約0.31秒（変更前も約0.36秒）。
- 別役（Codex・読み取りのみ）のレビューで2件を直した：明けの途中で飛ばすと暗転が一瞬薄くなる／溶け合いの途中で画面の大きさが変わると前の場面が消える。どちらも試験に足した。

読める・読めないの所見：語りは帯の上で、明るい空の場面でも読める。朱の字は生成りより暗いが、帯の上では十分に読める。仮の舞台の空の朱は画面の3割を超えており、二段目で2割以下に抑える。

## 二段目（2026-10-31）：場面A・Bの作り込み、目覚めの止まりの解消

A（燃える通り）と B（燃える寺）を作り込んだ。C・D はまだ仮（色だけ A・B にそろえた）。

- `stage2-O1a.jpg`・`stage2-O1b.jpg`：場面A。左奥の農家が燃え、右奥の農家は屋根の奥だけが燃える。奥は霧に溶ける。手前に倒れた無地の幟。
- `stage2-O2a.jpg`・`stage2-O2b.jpg`：場面B。石段の下から見上げる寺。棟と扉口の炎、火の粉、炎に照らされた石段と灯籠。
- `regress-stage2.json`・`perf-stage2.json`：`regress-opening.mjs` と `measure-opening-perf.mjs` の測定値。

測った値（M4 Pro・Chrome ヘッドレス・1280×720・DPR1・標準品質）：

- 朱の面積（上下の帯を除く絵）：A 15.3%・18.7%、B 14.6%・14.5%（目標は2割以下）。
- 明滅：A・Bとも 0回/秒（目標は1秒に3回以下）。
- 描画：A 呼出154・三角形48万、B 62・13万（予算は呼出300・三角形150万）。1コマ：A p95 7.4ms、B p95 5.5ms（予算 20ms）。
- 目覚めの最初の1コマ：288ms → 23ms（飛ばした経路）。始まりの1コマは536ms（2秒の暗転の下）。
- 上映を3回繰り返した前後で、形296・画像175のまま。区間の時刻・語り・飛ばし・短い版・休止などの一段目の検査も通る。

読める・読めないの所見（自分の目で画像を読んだもの）：A は「燃える町の通り」として読める。燃えるのは2棟で、町全体が焼けた絵にはなっていない。B は寺が燃えている絵として読めるが、棟の上の炎は一列に並んだ形がまだ少し残る。B の煙の柱は画面の上の帯より上に出るので、絵の中ではほとんど見えない。どちらも語りの帯と重ならない。

### 二段目の後半：場面C・D（軽く）

- `stage2-O3a.jpg`・`stage2-O3b.jpg`：場面C。橋を母子・老人・武士の4人が影になって渡る。対岸の家の向こうに火と煙。
- `stage2-O4a.jpg`・`stage2-O4b.jpg`：場面D。山道で振り返る景継の後ろ姿。谷底の2か所に火と煙、地平に赤い帯。O4b は左へ向き直って歩き出したところ（顔はカメラへ向かない）。
- `stage2-reduced-O1a.jpg`・`stage2-reduced-O4b.jpg`：「動きを減らす」。カメラは止まり、絵の組み立ては同じ。
- `regress-stage2.json`・`perf-stage2.json` は、A〜D をそろえたあとの測定値に置き換えた。

測った値：朱の面積 C 5.6%・5.7%、D 18.8%・19.3%。明滅は A〜D とも 0回/秒。描画 C 呼出63・三角形36万、D 42・9万。1コマの p95 は C 3.0ms・D 3.4ms（同じ回の A 5.5ms・B 4.7ms）。始まりの1コマは人物5人を足して625ms（暗転の下）。目覚めの最初の1コマは32ms。

所見：C は「燃える町から逃げる人の影」として読める。水面の照り返しはまだ広く、手前が少し明るい。D は後ろ姿と遠くの火が読めるが、谷底は平らな面に見える（山並み・木を置いていない）。

## 四段目（2026-10-31）：人影と景継の白い粒（3周目の講評の2）

見た目だけを直した。方式と捨てた案は `design-opening-impl.md` §8。講評の1（炎）・3（D の町）・4〜6 は、この周では手を付けていない。

所見（拡大して自分の目で読んだもの）：C の岸と橋の人影は、白い点が消え、炎の側の輪郭が細い朱の線で続く。D の景継も背中の白い点が消え、右の腕・肩・頭に朱の縁が出る。腰の柄は朱の塊に見える（刀の部品は法線をならしていない）。
