# 8.4a・8.5a 押し戻しと、とどめ・弾きのスロー：前後の記録

当たった敵が約0.2m下がり、弾き・とどめの瞬間に0.25秒だけゆっくりになるようにした（本人が2026-10-30に選んだ、規則に触れる2つ）。
設計・捨てた案・契約は `.kiro/specs/hidden-valley-slice/design-combat-impact.md`。ここは測った結果と画像の置き場。

## 実ゲームの確かめ（`regress-impact.json`）

`tools/scenarios/regress-impact.mjs`（`--strict`）の全項目が合格。

- 押す距離：兵の弱0.2m・強斬り0.25m、侍大将0.1m・0.125m。横ずれ0。
- 三連：相手まで1.2・1.6・2.0・2.15mで3発とも当たる。三段目の時の距離は0.72・0.72・0.82・0.97m（変更前は押し分けの下限0.72mに寄っていた）。
- 壁：入り0m。崖：46度より急な下りの手前で止まった（歩きなら0.49m降りられる場所で、出られる0.146mに対し+0.008m）。そばの人：最小0.72m、その人は動かない。
- スロー：弾き 停止6コマ＋スロー15コマ、とどめ 停止7＋15、弱の当たり 停止5＋0。最も遅いのは0.3倍で、停止と掛け算した0.015倍は0コマ。
- 揺れ0・動きを減らす：スロー15コマ（停止は前から半分の3コマ）、押す0.2m。

## 論理への影響（`attack-timing-drift.json`）

- 押し戻しとスローを止めると、変更前と全コマ一致（斥候320・侍大将520）。
- 斥候：攻撃の開始コマ（20・83・252）・技・相手の技・体力は同じ。位置は押した分ずれる（相手最大0.47m、主人公0.23m）。
- 侍大将：押し戻しだけなら、開始コマ・技・体力は同じ（位置のずれ0.045m）。スローを入れると、38コマ目の弾きのあとゲームの時間が約8コマ遅れる。
  侍大将の技は画面のコマで9〜10コマ後ろへずれ（74→83 など）、決まったコマの入力が別の場面に当たって、主人公の開始コマが変わる（153・332→130・163・320）。

## 盲検採点

別役（Opus・画像だけ）に、場面ごとに変更前と変更後を X・Y へ無作為に割り当てて渡した（6枚・コマごとの速さと距離の数値つき）。
尺度は0〜10点で、5＝改修前の水準（どちらかは伏せる）、7＝商業のアクションゲームの最低線。下の表は割り当てを開いたあとの値（変更前→変更後）。

| 場面 | 項目 | 第1周 | 第2周 |
| --- | --- | --- | --- |
| A 三連 | K1 手応え／K2 押し戻しの読み／K5 姿勢／K6 迫力 | 4→5／4→5／4→4／4→5 | 4→6／3→6／3→4／4→6 |
| D 弾き | K1 手応え／K3 間／K4 予兆と読み／K5 姿勢／K6 迫力 | 5→5／5→6／5→6／4→4／5→6 | 5→5／5→6／5→5／5→4／5→6 |
| F とどめ | K1 手応え／K2 押し戻しの読み／K3 間／K5 姿勢／K6 迫力 | 4→5／4→5／5→6／4→4／4→5 | 4→6／4→6／4→6／4→4／4→6 |

- 第1周のあとに直したこと：鎧でひるまない一・二発目で、構えたまま滑って見えた（押される0.3秒だけ被弾の動作を見せる）。とどめのあと、相手が背筋を伸ばして立ち直ってから崩れた（倒れる動作の始めの立ち姿を飛ばす）。撮影は、膝をつき終えるのを待ち、地面の矢印を消した（両方の版で同じ）。第2周では、主人公の手の握り（別の変更で直す）を減点に数えないよう頼んだ。
- **7点に届いた項目はない。** 変更後は、三連ととどめの手応え・押し戻し・迫力が6点、弾きの間と迫力が6点。
- 姿勢（K5）は2周とも4点で、同じ失敗が2回続いたので、ここで周回を止めた。

別役が挙げた、残った弱点（第2周）：

1. とどめで倒れる間、相手が両腕を真横へ水平に広げたまま倒れる（dying_backwards の動作）。スローがこの形を長く見せる。
2. 弾かれた相手が、踏み込んだ位置から下がらず、両腕を前に出して直立する。スローがこの形を約0.25秒映す。押し戻しは「当たった敵」だけなので、弾かれた相手は下がらない（下げるなら規則の追加で、本人の確認が要る）。
3. 弾いた瞬間に、画面上の「E で、とどめを刺せる」と右下の「左クリック…いま反撃」が同時に出て、どちらを押すか迷う（前からの案内。スローで目立つようになった）。
4. 三段目の当たりのあと、相手の両腕が頭の上へ跳ね上がる（被弾の動作の終わりの形）。三段目の停止は一・二段目と同じ0.07秒で、差が小さい。
