## 測定（2周目）

- 毎コマの回帰（`tools/scenarios/regress-hand-grip.mjs`・31場面。結果は `regress-hand-grip.json`）：すき間は右手で主人公2.0・兵2.9・侍大将5.7mm、両手持ちの左手で4.7・3.7・5.6mm、抜刀中3.2mm、鞘の左手5.1mm。めり込み最大1.5mm、跳び最大2.98倍、袖・腕・手の辺の伸び最大42.3mm、攻撃・構えで鍔が右の袖・手を横切るコマ0、材質はすべて不透明。
- 実ゲーム（`tools/scenarios/regress-hand-grip-game.mjs`・4場面）：抜き切ると右手は柄を握り、構えでは左手も柄を握る。抜く間は左手が鞘を持ち、納め切ると解ける。
- 刀の軌跡（`record-sword-tips.mjs`）：1周目の版（7678c78）と比べ、116列・22,379コマで切先の差0.0000mm。戦闘の論理（`regress-attack-timing.mjs`）：320コマ一致。
- 性能（`measure-perf.mjs`・戦闘・標準）：描画呼出682・三角形4,188,713で前後同じ。p95は16.5ms（前16.4ms）。型の準備は主人公158・兵94・侍大将81ms（読み込みの間に1回。前52・35・37ms）。
- 純粋層の試験10件、変異27件（`tools/verify-hand-grip-mutations.mjs`）はすべて検出。
