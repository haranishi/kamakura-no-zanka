本人が「いまのまま入れる」を選んだので、絵は直さず、枝 `feat/story-opening` に main（`eeafbf8`）を取り込んだ。磨きは取り込みの後に行う。

## 衝突と解き方（どちらの機能も捨てていない）
- `dist/valley/game.js`：コンストラクタの1行だけが衝突した。main のスローの時計（`slowT`・`slowDur`）と、オープニングの流れの名前（`intro`）を両方残した。`startNew()` は自動で合わさり、`stopOpening()` → `resetStory()` の順になる。
- `tools/check-valley.mjs`：モジュール表と純粋層の表を和集合にした（opening の5つと3つを main の表の頭に足した）。
- `tools/README-valley-qa.md`：シナリオの説明を、main の分の後にオープニングの3本を並べた。
- 物語の本体（#37）とオープニングは `game.js`・`hud.js` の別の行に触れていて、自動で合わさった。掛け合いは `flow !== 'play'` の間は出ないので、オープニング中には出ない（下の確認で実測）。
