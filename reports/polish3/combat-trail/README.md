# 8.3a 刃の軌跡と当たりの瞬間：前後の記録

第3周（2026-10-31）で、停止のコマに刃が相手の胴へ入るようにした。弓以外の11技で、相手まで1.2m・1.6m・間合いの端のどれでも入る（33件）。
方法は、模型の根だけを相手へ出して回す「見た目だけの踏み込み」。論理の位置は変えていない。戦闘の論理は main と一致する。
火花は白い煙の玉をやめた。刃が胴へ入る点から、斬った向きへ飛ぶ線状の筋にした。
設計・捨てた案は `.kiro/specs/hidden-valley-slice/design-combat-trail.md`。ここは測った結果と画像の置き場で、点数は付けていない。

- 第2周は、同じ距離で最短0.24〜1.56m（間合いの端）。第3周は最大0.195m。
- 論理（`regress-attack-timing.mjs`）：斥候320コマ・侍大将520コマとも main と一致。
- 見た目の中心どうしは最小0.553m。壁の前では根が壁へ入らない（0m）。急な斜面では、論理で出られる所の0.24m手前で止まる。そばに立つ別の人へは0.72mより近づかない。技が終わって0.4秒で根のずれは0に戻る。揺れ0・動きを減らすでも0.82m踏み込む。
- 三段目の接触を0.609→0.645へ遅らせたので、`contact-after3.json` の三段目は判定の始めより21ms早く出る（第2周の定義の接触）。切り出しは `move-segments-after3.json`（速さ1.8倍・使用割合0.527）。
- 火花（`regress-slash-trail-after3.json`）：当たり1回で芯の光1つと筋9〜14本。86〜100%が刃の進む向き。弾きは芯1つと筋22本、刃同士の距離は前と同じく3cm以内。
- 性能：描画呼出の増加は帯1・筋1。筋は最大96本（192三角形）。毎コマの確保は、踏み込みの計算・筋とも0.56B/コマ（空の繰り返しと同じ）。

## 自分の目で見た所見（採点ではない）

一段目・強斬り・二段目は、停止のコマで刃が相手の体に入って見え、火花が刃の入った所に出る。第2周の「刃先と煙の玉が離れる」は無くなった。
袈裟は体ごと右へ約60度回るので、真横のカメラでは主人公がこちらへ向き直って見える。三段目は相手が近すぎて、手が顔の前に残る。
帯（上からの細い弧・強斬りの縦の線）、相手のT字の棒立ち、弾きの姿勢は、第2周のまま（第3周では扱っていない）。
