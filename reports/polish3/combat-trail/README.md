# 8.3a 刃の軌跡と当たりの瞬間：前後の記録

第2周（2026-10-31）で、停止と火花が出るコマに刃が相手の胴の高さへ来るようにした。弓以外の11技すべてで、接触が判定の始めから1ms以内に来る（前は7技が34〜100ms遅かった）。
帯は乳白の板・縦の柱をやめ、切先の道に沿う細い光の線にした。戻りの間には残らない。どれも表示だけの変更で、戦闘の論理は main と一致している。
設計・接触時刻の定義・捨てた案は `.kiro/specs/hidden-valley-slice/design-combat-trail.md`。ここは測った結果と画像の置き場で、点数は付けていない。

## 第2周で測った結果

接触時刻と判定の始めの差（ms、正なら接触が遅い）。相手は間合いの距離に置いた動かない点（地面から1.1m）。最短は、刃の中ほど〜切先と胴の点の最も近い距離。

| 技 | 前（第1周） | 後 | 最短（後） |
| --- | ---: | ---: | ---: |
| light1 | +38 | +1 | 1.26m |
| light2 | +59 | 0 | 0.49m |
| light3 | +21 | 0 | 0.73m |
| heavy | +78 | 0 | 0.95m |
| counter | +34 | +1 | 1.56m |
| finisher | −7 | 0 | 0.24m |
| soldier_slash | +22 | 0 | 0.49m |
| soldier_thrust | +61 | +1 | 0.65m |
| officer_a | +23 | 0 | 1.02m |
| officer_b | +70 | 0 | 0.50m |
| officer_c | +100 | 0 | 1.03m |

- どの技も、間合いの距離では刃が胴の点に届かない（胴の半径0.2m以内に入らない）。とどめの0.24mが最も近い。記録は `contact-before.json`（第1周の生サンプルを第2周の定義で読み直した値）と `contact-after2.json`。
- 切り出し（`move-segments-after2.json`）：速さは最大1.8倍で、とどめは前と同じ2.0倍のまま。使用割合は light2 だけ0.491→0.485と下がり、ほかは前と同じ。light2 は上限1.8倍で技の0.53秒に流せる長さ（0.954秒）が最大なので、これ以上は戻せない。実際に再生されていた長さは前の0.943秒より延びた。
- 手首の速さの山（第1周の基準）は、判定の始めより21〜82ms早くなった。振りの途中に接触があるので、山が先に来るのは狙いどおり。
- 帯の決まり（`regress-slash-trail-after2.json`）：区間の外（戻りを含む）で足した数0、閉じて0.05秒＋1コマで消える、描画呼出の増加1、三角形は最大56（上限732）、三段目の停止0.07秒のまま。
- 停止のコマの主人公の切先（地面から）：light1 1.14m・light2 0.95m・light3 1.44m・heavy 0.87m（第1周の light1 は2.06m）。
- 火花の80〜100%が刃の進む向き（余弦0.5以上）。弾きで打ち合ったときの2本の刃の距離は0.000004m。
- 敵の刃は、予兆の間の18コマは元の鋼、戻りの間の40コマは地の色を落とした。ひるまない一段目でも、斥候の頭が主人公から8.7cm離れる（論理の state は idle のまま）。
- 論理（`regress-attack-timing.mjs`）：同じ入力列で、斥候との320コマと侍大将との520コマが main と一致。
- 新規確保：帯の見た目6種を混ぜて6本を毎コマ作り直しても、若い世代の増加は0.59B/コマ（空の繰り返しと同じ）。第1周の形は、見た目が混ざると68B/コマだった。

## 自分の目で見た所見（採点ではない）

停止のコマで、刃が相手の体の高さにあり、上からの細い弧が刃先へ入る。これで「斬った瞬間に止まる」と読める。ただし真横から見ると、刃先と相手の間に約1mの隙間が残る（刃が届かないため）。
強斬りの帯は、縦の振りなので真横からは縦の細い線に見える。長さは0.8mで止まり、戻りには残らないので、第1周の柱にはならない。
突きの光の線は等倍では読めるが、480×270のコマ割りでは細い。
弾きでは、主人公の刀が一瞬で伸びて相手の刃に触れる。停止の間に姿勢が切り替わるので、繋ぎは見えない。左手は柄頭へ届くが、指は受けの動作のまま開いている（握りは 8.6a）。
