## 測定（`perf.json`）

変更前（main 9bf9eea の写し）と変更後を、同じ条件で交互に2回ずつ測った（`tools/scenarios/measure-perf.mjs`、M4 Pro・Chrome 156・1280×720・DPR1）。同じ時間帯に他のセッションのChromeがGPUを使っていたので、絶対値は保存標本より高い。

| 品質・場面 | p95 前（1回目/2回目） | p95 後（1回目/2回目） | 最大呼出（前→後） | 最大三角形（前→後、1回目） |
|---|---|---|---|---|
| 標準・移動 | 17.4 / 17.6 ms | 19.0 / 17.9 ms | 757→757 | 4,456,285→4,542,602（+86,317） |
| 標準・戦闘 | 17.8 / 16.4 ms | 16.7 / 16.8 ms | 682→682 | 4,188,713→4,254,287（+65,574） |
| 軽量・移動 | 15.8 / 15.9 ms | 16.4 / 16.4 ms | 735→735 | 3,665,305→3,707,181（+1.1%） |
| 軽量・戦闘 | 14.7 / 15.5 ms | 16.0 / 15.7 ms | 654→654 | 3,372,000→3,396,898（+0.7%） |

全16回とも予算内（標準p95≤20ms・軽量≤33.3ms・呼出≤900・三角形≤500万）。標準・移動は1回目で19.0msと、上限まで1msしか残っていない。
木の1パスの三角形（Node・実際の配置）：開始地点 1,285,672→1,328,534、林道 1,242,466→1,278,092。画像を作る時間（起動時と品質の切り替え時）は約15ms→約45ms。
LODの明るさ（同じ木のL0・L1・L2を並べた画素の平均）：順光ではそろう（45mで43〜44）。逆光では中景（L1）が近景より約12%、遠景（L2）より約15%明るい（変更前は±4%以内）。

## 回帰

### 第2周の測定（`perf2.json`）

第1周（516f9bd の写し）と第2周を、同じ条件で交互に2回ずつ測った（M4 Pro・Chrome 156・1280×720・DPR1）。

| 品質・場面 | p95 第1周（1回目/2回目） | p95 第2周 | 最大呼出 | 最大三角形（1回目） |

| 標準・戦闘 | 16.1 / 19.9 ms | 14.4 / 18.3 ms | 682→669 | 4,254,287→3,799,173 |
