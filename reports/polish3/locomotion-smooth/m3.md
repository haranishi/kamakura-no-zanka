# 走り・歩きの滑らかさ M3：走りの形（体幹・頭・前傾・曲がり・骨盤の上下・後ろへ引く腕）（2026-11-04）

前＝この枝の `?smooth=arms`（M2b の姿勢。762コマの記録の指紋 69ee9d393ee3399a が M2b の main と一致）。後＝この枝の既定。
入れたのは上半身の二次運動の層（`dist/valley/upper-body.js`（式・純粋）・`upper-rig.js`）と物差し `tools/lib/upper-metrics.mjs`。設計と捨てた案は `design-locomotion-upper.md`。

## 結論
- **既定**：体幹の逆回転・頭の安定・前傾・曲がりの傾き・骨盤の上下の縮め・**後ろへ引く側だけ深くした腕**。前へ出る腕は M2b のまま（肘を畳んだ形・手の前への出19cm）。
- **見た目は旧（M2b）と同等**。盲検（画像だけを見る Opus 採点役3人）で、旧・腕なし・この版の3版が27件すべて同点。悪化はないが、**画像で「良くなった」とも言えない**（8コマ・0.5秒の連続写真では、頭の揺れや体幹の逆回転の差が読めない）。数値の改善は確かに出ている（下の表）。
- 実装担当の初版（腕を前へも振る）は、振り幅・同期の物差しでは目標を満たしたが、**盲検で旧に負けた**（54件中 新3・旧19）。そのまま出さず、腕を作り直した（下の経過）。
- 生の記録を main と項目ごとに比べて、**屈み歩きに入る約0.35秒、左腕が最大40度ずれる不具合**を見つけて直した（原因＝手の上限が層の効きに連動しなかった）。回帰に門番を足し、不具合を戻すと失敗することを確かめた。
- 論理側（位置・向き・歩容・接地・カメラ）は762コマすべて M2b と同じ。戦闘の論理は main と一致（斥候320・侍大将520コマ）。

- 1回目：前へ出た手が顔・頭の高さまで上がる／前腕が水平に棒状／曲がりで腕が頭より高く跳ねる、が3人とも繰り返し指摘された。実測も同じ向き（走りで手が首より上に出るコマ7%・前への出 19→26cm）。
- 2回目：肘を伸ばして手のひらを開いて前へ差し出す形が「棒のよう」。採点役が好んだのは M2b の「肘を畳んで胸の前」で、「後ろへの振りが小さい」とも言った → 3回目は前へ出る腕は触らず、後ろへ引く側だけ増やした。
- 3回目の「worst」の指摘は旧（M2b）側の1件だけ（頭が後ろへ傾く）。3人とも、旧・V1・V3 に同じ指摘（手のひらを開いて前へ差し出す・止まりが急・歩きが小走り）を付けた。
- 追従カメラ（プレイヤーが普段見る向き）は人物が小さく、差は読めない（2回目は27件すべて同点）。V1 の採点は差が読める横カメラだけにした。

## 実装担当の物差しが見逃したこと
腕の振り幅（45→71度）・反対側の太ももとの同期（相関0.99）・平均（−25→−9度）は、設計した内容そのものを測るので、初版でも目標を満たした（物差しと実装が同じ定義）。見た目の悪さ（手が首の高さまで上がる）は拾えなかった。**手の最高の高さ（首との差）と肩から手の前への出**を物差しに足し（`handPose`・単体試験つき）、回帰の目標を作り直した（手の最高≤首−5cm・前への出≤24cm。M2b は −5.9・19.0、初版は +2.0・26.4）。

## 戦闘・切替・性能・回帰
- `regress-attack-timing`：斥候320・侍大将520コマとも main の写しと一致（`combat.js` は変えていない）。
- `?smooth=arms` の記録の指紋 69ee9d393ee3399a が M2b の main と一致。敵（兵・侍大将）は構えで左手が武器を握る間は層が自動で切れる（実測：兵は効き≒0、侍大将は走り出しの一瞬だけ0.8まで入り、握りに合わせて1秒以内に消える）ので、主な効き先は主人公と味方。
- 単体887件・`npm run check`・`npm run smoke` 合格。ブラウザ回帰34本合格（`regress-locomotion-upper` に、屈み歩きの門番を足した）。
- 性能（`measure-perf`・main と交互に3回・p95 の中央値、ms）：移動・標準 15.8→15.7、戦い・標準 14.5→14.4。描画呼出（475・441）と三角形は同じ。差は測定のぶれの内（初版で測った +0.2ms も同程度）。最終コードで測り直した。

## 画像（`m3/`・8コマ・幅1280。`m2b-`＝`?smooth=arms`、`m3-`＝既定）
- `run_steady-side`・`run_stop-side`（4コマごと）：真横。M3 は後ろへ引く腕が少し深く、頭が水平に保たれ、上体が少し前へ傾く。差は小さい（画素の差は最大3.7%）。
- `run_steady-follow8`・`walk_steady-follow8`（8コマごと＝約0.13秒）：後ろからの追従。人物が小さく、腕の差はほぼ読めない。

## 残る課題・本人に遊んで見てほしい点
- **ロボットのような硬さが取れたか**は、遊んで確かめてほしい（画像では示せなかった）。`?smooth=arms` と見比べられる。
- 全版に共通して、盲検で繰り返し指摘された点（M3 以前から）：止まるとき走りの姿勢から2〜3コマで直立へ切り替わる／歩き（3.1m/秒）が両足の浮く小走りに見える／前側の手が手のひらを開いたまま胸の前に出る。
- 後ろへ引く腕の深さ（−62度）が大きすぎないか。止まった直後の息づかい（R36.3）は入れていない。
